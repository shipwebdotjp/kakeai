# ターミナルテンプレート（`terminal.session@1`）仕様

## 目的と境界

この文書は、黒いターミナル画面に入力と出力を並べるデータ駆動の VisualTemplate `terminal.session@1` の正とする。台本の契約は [../mvp/content-schema.md](../mvp/content-schema.md)、Cue 効果の共通単位は [../cue-effects/spec.md](../cue-effects/spec.md)、決定は [ADR-0119](../adr/0119-terminal-template-turns-and-reveal.md) を参照する。

- 画面は**映像として見せるだけ**とする。Scene の `lines`・`speakers`・TTS・字幕とは結びつけない。正本は Scene のセリフであり、ターミナルは独立した VisualCue の入力である。
- 正本は小さな構造化 JSON（ウインドウのタイトル・プロンプト・ターン列・表示効果）とする。HTML・SVG・スクリプト・実時刻は正本にしない。
- 1つの VisualCue は**1セッション**を表す。セッションは1つの Scene 内に収める。
- 表示は**上から詰める**。画面に収まらない場合は保存を成功させたうえで警告する（`terminal_overflow`）。スクロールはしない。
- ウインドウは `card` 層に置く。立ち絵（`standing` 層）は手前に描かれるため、端末が立ち絵を隠すことはない。左右の余白で重なりを減らすが、立ち絵の位置をテンプレートが知ることはない。
- テンプレートはコンテナ相対（cq 単位）で描く。字幕セーフエリアの上に収める。

## 入力契約

```jsonc
{
  "title": "~/project — zsh",       // 任意。タイトルバーの文字
  "prompt": "$",                     // 任意。既定 "$"。空文字なら描かない
  "typing": {
    "charsPerSecond": 40,            // 任意。既定 40（半角1・全角2の重み）
    "enterDelayMs": 120              // 任意。既定 120
  },
  "turns": [
    {
      "input": "npm test",           // 必須。1行
      "output": ["PASS ...", "..."]  // 任意。0〜32行
    }
  ],
  "effects": [
    {
      "target": { "kind": "turn", "index": 0 },
      "trigger": { "kind": "lines", "startLineId": "line-a", "endLineId": "line-a" },
      "effect": { "kind": "reveal", "mode": "type" }
    }
  ]
}
```

- `turns` は1件以上12件以下。`input` は1行・400文字まで。`output` は1件あたり32行まで、各行400文字まで。
- `prompt` と `title` は装飾テキストであり、動画の実時刻とは連動しない。
- `effects` は任意で最大32件。`target` は `{ kind: "turn", index }` のみ。1つのターンに複数の `reveal` は指定できない。
- `trigger` は既存の `lineTriggerSchema` を使う。ターンは1セリフに対応するため、`lines` を使う場合は `startLineId` と `endLineId` を同じ行IDにする。異なる場合は拒否する。`{ kind: "cue" }` は映像演出の先頭を契機にする。
- `effect` は `reveal` のみ。`mode` は `type`（既定）または `instant`。
- **effect がないターンは最初から表示する**。同期しない静的なターミナル画面はこれで作る。
- `collectLineRefs` は `effects[].trigger` の行参照を収集する。行を削除すると effect だけが取り除かれ、ターンは残って「最初から表示」に変わる。これはチャットテンプレートの「データは残す」挙動と同じ。
- `collectAssetRefs` は空。ターミナルは画像素材を要求しない。

## テンプレート定義

| 項目 | 値 |
| --- | --- |
| `id@version` | `terminal.session@1` |
| `layers` | `["card"]` |
| `transitionPolicy` | 既定（入退場はCue側） |
| `animationPolicy` | 既定（内部アニメーションは持たない） |
| `collectAssetRefs` | なし |
| `collectLineRefs` | `effects[].trigger` の行参照を収集する |

`inputFields` は次を持つ。

| key | kind | 内容 |
| --- | --- | --- |
| `title` | optionalText | ウインドウのタイトル |
| `prompt` | optionalText | プロンプト（既定 `$`） |
| `typing.charsPerSecond` | number | 入力速度（半角換算/秒、1〜120、未指定は40） |
| `typing.enterDelayMs` | number | 入力完了から出力までの間隔（0〜2000ms、未指定は120） |
| `turns` | turns | 入力と出力（最大12ターン） |
| `effects` | effects（`variant: "terminal"`） | セリフ同期（ターン選択・1セリフまたは映像演出全体） |

## 表示効果とタイピング

`reveal.mode = "type"` のとき、トリガーの開始から入力を1文字ずつ表示する。

- 既定速度は **40（半角換算/秒）**。全角1文字は2として数える。最初の文字はトリガー開始時に表示する。
- 1セリフ＝1ターンなので、タイピングの予算はそのセリフの終端から `enterDelayMs` を引いた時点までとする。最後の文字がそれを超える場合は、**その時点で残りを一気に表示**し、出力がセリフ終端までに表示されるようにする。途中で止めたまま次の行へ持ち越さない。
- 入力の表示完了から `enterDelayMs`（既定120ms）後に、出力をまとめて即時表示する。出力をタイプすることはしない。出力はセリフ終端（`cue` トリガーでは映像演出の終端）を超えない。
- `trigger` が `cue` の場合、予算は映像演出の終端までとする。複数のターンに `cue` を指定すると同時に始まるため、無音の自動再生には使わない。
- カーソルは「最後に表示された文字の右端」に置く。文字ごとの絶対配置で、全角・半角や折返しの幅計算に依存しない。点滅はしない。
- 表示はすべて `stateIntervals`（`tl.set`）で切り替える。CSSアニメーション・実時刻・乱数は使わず、シークとMP4出力で同じ結果になる。
- `reveal.mode = "instant"` は、トリガー開始時にターン全体（入力・出力）をまとめて表示する。タイピングもカーソルも出さない。
- effect がないターンは最初から表示し、タイピングもカーソルも出さない。

## レイアウトとウインドウ

- 背景は全面の近黒（放射グラデーション）。中央に **余白大きめのフローティングウインドウ** を置く。
- ウインドウは左右9%・上7%の余白、下端は字幕セーフエリア＋4%の位置。角丸・細い枠・影を持つ。
- タイトルバーは暗いグレー。左に赤 `#FF5F57`・黄 `#FEBC2E`・緑 `#28C840` の3ボタン、任意のタイトル文字を中央に置く。すべて装飾で、押せない・実時刻を読まない。
- 本体は黒。等幅フォント（`--kakeai-font-mono`）を使い、文字サイズは `1.75cqw`。プロンプトはテーマのアクセント色（黒背景とのコントラストが3未満なら白寄りに補正）、入力は明るい白、出力は少し暗いグレー。
- 内容は上寄せ。ウインドウ内で折り返し、はみ出した行は下でクリップする（スクロールしない）。
- 左端のプロンプトと入力は同じ行に置き、長い入力は折り返す。出力は行ごとに独立した行として描く。
- 下端は字幕セーフエリアの上で止める。字幕は黒背景の上に重なるが、ターミナル本文とは物理的に分ける。

## 行数警告

保存時に、`textWidthUnits`（半角1・全角2）で各ターンの入力・出力の折返し行数を概算し、合計が目安を超えたら `terminal_overflow` 警告を返す。

- 1行あたりの目安は全角44文字相当（縦型はプロファイルに合わせて縮小）。
- 合計行数の目安は横型13行・縦型32行。
- 警告は保存を拒否しない。プレビューで確認し、ターンや出力行を減らすか、Sceneを分割する。
- 実際の折返しはフォントと文字幅に依存するため、この値は目安であり、最終確認はプレビューで行う。

## 編集UI

- `turns` フィールドで、ターンごとに入力（1行）と出力（複数行）を編集する。
- 新しいターンを追加すると、まだ使っていない次のセリフを自動で割り当て、`reveal` 効果を追加する。未使用のセリフがない場合は効果を追加せず、ターンは最初から表示になる。
- ターンを削除すると、そのターンを対象にした効果を削除し、後続ターンの対象番号を詰める。
- `effects` の端末用バリアントでは、対象のターン（入力の先頭で表示）と、契機（1セリフまたは映像演出全体）、表示方法（タイプ／すぐ表示）を選ぶ。`lines` を選ぶとセリフは1つだけ選ぶ。
- `charsPerSecond` は「入力速度（半角換算/秒）」、`enterDelayMs` は「出力までの間隔(ms)」で編集できる。未入力ならそれぞれ40・120。

## 非目標

- 行をまたぐ自動再生（セリフ同期なしで順番にタイプするモード）。
- アニメ付きスクロール、過去行の保持、CRT風の走査線。
- 出力のタイプ表示、複数行入力（ヒアドキュメントなど）。
- ターン単位の強調（`emphasize`）や配色の自由指定。
- ウインドウ枠のバリエーション（最大化・枠なし）。v1はフローティング固定とする。
