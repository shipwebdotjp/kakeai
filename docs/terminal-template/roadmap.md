# ターミナルテンプレート ロードマップ

仕様は [spec.md](./spec.md)、実装項目は [todo.md](./todo.md) を正とする。

## Phase 1: 基本のターミナル（実装済み）

黒いフローティングウインドウに入力と出力を並べ、1セリフ＝1ターンで表示する。入力は固定速度でタイプし、セリフ尺からはみ出したら行末で残りを一括表示する。出力は入力完了後に即時表示する。effect のないターンは最初から表示する。

## Phase 2: 読みやすさと表現の拡張

出力行のトーン（成功・警告・エラー）、ターン単位の強調、入力速度の上書き、ウインドウ枠のバリエーションを追加する。行数警告の精度を上げ、プレビューで実際の折返しを確認しやすくする。

## Phase 3: 同期なしの自動再生

セリフに依存せず、固定ペースでターンを順番に表示するモードを検討する。タイピング速度と出力の保持時間から決定的に尺を導出し、実時刻を正本に直書きしない。アニメ付きスクロールを入れる場合は、折返し行数をコンパイル時に確定できる方式に限る。
