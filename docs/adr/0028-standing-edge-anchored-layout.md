# 立ち絵@2の外端アンカー配置

`character.standing@2` の左右配置を、固定中心（左 `x=0.27` / 右 `x=0.73`）から「外端の余白を固定し、倍率に応じて中心を寄せる」方式へ変更する。画像の半幅を `0.125×scale`（基準幅480px / フレーム幅1920px）とし、左 `x=0.03+0.125×scale` / 右 `x=0.97−0.125×scale` / `y=0.86` に写像する。

理由は、左右2体が中央寄りに見えるため、端一杯まで離したいから。外端の余白を一定にすることで、倍率を変えても「端」の見え方を保てる。`@1`（自由な `x`/`y`）は意味も描画も不変のまま残す。

## 版不変原則の一時的な例外

本来は[ADR-0009](./0009-template-version-immutability.md)に従い、見た目を変える場合は同じ `@2` を書き換えず新バージョン `@3` を追加すべきである。今回はMVP完成直後で保存済み `@2` が実運用上重要でないため、**`@2` の描画を直接変更することを一度だけ許容**する。レイアウト規則は [../multi-standing/spec.md](../multi-standing/spec.md) と [../mvp/content-schema.md](../mvp/content-schema.md) を同時に更新する。

## Considered Options

- 新バージョン `@3` を追加し、UIは `@3` を書き出す。→ 版不変原則には忠実だが、MVP直後で保存済み `@2` を保護する必要が薄く、契約と実装の分岐が増えるため見送り。
- 固定中心値を広げるだけ（例: 左 `0.15` / 右 `0.85`）。→ 倍率を小さくすると端から離れ、意図した「端一杯」を保てないため不採用。

## Consequences

- 保存済み `character.standing@2` の左右位置が変わる。`@1` は不変。
- 今後テンプレートの見た目を変えるときは、原則 [ADR-0009](./0009-template-version-immutability.md) に戻り新バージョンを追加する。
