# サムネイルは不変版にせず、可変の候補リストとして持つ

サムネイルは動画の `ScriptVersion` とは別に、`LanguageEdition` 配下の可変な候補群（`Thumbnail`）として持つ。各候補はテンプレート参照と入力JSONを持ち、明示保存でその場を上書きする（last-write-wins）。版履歴・復元は持たない。複数候補を最初から許し、1つを選択中としてポインタで指す。

理由は、サムネイルが台本のような厳密な版管理と再現性を要さず、ABテスト用に複数作って投稿する1枚を選ぶ運用が主だから。不変版を積むと「今どの候補が1枚か」の管理と参照ゼロ版のGCだけが増える。正本と派生の分離（[ADR-0001](./0001-canonical-json-over-derived-media.md)）は保ち、サムネイルも派生物を生む正本を持つ点は同じ。

## Considered Options

- `ScriptVersion` と同様に不変版を積む。→ 版管理・復元・GC の配管が増える割に、サムネイルの再現要求が低いため不採用。
- 候補を1枚に固定する。→ ABテスト・差し替えの拡張が後からのデータ移行になり、当初の狙いに反するため不採用。

## Consequences

- 可変の正本は本リポジトリでは初（`ScriptVersion`・`ThemeRevision` は不変）。衝突のない単一ユーザーの last-write-wins を前提とする。
- テンプレート版のGCは「どの保存済み候補からも参照されていない版」を条件にする。可変候補が参照しうるため、台本の参照だけで判断できない。
- サムネイル文書は `ContentDocument` に含めず、独立した `schemaVersion: 1` の契約とする。詳細は [../thumbnail/spec.md](../thumbnail/spec.md)。
