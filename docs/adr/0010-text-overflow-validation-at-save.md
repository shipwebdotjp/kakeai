# テキストのあふれは保存時に検証して拒否する

Status: superseded by ADR-0014

テキスト系テンプレートと字幕は、テンプレートごとに最大行数・最小フォントサイズ・自動改行規則を持つ。`title`、`subtitle`、`heading`、`body`、`captionText` がこの規則に収まらない場合、保存時に `VALIDATION_ERROR` で拒否する。描画時に黙って縮小したり、レンダー時まで問題を持ち越したりしない。

理由は、長文が保存できてしまうと、読めない動画がレンダーされてから初めて分かるため。将来AI下書きを加えると顕在化する。編集時に、修正可能なフィールドと理由を返す。

## Considered Options

- 保存は通し、描画時に自動縮小・切り詰めする。→ 意図しない見た目になり、気づきにくいため不採用。
- 保存は通し、警告だけ表示する。→ 見逃したままレンダーされるため不採用。

## Consequences

文字数・行数の上限はテンプレート契約の一部になり、上限を変えるには新しいテンプレート版が必要になる。多言語展開時は言語ごとに制約が変わりうる。
