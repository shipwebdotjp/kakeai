# 立ち絵の標準配置は外観に持たせる

Status: accepted

## Context

同じ立ち絵でも、全身画像と顔だけの画像では、同じキャンバスに置いたときの自然な大きさが違う。顔だけの外観は倍率を 0.5 程度にしないと全身画像と大きさが揃わない、といった調整が外観ごとに必要になる。

現在の倍率・端・高さはSceneの左右2枠に保存されており、外観を切り替えても値は引き継がれる。セリフ境界で外観を切り替える状態リストを導入すると、状態ごとに配置を持つ案も考えられるが、変更点ごとに配置を複製すると、開始時との整合規則とUIの編集項目が増える。

## 決定

- `CharacterAppearance` に任意の `standing: { scale, edge, vertical }` を追加する。ライブラリの外観と作品コピーの両方が持てる。省略時は `{ scale: 1, edge: "margin", vertical: "standard" }` とする。
- 立ち絵の倍率・端・高さは、各項目について `Cueの明示値 ?? 外観のstanding ?? 既定値` で解決する。
- シーン開始時の左右2枠は、キャラクターと外観を選ぶ。倍率・端・高さは外観の標準配置を読み取り表示し、直接編集しない。明示値を持つ旧Cueだけ「外観の標準に戻す」操作を出す。
- 状態リストは外観IDだけを持ち、配置を持たない。状態の外観を切り替えると、その外観の標準配置で描画される。
- ライブラリの外観の標準配置は「ライブラリから追加」で作品コピーへ引き継ぎ、「ライブラリから更新」の差分にも含める。作品コピー側で変更すれば、その作品だけ調整できる。
- 同じ外観画像を同じ作品の複数箇所で違う配置にしたい場合は、外観を複製する。外観とは別の「立ち絵プリセット」実体は作らない。必要が頻繁になった場合に別途判断する。
- `character.standing@1` の `scale`・`edge`・`vertical` は任意の上書きにする。既存の保存済みCueは明示値を持つため、旧作品の見た目は変わらない。新規Cueは省略し、外観の標準配置を使う。
- 状態変更ごとの入場・退場は持たない。切替はカットとする。

## Considered Options

- 状態ごとに倍率・端・高さを持つ。→ 変更点ごとに立ち絵カード相当の編集項目が増え、開始時との一貫性も崩れやすい。外観の標準配置で足りるため不採用。
- Sceneの2枠に配置を残し、外観は画像だけにする。→ 外観を切り替えるたびに配置を選び直す必要があり、「顔だけは0.5」という外観固有の知識を状態ごとに繰り返すことになるため不採用。
- 外観とは別に「立ち絵プリセット（外観＋配置）」を持つ。→ 同じ画像を複数配置で使う用途には強いが、新しい実体・CRUD・ライブラリ紐付け・Agent操作が増える。今回の用途は別画像の外観ごとの標準配置で足りるため不採用。
- 画像の寸法から自動で倍率を合わせる。→ 素材の余白や切り抜き方で結果が変わり、意図した大きさを予測できないため不採用。
- 状態リストの導入と同時に配置を完全移行する。→ 旧作品のSceneごとの明示値を失うか、外観の複製が必要になる。Cueの明示値を上書きとして残せば加算的に移行できるため、そちらを採用。

## Consequences

- ライブラリ外観のDBに倍率・端・高さの列が増え、DTO・作成/更新API・Agentの外観操作・外観編集UIに反映する。
- 作品の外観コピーは標準配置を引き継ぎ、「ライブラリから更新」の差分に含める。
- `character.standing@1` の入力スキーマは `scale`・`edge`・`vertical` を任意にし、レンダラーが外観の標準配置へフォールバックする。
- 旧作品のCueに残る明示値は上書きとして機能し続ける。UIは解決後の値を表示し、明示値がある場合だけ標準へ戻せる。
- 同じ外観画像を複数の配置で使いたい場合は、外観を複製する。複製した外観は `libraryAppearanceId` が重複するため、ライブラリ更新は同じ元を持つ外観をすべて差分に出す。
- 開始時状態のCueに明示値が残る旧作品で状態を追加すると、開始時と変更点で倍率が変わる可能性がある。UIは開始時の値を外観の標準へコピーするか確認する。
