# アプリ管理データの保存先はOS提供のアプリデータ領域とし、開発時だけ差し替える

SQLite、原本素材、レンダリング中間ファイル、Artifact（MP4）の保存先は、OSが提供するアプリデータディレクトリ（macOSでは Application Support 配下）をルートとし、特定OSの絶対パスをコードへ埋め込まない。開発時のみ環境変数 `KAKEAI_DATA_DIR` でルートを差し替える。絶対パスは正本データへ埋め込まず、`storageKey` をルート相対のキーとして解決する。

理由は、保存先を後から変えると既存作品の移行・バックアップ・容量表示が煩雑になるため、最初に境界を固定する。特定OSのパスを直書きすると、他OS対応やテスト時に移行コストが発生する。

## Consequences

起動時にルートを解決し、`db/`、`assets/`、`artifacts/`、`tmp/` を配下に分ける。バックアップと容量表示はルート単位で行える。`storageKey` は常にルート相対で扱う。
