# 立ち絵の基準倍率アップと立ち位置の3段階化

Status: amends ADR-0028

`character.standing@1` の描画基準と立ち位置の選択肢を変える。正式リリース前（`1.0.0` 未満）のため、[ADR-0071](./0071-pre-release-appearance-changes-without-version-bump.md) に従い版の追加なしで `@1` を書き換え、`schemaVersion` も `1` のままにする。

- 画像基準幅を 480px から 576px（従来の1.2倍）にする。`scale: 1` が従来の `scale: 1.2` と同じ大きさになり、新しい基準の1倍とする。半幅は `0.15×scale`（576px / 1920px）。
- 横位置は、画面端からの余白を3段階（`edge`）で選ぶ。`tight`（余白0）、`margin`（2%、既定）、`center`（8%）。左 `x=margin+0.15×scale` / 右 `x=1−margin−0.15×scale`。
- 高さは、中心Yを3段階（`vertical`）で選ぶ。`up`（0.78）、`standard`（0.86、既定・現状）、`down`（0.92）。
- 入力は任意フィールドの追加（`edge`、`vertical`、いずれも既定値付き）で行い、既存の `{ characterId, appearanceId, side, scale }` はそのまま検証を通る。保存時は新フィールドを明示的に書き込む。

理由は、従来の等倍が小さく常用が1.2倍だったため、基準自体を上げて操作を単純にすることと、立ち位置を自由座標ではなく「どれくらい端に寄せるか・上下」の離散選択で微調整できるようにすることである。外端アンカー方式（倍率を変えても端の余白が一定）の考え方は [ADR-0028](./0028-standing-edge-anchored-layout.md) を引き継ぐ。

## Considered Options

- 新バージョン `@2` を切る。→ ADR-0071 が正式リリース前の既定値・見た目変更を版追加なしで行えると定めており、開発用データのための描画分岐を増やす必要がないため不採用。
- `edge` / `vertical` を自由な数値（余白の割合・Y座標）で持つ。→ エージェントやUIが任意値を選ぶ余地が広がり、検証と表示のばらつきが増える。3段階で足りる要望のため不採用。
- `margin` の既定を従来の3%に据え置く。→ 「少し余白あり」を2%にすることで、現行位置（3%）が「少し余白ありより若干真ん中寄り」という利用者の認識と一致し、既定が自然な端寄せになるため不採用。

## Consequences

- 保存済みの `scale: 1` の立ち絵は、次回の描画から1.2倍の大きさで表示される。横位置は既定 `margin` で約19pxだけ外へ動く。
- `edge` / `vertical` を持たない既存JSONは読出し時に既定値（`margin` / `standard`）で解釈され、次回の保存で新フィールドが付く。
- `1.0.0` 以降の同種の変更は、[ADR-0061](./0061-template-version-as-reinterpretation-boundary.md) に戻り版追加または移行で行う。
