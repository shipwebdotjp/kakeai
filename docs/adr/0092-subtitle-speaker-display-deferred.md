# 字幕の話者名表示は今回は見送り、見せ方は Visual Skin の責務として将来検討する

焼き込み字幕と SRT の両方に話者名を出さない。`NarrationSegment.captionText` のみを従来どおり描画・出力する。

理由は、発話者は立ち絵のバウンドで判別できること、SRT は「聞かなくても内容が分かる」ためのもので話者名は必須ではないこと、見せ方（バッジ／2行目／なし）の選択は台本の真偽値ではなく Visual Skin の描写規則として設計すべきことである。Skin は trusted・版固定のレジストリであり、`ResolvedVisualSkin` に caption 話者名の描画を足すなら新 Skin バージョンとして設計するのが筋である。

## Considered Options

- 台本に `captions.showSpeakerName` 真偽値を追加する（映像は別行、SRT は「名前：本文」）。→ 実装は小さいが、将来 Skin へ移すと移行が必要になり、見せ方の選択肢（バッジ等）を真偽値では表せないため今回は不採用。
- Skin 側の caption 描画として追加する。→ 設計は正しいが、今回のスコープ（別名機能）を超えるため不採用。将来 Skin 新版として検討する。

## Consequences

- `docs/subtitle-export/spec.md` に「話者名は含めない」と理由を明記する。
- 将来やる場合は Skin 側の設計（バッジ／2行目／なし）から検討し、台本への真偽値追加は選ばない。
- この決定は恒久ではない。話者名の需要が明確になれば新しい ADR で再検討する。
