# ターミナルはターン単位のeffectsと専用revealで表す

Status: accepted

`terminal.session@1` は、黒いフローティングウインドウに入力と出力を並べる VisualTemplate とする。正本は `turns`（`input` と `output[]`）と、ターンをいつ表示するかを決める `effects` の配列である。表示効果は端末専用の `{ kind: "reveal", mode: "type" | "instant" }` とし、既存の共有 Cue Effect には加えない。1セリフは1ターンに対応し、`lines` トリガーでは開始と終了を同じ行IDにする。effect のないターンは最初から表示する。

タイピングは固定速度（既定40半角換算/秒）で行い、セリフの終端までに終わらない場合は残りをセリフ終端で一気に表示する。出力は入力完了後にまとめて即時表示する。ウインドウは `card` 層のフローティングとし、上から詰める。あふれはスクロールせず、行数の概算で `terminal_overflow` 警告を返す。詳細は [../terminal-template/spec.md](../terminal-template/spec.md) を正とする。

## Considered Options

- `chat.thread@1` にターミナル風の表示モードを追加する。→ 吹き出し・枠・入力ドックの意味論が残り、入力と出力が第一級のデータにならないため不採用。
- 1行ごとに VisualCue を分ける。→ 背景の端末を別Cueで維持し、行の範囲・重なり・退場を編集者が管理する必要があり、タイピングも表せないため不採用。
- ターンに `lineId` を直書きする。→ セリフ同期を外したターンを表せず、行削除でターン本体が消えるため不採用。トリガーは `effects` に分離する。
- 共有 Cue Effect に `reveal` を追加する。→ 端末以外の全テンプレートが新しい variant を解釈する必要があり、`appear` の preset 語彙とも意味が重なるため、v1では端末専用にする。
- 全画面の端末にする。→ 立ち絵と重なりやすく、左右に余白を残す目的に合わないため、余白大きめのフローティングウインドウにする。
- あふれた行をスクロールさせる。→ 折返し行数がフォント依存でコンパイル時に確定せず、シーク可能なスクロールを決定的に作れないため、v1では上寄せ・クリップ・警告にする。

## Consequences

- セリフを削除すると、その行を契機にしていた `reveal` 効果だけが消え、ターンは残って「最初から表示」に変わる。
- 行を同期なしで表示する場合は effect を付けない。固定ペースの自動再生はv1の対象外とする。
- タイピングのタイミングは `stateIntervals` で表し、CSSアニメーションや実時刻を使わない。プレビューとMP4で同じ結果になる。
- 行数警告は目安であり、実際の折返しはプレビューで確認する。ウインドウをフローティングにしたぶん、全画面より早く警告が出る。
- `reveal` が他のテンプレートでも必要になった場合は、新しいADRで共有語彙への昇格を判断する。
