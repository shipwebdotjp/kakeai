# ライブのコメントはコメントコーナーで拾い、人間ピンを優先してAIが残りを埋める

Status: accepted

ライブのコメントは、台本の途中で常時拾うのではなく、スパイン上の**コメントコーナー**でまとめて拾う。オペレーターが選んだコメント（**人間ピン**）を確定枠として優先し、残りの枠をAI候補がスコア順に埋める。人間の承認遅延は置かず、生成レスは自動で流す。オペレーターは非常ブレーキと訂正役として、スキップ・停止・編集・安全モードで介入する。

## Context

- コメントを常時拾うと、台本の話題が途切れ、進行の一貫性を保つのが難しい。最初のライブでは、話題の区切りでコメントを拾う方が安定する。
- AIだけに進行を任せると、コメント選択・文脈の維持・安全の判断がまだ重い。最初は人間がピンを刺し、AIが残りを埋める形で、人間の関与の効果を測る。
- 人間とAIの配分を固定比率にすると、番組ごとの差や人間の余裕に合わない。人間が活発ならピンが枠を埋め、人間が忙しければAIが全部拾う方が自然である。
- 生成レスを毎回人間が承認すると、ライブのテンポが落ち、コンソールの負荷が高い。一方で、放送遅延を入れて事前に消せるようにすると、プレイアウトとコンソールが複雑になる。
- LLMの安全訓練は、危険な内容の生成に対して強い。v1では、上流のコメントフィルターと生成レスの検査を置き、放送後の訂正とログで運用する。
- コメントの即時割り込みは、話題の一貫性と進行の制御を難しくする。v1では次のコメントコーナーで拾う。

## 決定

- コメントは、スパイン上の`comment`セグメント（コメントコーナー）でのみ拾う。v1では台本の途中に即時割り込みしない。
- コメントコーナーは`maxCommentsPerCorner`（既定4）の枠を持つ。コーナーの入りと締めは準備済みの固定キューにできる。
- 人間ピンは、台本パートの間にコンソールのコメント一覧から刺せる。ピンは次のコメントコーナーで優先され、AI候補より先に枠を消費する。
- 人間ピンがない場合は、AI候補が残り枠をすべて埋める。人間ピンが枠を超えた場合は、コーナーを上限まで延長するか、次のコーナーへ回す。
- 人間は、AIの候補一覧だけでなく、ライブのコメント一覧からどのコメントでもピンできる。ピンには短いメモ（質問として／ツッコミとして／共感して）を添えられる。
- AI候補は、コメント分析役がスコア、関連性、安全性、質問かどうか、理由、切り口を付けて提示する。ディレクターは残り枠をスコア順に埋める。
- コメントが0件ならコーナーをスキップする。1〜2件なら短く終える。枠を埋めるために無理に拾わない。
- コメントコーナー中のピンは、現在の回答が終わった次の境界で入れる。音声を途中で切らない。
- 安全の下限は人間でも超えられない。個人情報、攻撃、禁止話題は、ピンされても拾わない。それ以外は人間の判断を優先する。
- 生成レスは自動承認で流す。放送遅延（人間の承認待ち）は入れない。生成中はコンソールで編集・キャンセルでき、準備完了後・再生開始前は削除・並べ替えでき、再生開始後は停止・訂正だけを行う。
- オペレーターコンソールは、ピン、ピン解除、スキップ、コメント一時停止、停止、安全モード、訂正キュー、投稿者・話題のブロックを持つ。
- 生成・編集・削除・スキップ・停止は、追記のみの実行ログに残す。

## Considered Options

- 人間とAIの固定枠（例: 人間2・AI2）を設ける。→ 番組ごとの差と人間の余裕に合わず、比率の調整が常に必要になるため不採用。
- 人間ピンにスコア加点だけを付ける。→ 人間の推しがAI候補に負けることがあり、人間の意図が通らないため不採用。
- 生成レスを毎回人間が承認する。→ テンポが落ち、コンソールの負荷が高いため不採用。
- 10〜30秒の放送遅延を入れ、再生前に人間が消せるようにする。→ プレイアウトとコンソールが複雑になり、コメントの鮮度も落ちるため、v1では不採用。上流フィルターと再生後の訂正で運用する。
- 台本の途中で即時割り込みする。→ 話題の一貫性と進行の制御が難しくなるため、v1では不採用。
- AIだけにコメントコーナーを任せる。→ 最初のライブでは品質と安全の実績がなく、人間のピンの効果も測れないため、v1では併用を主とする。
- コメントを常時画面に流す。→ 視認性が悪く、進行の区切りも失われるため不採用。コメントカードは回答中のものだけに絞る。

## Consequences

- ショープロファイルに、コメントコーナーの枠数、人間ピンの上限、鮮度、即時割り込みの可否を持つ。
- コンソールに、コメント一覧、AI候補、人間ピン、残り枠、ピンの鮮度を表示する。人間は台本パートの間にピンを準備できる。
- AIは、人間ピンがないときだけコメントコーナーを主導する。人間がピンを刺したら素直に譲る。
- コメント0件やコメント不足でコーナーをスキップするため、尺は目標より短くなり得る。超過・不足は許容する。
- 安全は、コメント前処理、分析役の`safety`、生成レスの検査、禁止話題、人間の停止・訂正の多層で守る。放送後の完全な取り消しはできない。
- 生成・編集・削除のログが残るため、配信後のレビューとプロンプト改善に使える。
- AIの自律進行、即時割り込み、放送遅延は、v1の実績を見てから別ADRで判断する。
