# サムネイルはTheme継承の疎なAppearance上書きで個別化する

Status: amends ADR-0059, ADR-0080, amended by [ADR-0085](./0085-thumbnail-appearance-presets-as-snapshots.md)

サムネイルの見た目は引き続き Visual Theme を既定とするが、チャンネルごとの文字サイズ・色・書体・強調色・暗幕を調整するために、言語版共通と候補単位の2段階で**プロパティ単位の疎な上書き**を持つ。あわせて同梱テンプレートを `thumbnail.cutout-hero@1` だけに整理し、旧4テンプレートを削除する。

## 決定

- `LanguageEdition` に `thumbnailAppearanceJson` を追加し、言語版共通の Appearance を可変JSONとして保存する。候補ごとの上書きは Thumbnail 文書 v2 の `appearanceOverride` に保存する。
- 解決順は `Theme → 言語版共通Appearance → 候補Appearance → テンプレートの構図・倍率` とする。未指定プロパティは Theme の変更に追従し、明示した色・書体・サイズ・太さ・行間は保持する。
- Appearance は見出し・補足文の Font Face／カテゴリ／サイズ／色／行間／装飾、縁取り色・太さ、強調色、scrim色・不透明度を持つ。サイズと縁取りの太さは Theme と同じ1080基準pxで表し、1280x720出力時にテンプレートがスケールする。
- 写真上で読めるよう、見出し・補足文の色の既定は `onMedia` とし、書体・サイズ・行間・装飾は Theme の `title` / `heading` を継承する。
- 強調色を明示した場合は、背景とのコントラストによる自動置換をしない。未指定時だけ Theme の primary accent を可読性解決する（ADR-0080 の「アクセントは Theme 固定」をここで改める）。
- 縁取りは色と太さ（0–12、1080基準px）を指定でき、ロール全体の装飾と `%%` の部分装飾で同じ設定を共有する。色を未指定にした場合は、文字色と背景から Theme ニュートラルを選ぶ。
- テンプレートは背景全面・透過の前景切り抜き・下部の大見出しで構成する `thumbnail.cutout-hero@1` のみとする。旧 `headline-photo` / `photo-cover` / `text` / `layered` は描画コード・入力型・カタログから削除する。
- サムネイル文書は v2 を新規保存の既定とし、v1 は `appearanceOverride` なしとして読み取る。v1 から v2 への一括移行は行わない。
- プレビューAPIは未保存の共通 Appearance を受け取り、保存前の見た目を確認できるようにする。

## Considered Options

- 言語版ごとに Visual Theme を複製する。→ 動画側の Theme と二重管理になり、サムネイルだけの調整に Theme Revision を消費するため不採用。
- 解決済みの Appearance を候補へ丸ごと保存する。→ Theme 変更への追従が失われ、同じ値を全プロパティに複製するため不採用。
- テンプレートごとに独立した Appearance を持つ。→ テンプレート追加のたびに設定が分裂し、共通の見た目を揃えられないため不採用。
- 旧4テンプレートを legacy として残す。→ 保存済み候補が無い前提で、未使用の描画・入力・テストを維持するコストの方が高いため不採用。

## Consequences

- Theme を変更すると、上書きしていない項目だけが追従する。明示した値は保持される。
- 旧テンプレートを参照する候補は描画できない。今回は存在しない前提とし、削除用Migrationは作らない。
- 縁取りは固定2pxのThemeニュートラルから、ロールごとの設定可能なスタイルへ変わる。明示色は自動補正しないため、読みやすさはプレビューで確認する。
- 前景画像の透過性は検査しない。非透過画像は四角い背景ごと表示され、利用者がプレビューで判断する。
- Appearance は言語版内だけで共有し、Work横断のプリセットライブラリは作らない。
- テンプレートの構図（被写体の下端基準・反対側の下部安全領域・文字量による自動サイズ）は固定で、フリーキャンバスは提供しない。
