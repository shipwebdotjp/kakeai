# サムネイルの部分装飾は限定記法とThemeトークンで表し、`@1` を拡張する

Status: amends ADR-0061, amended by [ADR-0084](./0084-thumbnail-appearance-overrides.md)

サムネイルの文字入力は、文字列全体ではなく単語単位で装飾できるようにする。正本は今まで通り1本の文字列とし、装飾は `**太字**`、`*斜体*`、`==アクセント==`、`%%縁取り%%` の限定記法として同じ文字列に含める。`\` は直後の記法記号をエスケープし、記法記号以外の前ではバックスラッシュのまま残る。対になっていない記法記号は文字として表示する。保存される JSON の型は `string` のままなので、Thumbnail の `schemaVersion` は上げない。

装飾の見た目は利用者が決めない。`TemplateFieldSpec` の `richText` が許可する装飾（`marks`）を宣言し、太字・斜体は文字トークンの装飾へ、アクセント色は Theme の primary アクセントへ、縁取りは Theme のニュートラル色へ解決する。アクセント色は背景とのコントラスト比が3未満なら Theme のニュートラル方向へ寄せ、縁取り色は文字色に対してコントラストが取れるニュートラルを選ぶ（同点は背景とのコントラストで決める）。

同梱テンプレートは `thumbnail.headline-photo@1`、`thumbnail.photo-cover@1`、`thumbnail.text@1`、`thumbnail.layered@1` を版を上げずに拡張する。ADR-0061 は「保存済みの有効入力の再解釈を伴うときだけ版を上げる」と定めるが、今回は次の理由で例外とする。

- サムネイル機能は導入直後で、実運用の保存済み候補がほぼ無い。
- 記法の区切り記号（`**`、`==`、`%%`、`*`）は通常の日本語見出しに現れず、現れた場合も `\` でエスケープできる。
- 記法を含まない既存の文字列は、描画結果が完全に一致する。

## Considered Options

- HTMLを許可する。→ `sandbox="allow-same-origin"` のプレビューに任意マークアップが入り、任意スタイルとスクリプトの境界が崩れるため不採用。
- 装飾区間を構造化データ（`{ text, marks }` の配列）で保存する。→ 曖昧さは無いが、エージェントやCLIが文字オフセットを計算する必要があり、エディタも選択範囲の管理が重くなる。記法を正本にし、描画時に同じ区間表現へ正規化すれば同じ描画結果が得られるため、今回は不採用（将来の移行余地は残す）。
- テンプレートが決めた固定スロット（見出し＋強調見出し）だけを装飾する。→ 任意の単語を選べず、要望を満たさないため不採用。
- contenteditable のリッチエディタで任意の色・サイズを許す。→ Theme 共有（[ADR-0059](./0059-thumbnail-shares-visual-theme.md)）とフリーキャンバス禁止の境界が崩れるため不採用。UIは textarea とツールバーで記法を挿入する。

## Consequences

- 記法の解析は `packages/contracts` の1実装を保存時検証・プレビュー・コンパイル・エージェント入力で共有する。対になっていない記法記号は文字として描画し、フィールドが許可しない装飾だけを `VALIDATION_ERROR` にする。
- 保存済み候補に対になった区切り記号が含まれていた場合、その候補だけ見た目が変わる。ADR-0061 の「版を上げる」判断を今後も省略できるわけではなく、同種の変更では改めて版の要否を検討する。
- 斜体は書体に斜体フェイスが無い場合、ブラウザが合成斜体を作る。動画の `text.block` と同じ挙動であり、テンプレート側で特別扱いしない。
- 装飾の追加（下線、サイズ変更など）は `marks` の拡張として行い、ユーザー指定の色は引き続き受け付けない。
