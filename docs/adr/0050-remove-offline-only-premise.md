# オフライン完結の前提を外し、AI機能にネットワークと外部サービスの利用を許す

MVP仕様の前提「ネットワークや外部AIサービスなしで動画を作成・出力できる」（[../mvp/spec.md](../mvp/spec.md)）を外す。基本的な動画制作は引き続きローカルで完結するが、AI機能はネットワークや外部サービスを使えるものとする。

理由は、多言語化で必要になる外部AI（翻訳、外部TTSエンジンなど）はローカルの枠に収まらず、`LanguageEdition` を増やす翻訳・音声生成の実務を外部へ委ねる設計（[../mvp/roadmap.md](../mvp/roadmap.md) Phase 2/3、[../multilingual-voice/spec.md](../multilingual-voice/spec.md)）と、オフライン完結の前提が衝突するためである。

## Considered Options

- 前提を維持し、AIをすべてローカルで賄う。→ 多言語TTSや翻訳モデルをローカルに組み込む負担が大きく、個人用アプリの範囲を超えるため不採用。
- AIを外部に委ねつつ、前提を「AIを使わない場合はオフラインで完結」と読み替える。→ 採用。基本制作がローカルで完結する点は変えず、AIを使う操作だけ外部通信を許す。

## Consequences

- [../mvp/spec.md](../mvp/spec.md) の前提を「基本的な動画制作はローカルで完結する。AI機能はネットワークや外部サービスを使える」へ変更する。
- AIの出力は提案として扱い、人の明示的な採用なしに正本（`ScriptVersion.contentJson`）へ反映しない。AIが正本を自動更新しない原則は維持する。
- レンダーの再現性・bundleの外部URL禁止・content配信の保護といった、既存のローカル安全境界の設計は変えない。変える場合はこの決定を新ADRで見直す。
