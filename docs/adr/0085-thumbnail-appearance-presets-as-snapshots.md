# サムネイル外観プリセットはスナップショットとして適用する

Status: amends ADR-0084

言語版共通のサムネイル外観を別の言語版や作品でも使いたいという要求に対して、アプリ全体の名前付き**外観プリセット**を追加する。プリセットは疎な外観パッチを保存し、適用は言語版の共通外観への**スナップショットコピー**とする。プリセットへの参照は言語版に保存しない。

## 決定

- `ThumbnailAppearancePreset` をアプリ全体の共有資産として持つ。Work や LanguageEdition には属さない。
- プリセットは解決済みの外観ではなく、`Thumbnail Appearance` の疎な上書きパッチを保存する。適用先テーマで未指定のプロパティは、そのテーマの値に従う。
- プリセットを読み込むと、現在の言語版共通 Appearance の**下書き**をパッチで置き換える。ユーザーが「共通の見た目を保存」を押すまで言語版へ反映しない。
- 言語版はプリセットIDを保存しない。プリセットを後から上書き・削除しても、適用済みの言語版の外観は変わらない。
- プリセットの一覧・取得・作成・上書き・削除APIを追加する。空のパッチは保存時に拒否し、保存時に正規化する。
- プリセットはUI上で新規保存・読み込み・上書き・削除できる。読み込み時に未保存の変更がある場合は確認する。
- テーマへの外観の埋め込み、テーマごとの既定プリセット、プリセットのライブ参照は今回の対象外とする。

## Considered Options

- テーマIDに共通外観を持たせ、同じテーマの作品へ自動共有する。→ 同じテーマの作品を常に揃えられるが、外観の編集が全作品へ即時に波及する。組み込みテーマの保存先、テーマ切り替え時の追従、Theme Revision の不変性との関係も別途整理が必要なため、今回は採用しない。
- 言語版がプリセットIDを参照し、プリセット変更を自動反映する。→ 一元管理できるが、プリセットの編集が適用済みの全サムネイルを意図せず変える。サムネイルはオンデマンドPNGのため影響が即座に現れる。スナップショットの方が予測可能なため不採用。
- 他の言語版から直接コピーするだけにする。→ 最小実装だが、目的の外観を「どの作品のどの言語版か」で探す必要があり、名前付きの再利用資産にならないため、プリセットを採用する。
- 解決済みの外観をプリセットへ保存する。→ 適用先テーマの変更に追従できず、Theme 継承（[ADR-0059](./0059-thumbnail-shares-visual-theme.md)）と矛盾するため不採用。

## Consequences

- 既存の `LanguageEdition.thumbnailAppearanceJson` はそのまま使う。プリセット導入のためのデータ移行は不要。
- プリセットの上書き・削除は適用済みの言語版へ波及しない。ユーザーは適用時に明示保存する。
- プリセットはテーマや作品をまたげるが、プリセット自体のインポート／エクスポートや他端末共有は提供しない。
- 将来プリセットをライブ参照したくなった場合は、`LanguageEdition` にプリセット参照を追加する新しいADRが必要になる。その場合も既存のスナップショット適用済みデータはそのまま読める。
- ADR-0084 の「Work横断のプリセットライブラリは作らない」という判断を、このADRで置き換える。
