# AIエージェントは可逆な操作を直接実行してよく、不可逆な操作だけ人に限る

> amended by [ADR-0077](./0077-agent-tts-on-configured-adapters.md): 利用者が設定したループバック TTS Adapter への合成 Job 投入は、生成 Asset と Script Version のいずれも履歴から戻せるため可逆な操作に含める。接続設定の変更と TTS 以外の課金生成は引き続き人に限る。

Status: accepted

Kakeai は保存のたびに新しい不変の Script Version を追加し、過去版を書き換えないため、台本編集・素材割り当て・素材取り込み・レンダー投入のような操作は常に巻き戻せる。したがって、AI の変更のたびに「提案だけを出し、人の明示採用を待つ」一段を強制するのは、不変版管理がすでに与えている安全性と重複し、編集フローを不必要に遅くする。AI エージェントは、不変データの追加または Asset の取り込みという可逆な操作を直接実行してよい。実体の削除、外部への公開、課金を伴う生成などの不可逆な操作は人の明示操作に限る。

## Considered Options

- すべての AI 変更を提案として保持し、人の明示採用なしに正本へ反映しない（旧原則）。→ 不変版管理が同じ安全性をすでに提供し、採用操作が冗長なため不採用。
- AI に実体削除や外部公開も許す。→ 巻き戻せない変更を含むため不採用。

## Consequences

AI が作った版は帰属（Version Author）を記録し、履歴で識別と巻き戻しができるようにする。roadmap の「AI が作品の正本を自動更新しない」記述は本 ADR で置き換える。`ScriptVersion` に帰属列を追加する。操作の入口と接続方式は [ADR 0075](./0075-agent-local-socket-single-writer.md) と [Agent Access 仕様](../agent-access/spec.md) を正とする。
