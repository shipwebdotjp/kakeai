# ADR-0082: LanguageEdition 間の同期は追跡しない

## 状況

多言語 Edition の計画で、ロードマップ Phase 4 は「原本の変更と各言語版の同期状態を表示し、再翻訳・再レンダーの対象を明確にする」ことを含んでいた。Edition 間の対応付け自体は stable ID（`line` と Scene の版をまたぐ ID）で技術的には辿れる。

## 決定

- Edition 間の同期状態の表示・未同期検知・再翻訳リストは作らない。`line`/Scene の stable ID が Edition 間対応を辿れる前提だけ維持する。
- 各 Edition は作成後、独立した台本として編集する。原本の変更を他言語版へ反映する責務はアプリが持たず、作り直し（新 Edition 作成・必要な行のコピーや Agent 編集）で対応する。

## 理由

- 利用者（本人）は言語版を翻訳後ほぼ別のコンテンツとして扱っており、原文の文言修正は言語版に自動同期すべきでない。同期状態 UI は対応性の見かけを維持する負担だけを生む。
- 対応付けが stable ID で可能なため、将来同期機能を導入したくなったとき後からでも DB・契約を破壊せず足せる。導入せずに破壊的な損失もない。

## 今後に向けた含意

- [../mvp/roadmap.md](../mvp/roadmap.md) の Phase 4 記述の「同期状態を表示」は本 ADR により実装対象から外れる。
- Edition 間対応が必要になった場合は新 ADR で改める。
