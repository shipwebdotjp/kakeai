# テンプレート版は参照が無くなれば削除できる

Status: amends ADR-0009, amended by ADR-0034

`template.id@version` の意味とレイアウト規約は不変に保ち、変更は新しい版で行う。過去の版の描画コードは原則削除しないが、どの保存済みScriptVersionからも参照されていない版は削除してよい。見た目を頻繁に更新する将来（背景モーション、キャラ追加など）で、参照ゼロの版が無限に増えるのを避けるため。

## Consequences

版を削除する前に、保存済みScriptVersionと実行中Jobのスナップショットが参照していないことを検査する。参照がある版は削除できない。
