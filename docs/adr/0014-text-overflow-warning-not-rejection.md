# テキストあふれは保存時に拒否せず警告する

Status: supersedes ADR-0010

テキスト系テンプレートと字幕の最大行数・最小フォントサイズ超過は、保存を拒否せず `meta.warnings` として該当フィールドと理由を返す。利用者はプレビューで実際のはみ出しを確認して修正する。理由は、ブラウザ描画と一致するフォント計量を保存時に厳密に行う実装コストが高く、個人利用では誤拒否が作業を止めるため。描画時に黙って縮小・切り詰めない点は維持する。

## Considered Options

- 保存時に `VALIDATION_ERROR` で拒否する（旧 ADR-0010）。→ 厳密な計量が必要で、誤拒否のリスクが高いため不採用。
- 保存を通し、描画時に自動縮小・切り詰めする。→ 意図しない見た目になり気づきにくいため不採用。

## Consequences

テキスト制約はテンプレート契約に残るが、保存時の強制ではなくプレビューでの確認に変わる。AI下書きなどで長文が入りやすくなった場合は、厳密検証の再導入を検討する。
