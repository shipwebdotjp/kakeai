# エージェントの生成境界は課金ではなく利用者が設定した接続先で引く

Status: accepted

## 背景

[ADR 0074](./0074-agent-direct-reversible-operations.md) は可逆な操作をエージェントに許し、不可逆な操作を人に限る。ADR 0077 はこの基準で TTS を可逆と認めたうえで、「TTS 以外の課金生成は許可しない」という条件を付け足した。この条件には次の問題がある。

- 課金の有無は操作の性質ではなく、接続先と利用者の契約の性質である。アプリもエージェントも、その呼び出しが有料かを知る手段を持たない。
- エージェントの実行自体が利用者の費用を伴いうるため、「エージェントに課金を起こさせない」は自己矛盾になる。
- エージェントは Kakeai の外で画像などを生成し、`asset.import` で取り込める。金額の発生はこの経路で既に起こりえて、規制文はそれを捕捉していない。
- TTS も接続設定ひとつで有料のクラウドへ向きうる（現行のループバック限定はアダプター側の制約）。禁止の境界は設定変更で破れる。

一方で、実際に守るべき境界は観測できる。エージェントが **利用者の設定していない接続先** を使わないこと、**接続先・認証情報・アダプター設定を読み書きしない**ことである。そこで課金を公開条件から外し、接続先の帰属を条件にする。

## 決定

可逆な操作をエージェントへ公開する条件を、次の2つとする。金額は条件に含めない。

1. 操作の結果を Kakeai の正本データ（不変 Asset・Script Version・Composition Version）に対して巻き戻せること（ADR 0074 の基準を維持する）。
2. 利用するのが **利用者が設定した接続先だけ** であり、エージェントが接続先・認証情報・アダプター設定を作成・変更・読取できないこと。

現時点（B2）では、Kakeai は接続先（URL）だけを知り、生成サービスの認証情報を保持しない。認証情報は利用者の環境（ローカルゲートウェイ等）に置く。これにより Kakeai は課金主体にも秘密の保管者にもならない。

外部送信と外部公開は別とする。利用者が設定した接続先への生成要求は外部送信だが、成果物を第三者の場に置く外部公開ではない。外部公開は引き続き人に限る。可逆性は Kakeai の正本データに対して定義し、Kakeai の外の副作用（プロバイダ側の課金・ログ）は判定に含めない。

## Considered Options

- 課金を伴う生成を引き続き禁止する（ADR 0077 の条件）。→ 判定不能で、エージェントの実行費用とも矛盾し、`asset.import` 経由の外部生成を止められない。不採用。
- 課金の語を消し、代わりの条件を置かない。→ 将来クラウドの生成アダプターを足したときの既定が決まらず、機能追加のたびに場当たりになる。不採用。
- アプリがクラウド API キーを保持する（B1）。→ 今は必要がない。採る場合は「アプリは API キー・課金を管理しない」という非ゴールを全面的に書き換える別の決定になる。将来の選択肢として保留する。
- 採用: 利用者が設定した接続先だけを使えることを条件にする（B2）。

## Consequences

- ADR 0074 の不可逆の例から「課金を伴う生成」を外す。可逆性の基準そのものは変えない。
- ADR 0077 の「TTS 以外の課金生成は許可しない」を、上の接続先の条件へ置き換える。TTS を可逆として公開する決定は維持する。
- Agent Access 仕様・ユーザーガイド・制作スキルは、金額ではなく「設定済みの接続先だけを使える」「接続先・認証情報・アダプター設定は読み書きできない」「実体削除と外部公開はしない」を境界として書く。
- この決定で新しく公開される操作はない。画像生成アダプターは存在せず、操作カタログも変わらない。基準の窄め方の変更であり、公開面の拡大ではない。
- 将来クラウドの生成アダプターを追加するときは、利用者が設定した接続先である限りこの条件の下でエージェントに公開できる。どのアダプターを製品として持つかが唯一の判断点になる。
- ADR 0078 の理由にある「課金生成の禁止を侵さない」は、本 ADR で接続先の条件へ読み替える。`preview.frame` が読み取り専用である結論は変わらない。
- この決定は恒久ではない。アプリが資格情報を保持する必要が出た時点（アプリ単体でクラウド生成を完結させたい要件が出た時点）で B1 を再検討し、非ゴールを含めて新しい ADR で置き換える。それまでは B2 を前提とする。
