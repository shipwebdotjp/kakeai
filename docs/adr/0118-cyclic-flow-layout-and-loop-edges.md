# フロー図は明示的な線形・循環レイアウトと導出辺種別で反復を表す

Status: amends ADR-0064

`flow.diagram@1` は既存のノード配列とindex参照の辺を正本として維持し、任意の `style.layout: linear | cycle` を追加する。自己ループを許可し、後ろ向き・自己ループ・周回・補助の各辺は別の保存値ではなく `from` / `to`、レイアウト、ノード数から導出する。動画用の小さな図で意図と決定性を保つため、自由座標と任意グラフの自動レイアウトは採用しない。

## Considered Options

- 辺に `kind: forward | backward | loop` を保存する。→ indexの向きと意味が食い違う状態を作り、線形から循環へ切り替えたときにも再解釈が必要になるため不採用。
- 循環ごとに専用テンプレートを作る。→ ノード・辺・効果・編集の契約が重複するため不採用。既存テンプレートのレイアウト選択として表す。
- 任意グラフの自動レイアウトを導入する。→ 結果が予測しにくく、動画のプレビューとMP4での決定的な描画確認も難しくなるため不採用。

## Consequences

- `layout` 未指定の既存Cueは従来の線形表示を維持する。
- 線形では配列順が主工程、循環では配列順が時計回りの周回順となる。ノード並び替えはどちらでも辺と効果targetを追従させる。
- 自己ループは1ノード1本に制限し、循環レイアウトは3〜8ノードに限る。詳細は [../flow-loops/spec.md](../flow-loops/spec.md) を正とする。
