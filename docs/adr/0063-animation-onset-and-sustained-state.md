# テンプレート内部アニメを発火と持続状態に分離し、持続を行区間で解決する

テンプレート内部アニメーションを、一発で完結する**発火アニメ**と、区間中ずっと続く**持続状態**に分離する。発火は既存の `AnimationPlan`（`tl.from`）で表し、持続は `RenderedCue` に `stateIntervals`（対象要素ID・ON区間・ON/OFF時の見た目）として返す。コンパイラだけが `stateIntervals` を `tl.set` の on/off へ変換する。ON/OFFの区間は行区間から解決し、発火と持続は別サブ要素に当てて互いに干渉させない。

理由は、口パク・瞬き・表情（[ADR-0048](./0048-deterministic-blink-and-speaking-mouth.md)）で既に「行区間で状態を切り替える」機構をコンパイラが持つが、`character.standing` にハードコードされていること。これを汎用化すれば、発火と持続を分離でき、「発火中に持続状態を重ねて競合する」問題を避けられる。発火の尺とトリガー区間の尺は別の時計として扱い、発火中に持続の解除判断をする必要をなくす。

## Considered Options

- 持続も `AnimationPlan` の2つの発火（ONとOFF）で表す。→ `tl.from` は状態を保持できず、区間終了時の解除を表現できないため不採用。
- 発火と持続を同じ要素の同じプロパティに当てる。→ 発火アニメの進行中に持続状態が競合して描画が壊れるため不採用。
- 持続状態をテンプレートが生のGSAPとして返す。→ 任意スクリプトを正本へ持ち込む方針に反するため不採用。

## Consequences

- コンパイラの interval→`tl.set` 生成を `character.standing` 専用から共通ヘルパへ抽出し、任意テンプレートの `stateIntervals` に適用する。
- 持続のON/OFFは半開区間 `[start, end)` で解決し、Cue窓の外はクランプする。空区間は無視する。
- `emphasize` は持続状態として表す。第一弾は枠・背景の強調で、発火時の走査演出（`onset`）は後続の加算的拡張とする。
- 発火と持続は別サブ要素（例: 走査線は一時要素、強調は枠要素）に割り当てることをテンプレート側の責務とする。
