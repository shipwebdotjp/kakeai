# MVPは単一プロセスで起動し、レンダーワーカーをAPI内で実行する

個人利用のローカルアプリで開発・起動の負担を最小にするため、MVPではAPIとレンダーワーカーを単一プロセスで起動し、ワーカーはAPIプロセス内のバックグラウンドループとして動かす。将来の分散・スケール時に別プロセスへ分離できるよう、コード境界だけは分けておく。

## Considered Options

- APIとワーカーを最初から別プロセスにする。→ 起動・ビルド・デバッグの手間が増え、単独利用のMVPに見合わないため不採用。

## Consequences

「1コマンド起動」を保証できる。SQLiteへの書込みは同一プロセス内で完結する。ワーカーの異常終了はAPIプロセスの終了と一致する。
