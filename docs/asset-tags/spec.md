# 素材タグ仕様

## 目的と境界

この文書は、再利用可能な素材ライブラリで素材を分類し、見つけやすくするためのタグの正とする。素材の取り込み・原本の不変性は [../mvp/spec.md](../mvp/spec.md)、HTTP契約は [../mvp/api-contract.md](../mvp/api-contract.md) を正とする。

- タグはユーザーが後から追加・削除できる表示用メタデータとし、素材の原本（`sha256`・`storageKey`・`kind`・寸法・長さ）とは独立に扱う。取り込み後の不変原則の例外は[ADR 0039](../adr/0039-asset-tags-mutable-metadata.md) に従う。
- タグは素材ライブラリ画面と素材ピッカーで付与・絞り込みできる。
- タグに階層・色・並び順は持たせない（フラットな文字列の集合）。

## データモデル

Assetはタグの配列を持つ。

```json
{
  "id": "ast_image_001",
  "tags": ["背景", "夏"]
}
```

- 保存は `Asset.tagsJson`（JSON文字列）。空配列は `NULL` として保存する。
- 読み書きは `packages/contracts` のZodスキーマで検証する。先頭・末尾の空白は除去し、空文字は除去し、重複は1つにまとめる。
- 1素材あたり最大30個、1タグ最大40文字。
- タグは作品に属さない素材属性であり、どの作品からも同じ素材のタグを共有する。

## 更新API

`PATCH /assets/:assetId` に `{ "tags": [...] }` を送り、タグ配列を丸ごと置き換える。存在しない素材は404 `RESOURCE_NOT_FOUND`、契約違反は422 `VALIDATION_ERROR` とする。

## 絞り込み

素材一覧はページングせず全件取得しているため、絞り込みはクライアント側で行う。複数のタグを選んだときは、いずれか1つ以上を持つ素材を表示する（OR）。ファイル名検索とは併用でき、両方を満たす素材を表示する。

## 非ゴール

- タグの階層化・色分け・並び順の保持。
- サーバー側でのタグ集計・タグ絞り込みクエリ（全件取得で足りるため）。
- 素材以外（作品・キャラクターなど）へのタグ付け。
