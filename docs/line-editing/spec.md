# セリフ操作・シーン分割・Cueのセリフ選択 仕様

## 目的と境界

要点Sceneのセリフを、番号で識別しながら並べ替え・複製・分割できるようにし、Cueのセリフ区間も番号だけでなく話者名と字幕先頭で選べるようにする。対象はインポート台本に限らず、すべての要点Sceneのセリフ。

内部参照は現在どおりLine IDのままとし、表示用の連番は保存しない。`ContentDocument`・HTTP API・DBスキーマは変更しないため、ADRは追加しない。この機能は未保存の編集フォーム上の操作と表示であり、保存のタイミングや正本のデータ構造を変えない。

関連: [../editor/spec.md](../editor/spec.md)（編集画面のテキストモデル・Cue）、[../mvp/content-schema.md](../mvp/content-schema.md)（台本契約）。

## 連番表示

各セリフカードの先頭に、表示専用の連番と要約を出す。書式は `番号. 話者名 — 字幕先頭`。

```text
3. レン — やっほー
```

- 話者未設定（`speakerId` が `null`、または話者名が空）なら `話者なし`。
- 字幕が空なら `（字幕なし）`。
- 連番はScene内の配列順で振り、保存しない。並べ替えや分割で自動的に振り直される。

## セリフ操作メニュー

`LinesEditor` の各セリフカードへ、アクセシブルな `…` メニューを追加する。常時操作ボタンは増やさず、このメニューへ集約する。

- 「上へ」「下へ」は同じScene内の隣接セリフと入れ替える。先頭行の「上へ」、末尾行の「下へ」は無効化する。
- 「このセリフの前でシーンを分割」は先頭行では表示しない。
- 「複製」は元のセリフの直後に、話者・字幕・読みを複製した新しいLineを追加する。Line IDは新規発行し、Audio Takeは複製しない（音声素材の重複参照と、誤った音声の再利用を避けるため）。選択済み音声も複製しない。
- 「削除」は既存の削除操作をメニューへ移したもの。Cueの表示区間がそのセリフを参照している場合の後始末は次節に従う。

上・下移動ではLine ID、話者、字幕、読み、Audio Take、選択済み音声をすべて保持し、配列順だけを変える。これによりTTSを再生成する必要はない。

## セリフ削除時のCueの後始末

削除するセリフを開始または終了に持つLine範囲Cueがある場合、削除前に件数を示して確認する。確定時は次を適用し、存在しないLine IDを参照する状態を作らない。

- 消えた端点が開始なら、残る範囲の先頭Lineへ開始を寄せる。
- 消えた端点が終了なら、残る範囲の末尾Lineへ終了を寄せる。
- 範囲が単一Lineで、そのLineを削除する場合は、そのCueを削除する。
- 参照していないLine範囲Cue、および `scene`／`offset` のCueは変更しない。

これにより、保存時に「同一Scene内のラインを指していません」で保存不能になる状態を避ける。

## シーン分割

「このセリフの前でシーンを分割」を選ぶと、選択したセリフを先頭に新しい `point` Sceneを、元Sceneの直後へ挿入する。

- 元Sceneは先頭側のセリフと既存Scene IDを保つ。
- 新Sceneだけに新しいScene IDを発行する。
- 後半へ移るセリフはLine ID・話者・字幕・読み・Audio Takeを保つ。
- 新Sceneは通常の要点Sceneの既定Cue（見出し・本文のテキストCue）を持つ。背景・立ち絵・見出し・本文の内容は空の状態から編集する。
- 新Sceneの切り替えは既定のカットとする。アイキャッチにしたい場合は、背景・カード・テキストCueと切り替え演出を利用者が設定する。
- 導入・結びは対象外。セリフが1件以下の要点Sceneでも分割できない。

### 既存Cueの扱い

分割でCue参照が壊れないよう、Cueの表示区間ごとに次を適用する。

| Cueの表示区間 | 分割時の扱い |
|---|---|
| `scene` / `offset` | 元Sceneに残す |
| `lines` が分割点より前だけを指す | 元Sceneに残す |
| `lines` が分割点より後だけを指す | 新Sceneへ移す。Cue IDは維持する |
| `lines` が分割点をまたぐ | 元Cueは前半へ縮め、新しいCue IDの複製を後半へ作る |

これにより、セリフに追随するCueは対象セリフとともに移動し、どちらのSceneにも存在しないLine IDを参照する状態を作らない。Scene全体の背景・立ち絵・見出しなどは、新Sceneへ自動コピーしない。

## Cueのセリフ直接選択

`CueList` の「開始」「終了」セレクトを、番号のみから `番号. 話者名 — 字幕先頭` の表示へ変更する。

- optionの値はLine IDのままにする。
- 開始の選択後、終了には開始セリフ以降だけを候補として出す。
- 開始を終了より後へ変えた場合は、終了を開始と同じLineへ補正する。
- 既存のLine範囲Cueを含む状態でセリフを上下移動した際、開始・終了が逆転したら、両端のLine IDを自動で入れ替えて有効な範囲に正規化する。
- セリフの移動によってCueが指す時間範囲は変わり得るため、保存前に通常のプレビューで確認できる。
- 長い字幕はセレクト内で省略し、選択中の開始・終了は近くに全文を表示する。

## 実装構成

- `apps/web/src/content/form.ts` に、分割・並べ替え後のCue範囲を正規化する副作用のない変換関数を置く（`moveLineInScene`・`normalizeLineRangeCues`・`splitPointScene`・`duplicateLineFormValue`・表示ラベル・候補制約の各関数）。
- `LinesEditor` にメニューと連番表示を追加し、Scene配列の挿入が必要な分割操作は親の `SceneEditor` へコールバックする。
- `CueList` にセリフ表示ラベルと、開始・終了の候補制約を追加する。

## 非ゴール

- 複数Sceneにまたがるセリフの一括移動、ドラッグ&ドロップ並べ替え。
- 連番の保存、Line IDの採番変更。
- `ContentDocument`・API・DBスキーマの変更。
