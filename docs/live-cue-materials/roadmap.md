# ライブCue単位の素材カード ロードマップ

[spec.md](./spec.md) を正とする。ここに書くものは約束された仕様ではなく、必要になった時点で個別に仕様化する。

## 今回の範囲

- `scriptCues[].materialId` によるCue単位の素材切り替え。
- Segment既定素材の継承と `null` による非表示。
- 1 Cue = 1 occurrence の検証。
- 本編を常に `script` フェーズにする整理。

## 別仕様へ移したもの

- CutIn（コーナー間の短い動画）は、素材カードの拡張ではなくSpine専用の `cut_in` セグメントとして [../live-media-playout/spec.md](../live-media-playout/spec.md) で仕様化した。

## 次に検討する候補

| 項目 | 内容 | 着手のトリガー |
| --- | --- | --- |
| 素材の先読み | 現在と次のCueの画像デコード・動画メタデータを先読みする | 切り替え時の空白が許容できなくなったとき |
| HTMLの読み込み失敗検出 | iframeの読み込み失敗を検出して中央を隠す | HTML素材で不良ファイルが問題になったとき |
| 素材エラーのコンソール通知 | ステージから素材エラーを送り、オペレーターへ通知する | 素材不良の切り分けを運用で行いたくなったとき |
| Web編集UI | Show ProfileのCue素材をGUIで編集する | JSON編集が負担になったとき |
| 生成レスの素材選択 | コメント応答や訂正キューに素材を指定する | コメントコーナーの演出を強化するとき |
