# エージェント新規作成の信頼性向上 ロードマップ

`docs/agent-new-work/spec.md`を正とする。本フォルダの候補は約束された仕様ではなく、順序と依存の共有である。実装時は本フォルダの`todo.md`と既存正（Agent Access・editor-core・TTS・ユーザーガイド）へ落とす。

## 方針

- 新規`work.create`完走を主線とし、同時編集は扱わない。
- 破壊的契約変更なし。`protocolVersion`据え置き、任意フィールド追加に留める。
- 可逆のみ。削除・公開・設定変更は人に残す。
- スキルは`schema.get`を正とし、契約複製をしない。

## 実施順序

P0 → P1（A） → P2（B） → P3 の順に進める。P1とP2は文書・技能中心で、契約変更が必要になったら立ち止まり別途ADR/版上げを検討する。

| フェーズ | 対象 | 依存 | 順序理由 |
| --- | --- | --- | --- |
| P0 | 現状再現・計測 | なし | 憶測で直さない。主線の停止点を安定コードで特定する |
| P1 | A. 止まり潰し | P0 | 完走への寄与が最大。非破壊に収まる |
| P2 | B. 検証前倒し | P1 | P1の上に乗る。作り直し削減 |
| P3 | 回帰・文書確定 | P1, P2 | 型検査・テスト・ガイド整合の締め |

## 残す拡張（今回扱わない）

- 版履歴一覧・Artifact列挙・素材バイト直読の開放。
- サムネイル/Theme/FaceSet/Voice読取の拡張。
- 削除系・外部公開・同時編集・実行中取消。
- 視覚確認の強化（renderなし確認・複数時刻一括）。

## 更新ルール

- 本フォルダの`spec.md`を正とし、`todo.md`は上から順に進める。
- 既存正（Agent Access・editor-core・TTS・ユーザーガイド）に触れたら同一変更で更新する。
- 破壊が必要になったら本計画を止め、ADRと版上げを先に議論する。
