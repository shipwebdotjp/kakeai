# 視覚確認（R3-4）ロードマップ

## 今回の決定（V1）

- render 成果物からの静止画抽出（`preview.frame`）を C1〜C5 で実装する。詳細は [spec.md](./spec.md)、実施項目は [todo.md](./todo.md) を参照。
- 輸送形式は [ADR 0078](../adr/0078-agent-preview-frame-image-transport.md) を正とする（原寸 PNG の base64、MCP は image ブロック追加、CLI は `--out`）。
- 完了条件: ソケット・MCP・CLI から指定時刻の原寸 PNG が取得でき、異常系が安定コードで返り、文書一式が更新されている。

## 変わらない原則

- エージェントは実体削除、外部公開、Adapter 設定の変更、TTS 以外の課金生成を行えない。
- `preview.frame` は版を追加せず Artifact も作らない読み取り操作である。
- 視覚品質の最終判断は人に残す。
