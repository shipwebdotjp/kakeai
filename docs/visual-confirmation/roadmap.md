# 視覚確認ロードマップ

## V1: render 成果物からの静止画（完了）

- render 成果物からの静止画抽出（`preview.frame`）を C1〜C5 で実装した。詳細は [spec.md](./spec.md)、実施項目は [todo.md](./todo.md) を参照。
- 輸送形式は [ADR 0078](../adr/0078-agent-preview-frame-image-transport.md) を正とする（原寸 PNG の base64、MCP は image ブロック追加、CLI は `--out`）。

## V2: レンダー前の視覚確認（実装済み）

| 項目 | 状態 |
| --- | --- |
| 保存版プレビュー（`preview.scriptFrame`） | 実装済み。保存版 ScriptVersion を headless でシークして PNG 化する |
| 素材プレビュー（`preview.assetFrame`） | 実装済み。画像は原本、動画は指定時刻の PNG、音声は対象外 |
| 下書きプレビュー | 未着手。エージェントの `script.edit` が保存を伴うため後回し |
| 複数時刻の一括取得・コンタクトシート | 未着手。単一フレームの利用実績を見てから検討 |
| 縮小・形式指定パラメータ | 未着手。V2 の利用実績を見てから検討 |

V2 の実測と判断は [spike.md](./spike.md) を正とする。1 フレーム 0.7〜1.0 秒、1920×1080 PNG 約300KB で通常は 10 秒に収まる。長尺・多数の動画素材に備え、画像プレビュー操作だけ read timeout を 30 秒にする。Job 化はしない。

## 変わらない原則

- エージェントは実体削除、外部公開、Adapter 設定の変更、TTS 以外の課金生成を行えない。
- `preview.*` は版を追加せず Artifact も作らない読み取り操作である。ラスタライズ用の一時ファイルだけを作る。
- プレビューは構図・重なり・欠落の確認用であり、最終的な色・動き・音の判断は人に残す。
