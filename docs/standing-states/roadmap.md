# セリフ境界の立ち絵状態 ロードマップ

仕様は [spec.md](spec.md)、実装の段階は [todo.md](todo.md) を正とする。

## 背景

シーン内で立ち絵の外観を変えるには、現在はSceneを分割するしかない。Sceneを分割すると見出し・本文・Cue・遷移まで増え、台本の見通しが悪くなる。一方、`VisualCue.range` は既にセリフ区間をサポートしており、コンパイラもCueの表示窓でバウンド・表情をクリップしている。不足しているのは、編集モデルと操作、外観ごとの標準配置である。

## 方針

- 正本は「シーン開始時状態＋セリフ境界の変更点」だけにする。各セリフの有効状態は保存せず、投影とレンダーで解決する。
- 外観の標準配置は `CharacterAppearance` に持たせる。状態は外観を選ぶだけで、配置を複製しない。
- 既存の `character.standing@1` Cueは開始時状態として残し、配置の明示値は上書きとして互換を保つ。`schemaVersion` は1のまま。
- レンダー時は状態を既存のCue区間へ展開し、テンプレートと描画ロジックを再利用する。

## 段階

1. 契約と操作コア（状態、外観配置、行・Scene構造操作）
2. レンダー（状態の区間展開、外観配置の解決）
3. API・Agent（ライブラリ外観、表情検証、操作公開）
4. Web UI（外観編集、状態一覧、セリフ表示、Cueマップ）
5. 文書と受入確認

## 非対象

- セリフ途中の切替、状態ごとの入場・退場、外観とは別の立ち絵プリセット。
- 3体目以降、自由座標。
