# セリフ境界の立ち絵状態 仕様

Status: Implemented

## 目的と境界

この文書は、同じSceneの中でセリフを切れ目に立ち絵の表示・非表示・外観を切り替える機能の正とする。外観ごとの標準配置（倍率・端・高さ）もここで扱う。台本の正本JSON契約は [../mvp/content-schema.md](../mvp/content-schema.md)、HTTP契約は [../mvp/api-contract.md](../mvp/api-contract.md)、立ち絵の左右配置と発話中バウンドは [../multi-standing/spec.md](../multi-standing/spec.md)、表情は [../face-expression/spec.md](../face-expression/spec.md) を正とする。決定は [ADR-0116](../adr/0116-standing-states-at-line-boundaries.md) と [ADR-0117](../adr/0117-standing-layout-on-appearance.md) を参照する。

- 立ち絵を変えるためだけにSceneを分割しない。Sceneは構図・背景・テロップの単位のままにする。
- 切替の粒度は**セリフの先頭**に限る。セリフ途中の秒指定やoffset区間の切替は持たない。
- 1 Sceneに左右1体ずつ、最大2体という制約は変えない。
- 状態は「誰のどの外観か」だけを持ち、倍率・端・高さは外観の標準配置から解決する。
- 状態の切替に個別の入場・退場は持たない。切替はカットで、Scene開始時の入場とScene終了時の退場は従来どおり開始時状態のCueが持つ。

## 用語とモデル

| 用語 | 定義 |
| --- | --- |
| Standing State（立ち絵状態） | 1つのsideについて、あるセリフの先頭から次の状態まで有効な「表示するキャラクターと外観」または非表示。 |
| Standing Layout（立ち絵配置） | 外観ごとの標準の倍率・端・高さ。`CharacterAppearance.standing` に持つ。 |
| Scene Opening State（シーン開始時状態） | 左右2枠で編集する、Scene開始時（最初のセリフより前）の立ち絵。従来の `range: scene` の `character.standing@1` Cueで表す。 |
| State Resolution（状態解決） | 開始時状態と変更点から、各セリフで有効な立ち絵状態を導くこと。保存はしない。 |

```text
Scene Opening State (left/right)
  └─ scene.standingStates[] (side, fromLineId, characterId, appearanceId)

CharacterAppearance
  └─ standing { scale, edge, vertical }

effective state at line N
  = last state for the side with lineIndex(fromLineId) <= index(N)
    ?? opening state for the side
    ?? none
```

## データ

### 立ち絵状態

`scene.standingStates` は任意の配列で、Sceneのセリフ境界ごとの変更点を表す。空または省略は「変更なし」で、開始時状態だけを使う。

```json
"standingStates": [
  {
    "side": "left",
    "fromLineId": "line-a3f-9c2",
    "characterId": "character-rin",
    "appearanceId": "appearance-rin-face"
  },
  {
    "side": "left",
    "fromLineId": "line-a3f-9c4",
    "characterId": null,
    "appearanceId": null
  }
]
```

- `side` は `left` / `right`。
- `fromLineId` は同じSceneのセリフID。状態はそのセリフの開始時点から有効になる。
- `characterId` と `appearanceId` は両方null（非表示）か、両方非null（表示）のいずれか。片方だけのnullは拒否する。
- 非nullの `appearanceId` は、`characterId` の外観に存在しなければならない。
- 同じ `(side, fromLineId)` は1件だけとする。
- 配列は行順に正規化して保存する。解決時は配列順ではなく、Scene内の行indexで並べる。行を移動しても状態は行IDに追従する。
- `insert` Sceneは `standingStates` を持てない。行を持たないSceneでは空にする。
- 状態は次の状態（同じside）の直前まで、またはScene末尾まで継続する。状態と状態の間に行が追加されても、新しい行は前の状態を引き継ぐ。

### 外観の標準配置

`CharacterAppearance` に任意の `standing` を追加する。ライブラリの外観と作品コピーの両方が持てる。

```json
"standing": { "scale": 1, "edge": "margin", "vertical": "standard" }
```

- `scale` は正の数。幅576px基準の倍率（既定 `1`）。
- `edge` は `tight` / `margin` / `center`（既定 `margin`）。
- `vertical` は `up` / `standard` / `down`（既定 `standard`）。
- 省略時は上記の既定値で解釈する。
- ライブラリの外観の標準配置は「ライブラリから追加」で作品コピーへ引き継ぎ、「ライブラリから更新」の差分にも含める。作品コピー側で変更すれば、その作品だけ調整できる。
- 同じ外観画像を同じ作品の複数箇所で違う配置にしたい場合は、外観を複製する。外観を複製すると `libraryAppearanceId` が重複するが、ライブラリ更新は同じ元を持つ外観をすべて差分に出す。頻繁に必要になった場合だけ、外観とは別の「立ち絵プリセット」を検討する。

### 開始時状態とCueの上書き

開始時状態は従来どおり、左右1体ずつ `character.standing@1` の `range: scene` Cueで保存する。入力は `characterId`・`appearanceId`・`side` を必須とし、`scale`・`edge`・`vertical` は任意の上書きとする。

- 新規保存では `scale`・`edge`・`vertical` を書かず、外観の `standing` を使う。
- 既存の保存済みCueは明示値を持っているため、それを上書きとして残す。これにより旧作品の見た目は変わらない。
- 解決は各項目について `Cueの値 ?? 外観のstanding ?? 既定値` とする。
- UIは開始時状態の解決後の値を読み取り表示し、明示値がある場合だけ「外観の標準に戻す」を出す。開始時状態の倍率・端・高さを直接編集する入力は置かない。
- 状態の変更点は `standingStates` だけを持ち、Cueの上書きを持たない。変更点の表示は常に外観の標準配置に従う。

## 状態解決と投影

正本は「開始時状態＋変更点」だけとし、各セリフで有効な状態は毎回導出する。解決結果をJSONへ書き戻さない。

- セリフ一覧: 各行に有効な状態を表示する。開始時と異なる行、非表示の行、外観が変わる行が一目で分かるようにする。変更点の行には「この行から」であることを示す。
- Cueマップ: 立ち絵レーンを変更点で分割し、各区間にキャラクター名と外観名を表示する。開始時状態だけのSceneは従来どおり1本の帯にする。
- 変更検知: `sceneNavProjection` に開始時状態と変更点の解決に必要な値を含める。
- シーク: 変更点は対象セリフの先頭へジャンプできるようにする。
- 警告: 外観・キャラクター・行が削除されて状態が解決できない場合、その行に警告を出す。

解決の規則:

1. sideごとに開始時状態を初期値にする。
2. そのsideの変更点を行indexの昇順に見て、対象行以前の最後の変更点を適用する。
3. 変更点が非表示なら、その区間は立ち絵を描かない。
4. 変更点がないsideは開始時状態をScene全体で使う。

## 表情との関係

`NarrationSegment.expressionId` の検証は、そのセリフで有効な立ち絵状態の外観に対して行う。

- セリフの話者キャラクターが、そのセリフで左右いずれかに表示されている場合、表示されているすべての外観の固定Face Setに `expressionId` が存在することを要求する。
- 表示されていない場合、または有効な状態がない場合は検証をスキップする。描画にも影響しない。既存の「話者に対応する立ち絵がSceneに無い場合、expressionIdは描画に影響しない」と同じ扱い。
- 外観がFace Setを参照しない場合に `expressionId` を指定したら、従来どおり保存を拒否する。
- 状態の変更で既存のセリフの表情が使えなくなる場合、保存時に該当行を列挙して拒否する。暗黙に `normal` へ置き換えない。UIは状態の追加時に影響するセリフを事前に示す。
- 非表示のセリフに `expressionId` が残っていても、描画されないだけで保存は拒否しない。

## 構造操作

- **行の追加**: 既存の状態の間に行が入った場合、その行は直前の状態を引き継ぐ。状態の追加は不要。
- **行の削除**: 状態の `fromLineId` が削除された行を指す場合、次の行へ移す。次の行が同じsideの状態を既に持つ場合は、移した状態を捨てて次の状態を優先する。次の行が無ければ状態を削除する。
- **行の分割**: 分割元の行IDは前半に残るため、その行を指す状態は前半と後半の両方に適用される。後半だけ別状態にしたい場合は、後半の先頭行に状態を追加する。
- **行の移動**: 状態は行IDに追従する。移動後の行順で解決し、保存時に配列を正規化する。
- **Scene分割**: 分割点で有効な状態を新しいSceneの開始時状態へ引き継ぐ。分割点以降の変更点は新しいSceneへ移す。分割点ちょうどの変更点が引き継いだ開始時状態と同じなら、重複する変更点は落とす。元のSceneに変更点が無い場合は、従来どおり開始時状態を新しいSceneへコピーしない（旧作品の分割挙動を変えない）。
- **Scene複製**: 既存の「前のシーンを複製」は行を持たないCueのみの複製なので、開始時状態も変更点もコピーしない。将来、行を含むScene複製を追加するときは、開始時状態と変更点をコピーし、変更点の `fromLineId` を複製先の新しい行IDへ付け替える。
- **キャラクター・外観の削除**: その外観を指す変更点を削除し、直前の状態へ戻す。削除後に有効な状態が変わる行に警告を出す。
- **開始時状態の解除**: 左右2枠のキャラクターを「未指定」に戻す。変更点は残る。

## 編集UI

- 立ち絵セクションは「シーン開始時」の左右2枠と「セリフごとの変更」の一覧で構成する。
- 変更一覧の各行は、対象セリフ、side、キャラクター、外観（または非表示）を選べる。同じsideと同じセリフの重複は作らせない。
- 外観の標準配置（倍率・端・高さ）は、キャラクターの外観編集で設定する。立ち絵セクションには解決後の値を表示する。
- セリフカードには有効な状態を読み取り表示する。変更点の行には「この行から変更」であることを示す。
- 変更点ごとの入場・退場は編集できない。切替はカット。

## 互換性

- `scene.standingStates` と `CharacterAppearance.standing` は任意項目の追加であり、`schemaVersion` は `1` のまま、テンプレート版も変えない。`caption` や `gapBeforeMs` と同じ加算的拡張として扱う。
- `character.standing@1` の `scale`・`edge`・`vertical` は任意化する。既存の値を持つCueはそのまま検証を通り、明示値として描画される。新規Cueは省略できる。
- 旧JSONは `standingStates` 無し＝変更なし、`standing` 無し＝既定配置として読める。保存済みJSONは書き換えず、次回保存で新しい `ScriptVersion` を作る。
- 新しいJSONを旧ビルドで開くことは保証しない。契約は `strictObject` のため、旧ビルドは未知の項目を拒否する。状態を黙って落として別の動画を出すより安全側に倒す（[ADR-0112](../adr/0112-pre-1.0-in-place-v1-api-updates.md)）。
- ライブラリの外観に `standing` を追加するとき、既存の外観は既定値で補う。DBの列追加時も既定値を入れる。

## 操作シナリオ契約

| 段階 | 入力と正本 | 機械可読な識別子 | 永続化・次に読む主体 | 停止・失敗時 | 不可逆操作 |
| --- | --- | --- | --- | --- | --- |
| 外観の標準配置 | 外観編集の倍率・端・高さ | `appearanceId` | ライブラリまたは作品コピーの外観 | 不正な倍率・enumは保存しない | DB書込み |
| 状態の保存 | side、対象セリフ、キャラクター、外観 | `fromLineId` | `Scene.standingStates` | 行・キャラクター・外観が無い、片方null、重複は保存しない | DB書込み（新規 `ScriptVersion`） |
| 状態の解決 | 開始時状態、変更点、行順 | `sceneId`、`lineId`、`side` | セリフ一覧・Cueマップ・レンダラー | 解決不能な状態は警告し、その区間を描かない | なし |
| レンダリング | 解決済みの状態、外観の標準配置 | `lineId`、`appearanceId` | 出力動画 | 参照欠落は出力を開始せず失敗する | 出力メディアの保存 |
| Scene分割 | 分割点の有効状態、以降の変更点 | `sceneId`、`lineId` | 新しいSceneの開始時状態と変更点 | 分割点を解決できなければ分割しない | DB書込み（新規 `ScriptVersion`） |

## 受入条件

1. 同じScene内で、セリフ2行目から別の外観、5行目から非表示、7行目から再表示にでき、Sceneを分割しない。
2. 開始時状態だけのSceneは、従来と同じ見た目・同じ帯・同じ分割挙動になる。
3. 外観ごとに倍率・端・高さを設定でき、セリフごとに外観を切り替えると、その外観の標準配置で描画される。
4. 既存のCueが持つ倍率・端・高さの明示値は上書きとして残り、旧作品の見た目が変わらない。
5. セリフ一覧とCueマップの両方で、各行の有効な立ち絵状態と変更点が分かる。
6. 状態の変更で使えなくなる表情がある場合、保存前に該当行が示される。
7. 行の追加・削除・移動、Scene分割の後も、状態の行参照が壊れない。Scene分割では分割点の有効状態が新しいSceneへ引き継がれる。
8. 旧JSONはそのまま読め、`schemaVersion` は1のままである。
9. Agent Accessの `standing.state.upsert` / `standing.state.remove` で同じ状態を編集できる。

## v1の対象外

- セリフ途中（秒単位）の状態切替、offset区間の状態。
- 状態ごとの入場・退場、クロスフェード。
- 3体目以降の立ち絵、自由座標。
- 外観とは別の「立ち絵プリセット」実体。
- 状態ごとの倍率・端・高さの上書き（外観の標準配置で足りない場合に再検討する）。
- AIによる状態の自動生成。
