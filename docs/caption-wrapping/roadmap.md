# 字幕の均等自動折り返しロードマップ

[spec.md](./spec.md) の実装後に検討する拡張候補を整理する。この文書は約束された仕様ではない。採用するときは、対象を `spec.md` と `todo.md` に落とす。

## 実装順序

| フェーズ | 対象 | 依存 | 順序の理由 |
| --- | --- | --- | --- |
| P1 | 禁則と候補選択 | なし | 幅測定やHTMLを加える前に、分割ルールを決定的にする |
| P2 | 実幅測定・コンパイラ | P1 | テーマとフォントに沿った均等化を実現する |
| P3 | プレビュー・レンダー同期 | P2 | 改行確定前のキャプチャを防ぐ |
| P4 | 警告・文書・ガイド | P1–P3 | 実際の表示責務を確定してから案内を固定する |

## 拡張候補

| 項目 | 内容 | 採用条件 |
| --- | --- | --- |
| テーマごとの字幕折り返し設定 | 1行しきい値、優先行数、禁則プリセットをテーマで選べるようにする | 番組・チャンネルごとに字幕密度を変えたい要求が繰り返し出た場合 |
| locale ごとの禁則セット | 日本語以外の組版規則を明示的に追加する | 日本語以外で字幕の改行品質が実用上問題になった場合 |
| 3行の均等化の調整 | 縦型の長文で、2行から3行への増加条件や均等性を最適化する | 縦型長文での警告や見栄えを実レンダーで検証した後 |
| 編集画面での焼き込み結果の可視化 | textareaの原文を変えず、想定改行だけを補助表示する | 利用者がプレビューを開かずに結果を確認したい場合 |
| 話速を考慮した行数 | 表示時間が短い字幕では、文字数だけでなく読了時間も警告する | 読み切れない字幕が品質課題として観測された場合 |

## 見送り

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| 自動改行を `captionText` に保存 | 見送り | 正本の台本、SRT、焼き込み表示の責務が混ざり、テーマ変更で保存値が古くなる |
| SRT へ焼き込み用の自動改行を反映 | 見送り | 配信先プレイヤーの幅とフォントが異なり、焼き込み用の組版を移植できない |
| CSS のみで均等化する | 見送り | 1行に収まる29〜38文字相当を確実に2行にする規則と、禁則の決定性を保証できない |
| 文字数だけで分割位置を決める | 見送り | テーマのフォント、英数字、句読点で実際の行幅が大きくずれる |
