# 字幕の均等自動折り返し仕様

## 目的

焼き込み字幕を、単に表示可能幅を超えたときだけ折り返すのではなく、読みやすい長さから2行を選び、各行の見た目の幅ができるだけ均等になる位置で自動折り返しする。日本語の禁則処理を守り、字幕の正本である `NarrationSegment.captionText` は変更しない。

この文書は字幕の焼き込み表示の正とする。字幕本文・タイミング・SRT の正は引き続き [../mvp/content-schema.md](../mvp/content-schema.md) と [../subtitle-export/spec.md](../subtitle-export/spec.md) とする。

## 用語

- **明示改行**: `captionText` に利用者が入力した LF（CRLF / CR は LF として扱う）。自動折り返しより常に優先する。
- **幅単位**: 既存の `textWidthUnits` と同じ全半角換算。全角文字は2、ASCII・半角カナは1、結合文字・制御文字は0と数える。全角1文字相当は2単位とする。
- **自動改行**: コンパイラが焼き込み用 HTML にだけ挿入する改行。`captionText`、保存済み ScriptVersion、SRT には保存しない。
- **候補境界**: 2つの書記素クラスタの間にある、自動改行できる位置。明示改行は候補ではなく固定境界である。
- **禁則境界**: 行頭禁則または行末禁則を生むため、自動改行の候補から除外する境界。

## 1. 対象と非対象

- 対象はコンパイラ固定層の `.kakeai-captiontext` だけである。`text.block@1`、テンプレート内の本文、サムネイル、エディタの textarea は対象外とする。
- `captionText` の正本値、行の ID・タイミング・話者名タブ、テーマの文字設定は変えない。
- SRT は従来どおり正本の `captionText` から生成する。焼き込み用の自動改行を SRT に持ち込まない。
- 明示改行、空白、HTML エスケープの既存の安全性を保つ。利用者入力を HTML として解釈しない。
- 字幕のためにフォントサイズを黙って縮小、文字を省略、または切り詰めない。収まらない場合は既存どおり警告とプレビュー確認で扱う。

## 2. 行数を選ぶ規則

まず各明示改行で区切られた段落について、幅単位で1行・2行を選ぶ。段落をまたいで行を再配分しない。

| Output Profile | 1行に保つ上限 | 上限超過時の優先行数 | 物理的な1行幅の目安 |
| --- | ---: | ---: | ---: |
| `landscape` | 全角28文字相当（56単位） | 2行 | 全角38文字相当 |
| `portrait` | 全角22文字相当（44単位） | 2行 | 全角22文字相当 |

- 上限以下で、表示可能幅にも収まる段落は1行のままとする。
- 上限を超える段落は、表示可能幅に収まるなら2行へ自動改行する。よって横型では、従来1行に収まっていた全角29〜38文字相当の字幕も2行になる。
- `portrait` の物理的な1行幅は全角22文字相当であるため、横型の28文字基準を持ち込まない。23文字相当から2行にする。
- 2行で収まらない長文は、既存の出力形式別の許容行数まで増やしてよい（横型2行、縦型3行）。許容行数を超える場合も描画は試みるが、警告を返す。
- 明示改行の合計で許容行数を超える場合も、入力を改変せず既存と同様に警告する。

## 3. 分割位置の選択

### 3.1 幅の測定

分割候補の比較には、テーマ・locale 解決後の字幕フォント、font size、font weight、letter spacing を適用した実描画幅を使う。幅単位は第2節の「1行か2行か」の入り口判定および警告の目安であり、候補間の均等性を文字数だけで判定してはならない。

フォント読み込み完了後に、レンダー HTML 内の非表示測定要素で各候補の幅を測る。同じ処理を Web プレビュー、PNG プレビュー、MP4 レンダーで実行する。測定と改行の確定が済むまで、プレビュー・レンダーの ready 状態にしてはならない。

### 3.2 最適化

選択した行数で、次の順序により最良の候補境界を選ぶ。

1. すべての行が表示可能幅以内である候補だけを残す。
2. 行幅の最大値と最小値の差が最小の候補を選ぶ。
3. 同点なら最大行幅が小さい候補を選ぶ。
4. それも同じなら、前の行が後ろの行より長くなりすぎない候補、さらに先に現れる境界を選び、結果を決定的にする。

候補がないときは、禁則を破る改行を挿入しない。改行なしで表示して既存のはみ出し警告に委ねる。

### 3.3 日本語・欧文の境界

- 書記素クラスタを途中で分割しない。結合文字、絵文字のZWJ列、異体字セレクタを壊さない。
- 行頭禁則: 句読点、閉じ括弧・閉じ引用符、終端記号、長音記号、小書き仮名などを行頭にしない。
- 行末禁則: 開き括弧・開き引用符を行末にしない。
- Latin 文字・数字から成る連続語は原則として途中で分割しない。空白・ハイフン等の自然な語境界を候補とする。
- 禁則文字集合は `packages/video` の1か所に定義する。CSS の UA 差分だけに委ねない。
- 禁則を満たす候補が存在しない長い語や URL は、任意位置で切らない。はみ出し警告により台本の修正を促す。

## 4. HTML/CSS とレンダーの契約

- コンパイラは元の字幕を安全にテキストとして出力し、折り返し処理はその要素の子ノードだけを書き換える。挿入する改行は `<br>` であり、入力由来のタグは作らない。
- `.kakeai-captiontext` は明示改行と確定した自動改行を表示できるスタイルにする。補助的に `line-break: strict` と通常の単語分割規則を指定するが、確定した自動改行の可否は第3節で決める。
- レンダー・静止画プレビューは `document.fonts.ready` 後に改行を確定し、`data-kakeai-caption-wrap-ready` の完了を待つ。改行前の1フレームをキャプチャしてはならない。
- 改行処理は時間に依存せず、同じ HTML・フォント・Chromium では同じ DOM を生成する。timeline と clip の開始・終了には影響しない。
- 字幕セーフエリアは、現在の許容最大行数を引き続き予約する。2行を優先するようになっても、縦型の3行許容と既存のセーフエリアは狭めない。

## 5. 警告と編集体験

- `meta.warnings` は、表示可能な最大行数を超える入力を従来どおり `text_overflow` として返す。
- 警告の見積もりは幅単位で行う。横型の実効1行表示しきい値を28文字相当へ変更しても、最大行数の収容目安（横型38×2、縦型22×3）は維持する。
- 編集画面の入力値には自動改行を書き戻さない。利用者が入力した改行だけを表示・保存する。
- ユーザーガイドには、短文は1行、上限超過時は焼き込み表示だけが均等な複数行になり、SRT と入力本文は変わらないことを記載する。

## 6. 互換性

- 既存 ScriptVersion の JSON スキーマ、HTTP API、Agent 操作、DB マイグレーションは変更しない。
- 同じ既存台本を新実装で再レンダーすると、横型の29〜38文字相当の字幕を中心に焼き込み画像が変わりうる。既に生成済みの Artifact は不変で、再生成しない。
- テーマで字幕フォント、サイズ、字間を変えた場合は、そのテーマで測定し直して最適な境界を選ぶ。

## 7. 受け入れ条件

- 横型で全角28文字相当以下の字幕は、表示幅に収まる限り1行である。
- 横型で全角29〜38文字相当の和文字幕は、禁則を守る、幅差が最小の2行になる。
- 縦型で全角23文字相当の和文字幕は、禁則を守る2行になる。
- 句読点・閉じ括弧などが自動行頭に、開き括弧・開き引用符などが自動行末にならない。
- 明示改行、SRT 出力、台本JSON、字幕タイミングは変更されない。
- フォントの読み込みを待った後のプレビュー PNG と MP4 に、確定済みの改行が反映される。
