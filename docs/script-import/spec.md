# 章立て台本の一括インポート 仕様

## 目的と境界

外部で書いた章立ての台本を編集画面へ貼り付け、確定前のプレビューで「台本中の話者名 → 既存の話者」の対応を話者名ごとに一度だけ指定して、各章を要点Scene、各セリフ行をセリフとしてフォームへ一括反映する。

これは未保存の編集フォームを更新するだけの編集支援であり、インポートした時点では保存・TTS生成・API呼び出しを行わない。利用者が「保存」を押した時点で、既存どおり新しい Script Version になる。

正本（`ContentDocument`・HTTP API・DBスキーマ）は変更しない。インポートはWebフォーム上の操作であり、正本のデータ構造を増やさない。この決定は正本JSONや永続的なアーキテクチャを変えないため、ADRは追加しない。

## インポート書式

```text
## 第一章
リン:こんにちは
レン:やっほー

## 第二章
レン:あわわ・・・
```

確定するルールは次。

- 行頭・行末の空白を除去した行が `##` で始まる場合、その行を章見出しとして扱う。見出しテキストは `##` の後ろを除去後の文字列とする。
- `話者名:` と `話者名：`（半角・全角コロン）をセリフとして扱い、最初の区切り記号だけで分割する。話者名とセリフ本文はそれぞれ空白を除去する。
- 空行は無視する。
- 1物理行を1セリフ、すなわち1字幕・1TTS生成単位とする。
- 見出しは、生成する要点Sceneの `label`（編集用名称）へ設定する。`heading` テキストCueの `text` は変更しない。
- セリフの `captionText` と `speechText` は同じ文で作成し、音声（`selectedAudioTakeId`・Audio Take）は未設定にする。
- 話者の新規作成は行わない。未登録の話者は既存話者へ割り当てるか、明示的に「話者なし」を選ぶ。

次の入力はエラーにし、取り込み確定をできなくする。

- 見出しより前のセリフ。
- 空の見出し（`##` のみ、または `##` の後が空白のみ）。
- 空の話者名（区切り記号より前が空白のみ）。
- 空のセリフ（区切り記号より後が空白のみ）。
- 書式に合わない非空行（見出しでも `話者名:` でもない行）。
- 1章にセリフがない場合。空の要点Sceneを無意識に増やさないため。
- 章見出しが1つもない場合。

## 画面フロー

編集画面の要点シーン操作付近に「台本をインポート」を追加する。

1. 貼り付け用のテキストエリアへ台本を入力する。
2. 構文解析結果として、章数・セリフ数・検出した固有話者名・エラーを行番号付きで表示する。
3. 検出した固有話者名ごとに一行だけ対応付けを表示する。同じ話者名が何回出ても対応付けは1件に集約する。
   - 名前が完全一致する既存話者が1人だけなら初期選択する。
   - 候補がない・同名候補が複数ある場合は未選択にし、利用者が選ぶまで確定不可にする。
   - 「話者なし」を選ぶと、その話者名のセリフは話者未設定（字幕のみ）になる。
4. 反映先を選択する。
   - 既存の要点Sceneを置き換える（既定）。
   - 既存の要点Sceneの末尾へ追加する。
   - 置き換えでも、導入・結び・作品内キャラクター・BGM・素材・既存の話者設定は維持する。置き換えで消えるのは未保存フォーム上の要点Sceneだけであり、保存済みの版は明示保存まで変わらないことを確認画面で明示する。
5. 「反映」で章数分の `point` Sceneとセリフを一括生成し、通常の編集状態に戻る。以後は個別に読みや話者、Cue、立ち絵などを編集できる。

## 反映規則

- 章ごとに `createPointSceneFormValue` で要点Sceneを作り、章見出しを `scene.label` に設定する。通常のpoint Sceneにある空の `heading` / `body` Cueはそのまま残す。
- セリフは `createEmptyLine` で作り、`captionText`・`speechText` に同じ本文を入れ、話者対応表のID（「話者なし」は `null`）を `speakerId` に設定する。
- IDは既存の生成関数（`newSceneId`・`newLineId`・`newVisualCueId`）で発行し、Scene・Cue・Lineで一意にする。既存のCue既定値・ID不変条件に従う。
- 話者候補は、作品内キャラクターに紐づく話者と、声だけの話者の両方から作る。取り込み後のセリフは話者IDを持つため、現在のTTSフローをそのまま利用できる。
- 置き換え時は、既存の要点Sceneだけを取り除き、最初の要点Sceneがあった位置（なければ結びの直前）へ生成したScene群を差し込む。
- 追加時は、最後の要点Sceneの直後（なければ結びの直前）へ生成したScene群を差し込む。

## 非ゴール

- 複数行の同一セリフ、ファイル読込、CSV/JSONの取り込み。
- キャラクター・話者の自動作成。
- 正本JSON・HTTP API・DBスキーマの変更、保存の自動化。
