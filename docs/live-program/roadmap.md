# ライブプログラム台本 ロードマップ

[spec.md](./spec.md) を正とする。この文書は、実装の順番、依存関係、将来の拡張を整理する。ここに書いたものは約束された仕様ではなく、必要になった時点で個別に仕様化する。

## 方針

- ライブの内容はLive Programが所有し、動画用Workとは分離する。
- 見た目はテーマトークンで揃え、レンダラーはライブ専用に持つ。
- カードは型付き状態スナップショットとし、自由HTML/JSを実行しない。
- 実行時はパッケージだけを読み、KakeaiのDBに依存しない。
- まず「1本のライブ台本をGUIで作り、版を確定し、パッケージで配信する」を安定させる。

## 依存関係

```text
P0 契約
 ├─ P1 永続化・API ── P3 エディタGUI ─┐
 ├─ P2 カードレンダラー ──────────────┼─ P5 実行系 ── P6 起動・運用 ── P7 移行
 └─ P4 パッケージv2 ──────────────────┘
```

P2はP1と独立して進められる。P4はP1のプログラム版とP2のカード契約に依存する。P3のプレビューはP2を必要とする。

## 主なリスク

- **二つのエディタのドリフト**: 動画とライブで見た目が離れる。テーマトークンとビジュアルガイドで揃える。
- **状態モデルの複雑化**: Cue内の時間同期や自由なキーフレームを足すと、タイムライン編集に近づく。最初はCue単位の状態変更に限定する。
- **カード型の増加**: 何でもカードにすると、エディタとレンダラーが肥大化する。5型を基本にし、追加は利用実績で判断する。
- **素材の二重管理**: Work Sceneの取り込みとネイティブカードが併存する。取り込みは一度だけのスナップショットとし、参照を保持しない。
- **実行系の肥大化**: カードレンダラーを `apps/live` に持ち込むと、配信プロセスが重くなる。`@kakeai/video` に依存させない。
- **パッケージ互換性**: v2のカードスキーマ版とライブアプリの対応を検証する。未知の型は読み込み時に拒否する。
- **解決スナップショットの肥大化**: Theme、キャラクター、声、音声、CutIn、Live Materialのハッシュを版ごとに固定すると、保存量と確定処理が増える。ハッシュと参照だけを保存し、実体はAsset/Theme側に置く。
- **再buildの扱い**: 同じ版から再書き出しすると見た目が変わり得る。package buildを明示し、Runがどのbuildを使ったかを必ず記録する。
- **起動制御の複雑化**: health/control endpoint、control token、PID、再接続を足すと、Kakeaiとライブアプリの境界が増える。loopback限定・自動復元なしを維持する。
- **旧経路の残存**: Show Profile、旧CLI、v1パッケージは P7 で削除済み。互換読み込みを再導入せず、必要なら版付きの新しい契約として追加する。

## 将来の候補

### 発話に合わせた項目表示

- Cue内の文・単語のタイミングで、リスト項目やグラフの系列を順に出す。
- TTSのタイミング情報、または文分割と推定尺が必要。
- 全体タイムラインやシークは持たず、Cue開始からの経過時間で演出する。
- 失敗してもカードは最終状態を表示し、発話を止めない。

### ライブデータ連携

- 株価、投票、実況、コメント数などの外部データでカード内容を更新する。
- 書き出し時の固定データと、実行時の更新データを分ける。
- データ取得失敗時のフォールバックと、更新頻度の上限を定める。

### フォーマットの差分適用

- フォーマットの変更を、既存プログラムへ明示的に適用する。
- セグメント、キャスト、ポリシー、カード型の差分を表示し、選択して適用する。
- 自動反映はしない。

### Live Materialの編集

- Work Sceneから取り込んだカードを、ライブ側で本文・グラフデータ・画像を編集する。
- 元のWork Sceneとの対応は来歴としてだけ保持する。
- 再取り込みと、ライブ側での編集のどちらを正にするかを画面で明示する。

### カード型の拡張

- タイムテーブル、プロフィール、比較表、地図、QRコードなど。
- 追加するときは、型付きスキーマ、レンダラー、アニメーション、パッケージ検証を同じ変更で揃える。

## 現行でやらないこと

- Cue内の時間同期
- 自由なキーフレーム編集
- 任意のHTML/JavaScriptの実行
- 動画用Visual Templateのレンダラー共有
- ライブ中の外部データによる自動更新
- 複数解像度・縦型ステージ
- YouTubeの配信作成・開始・チャット投稿
