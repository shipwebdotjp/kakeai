# チャットテンプレート ロードマップ

正は [spec.md](spec.md)。`@1` はここに挙げる拡張を、既存入力の意味・レイアウト・検証結果を変えない限り加算的に取り込める（[ADR-0061](../adr/0061-template-version-as-reinterpretation-boundary.md)）。

## 次の候補

- **Cue Map への反映**: メッセージのアイコンを Cue の代表画像として Cue Map に表示する。
- **本文の書式**: 太字・リンク風の強調など、限られた範囲の書式を有限の語彙で表す。
- **字幕セーフエリアの残り枠への適用**: `laptop` はキーボードベースを含めた寸法の再フィット、`none` は全画面の扱いを決めたうえで、同じ `--kakeai-caption-safe` を適用する。
- **`scene.device-frame@1` のスマートフォン枠**: 画面に字幕が重なるため、同じ予約領域を適用するか、端末を小さくするかを決める。

## 別設計として扱うもの

- **会話の読み上げ・字幕・TTS 連動**: チャットを `lines` / `speakers` から派生させる設計であり、この VisualTemplate の入力とは混ぜない。会話を喋らせる要求が出た時点で、台本側の別機能として検討する。
- **任意テンプレートの入れ子編集**: `scene.device-frame@1` の画面に任意の VisualTemplate を入れ子で置いて編集するには、エディタの `nestedTemplate` 対応が必要。今は非破壊に保持するだけで編集できないため、チャットは自前の枠を持つ。
