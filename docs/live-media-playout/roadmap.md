# ライブのメディア挿入（CutIn）ロードマップ

[spec.md](./spec.md) を正とする。ここに書くものは約束された仕様ではなく、必要になった時点で個別に仕様化する。

## 今回の範囲

- `cutIns[]` と `cut_in` セグメントによる、全画面の短い動画の挿入。
- 音声あり・音声なしのCutIn。programだけが音声を再生し、previewはミュート。
- 書き出し時のMP4正規化とprobe結果を正本にした尺。
- `StageState.cutIn`、`cut_in` フェーズ、専用イベント、watchdog、再接続のseek。
- pauseは先頭から再開、専用スキップ、安全モードでのスキップ。
- コンソールのCutIn名表示と専用スキップ。
- 素材カードの無音検証を維持したまま、CutInだけ別のパッケージ種別にする。

## 次に検討する候補

| 項目 | 内容 | 着手のトリガー |
| --- | --- | --- |
| BGM・効果音 | コーナー切り替え、オープニング、エンディングのBGMと効果音 | CutInだけでは間が持たない、または演出の要望が出たとき |
| スポンサー告知 | スポンサーのロゴ・読み上げ・表示区間をCutInとして管理する | スポンサー枠の運用が始まるとき |
| オープニング映像 | オープニングの短い映像をCutInとして再生する | 毎回のオープニングを固定したいとき |
| 1つのCutInに複数動画 | 複数の短い動画をつないで1つの区切りにする | ジングルと告知を連結したいとき |
| トランジション | CutInの前後にフェード、ワイプ、ディゾルブを入れる | ハードカットが唐突に感じられるとき |
| CutInの先読み | 次のCutInのメタデータ・映像を先に読み込む | 切り替え時の空白が許容できなくなったとき |
| CutInの音量・ダッキング | CutInの音量、BGMとのダッキング、フェード | BGMを導入するとき |
| CutInのトリム・ループ | 動画の使用区間、ループ、速度変更 | 長い素材の一部だけを使いたいとき |
| Web編集UI | Show ProfileのCutInをGUIで選ぶ | JSON編集が負担になったとき |
| auto-profileのCutIn候補 | コメントコーナーの前などにCutInの下書きを入れる | 定型的な番組構成が固まったとき |
| CutInのHTML・PNG | 動画以外の全画面素材をCutInとして扱う | 静止画のバンパーが必要になったとき |
| CutInのログ分析 | 再生時間、スキップ、失敗率を集計する | 番組の改善にCutInの効果を見たいとき |

## 非目標

- CutInをMaterial Cardの拡張として扱うこと。
- CutInを通常のLive Cueの再生契約に混ぜること。
- CutInをCompositionのタイムラインやHyperFrames Playerで動かすこと。
- 視聴者コメントや外部HTMLをCutInとして実行すること。
