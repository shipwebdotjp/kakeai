# Cue対応マップ仕様

## 目的と境界

編集画面の左ペイン「構成」を、Scene・Cue・セリフの階層ツリーから、動画全体を連続して見渡せる **Cue対応マップ** へ置き換える。Cue対応マップは、セリフの順序と、その区間に表示される Visual Cue の対応・重なりを素早く確認し、編集箇所とプレビューへ移動するためのナビゲーション表示である。

- 縦軸は実時間ではなく、Scene と Narration Segment の**編集上の順序**とする。セリフの尺に比例させない。
- Cue の開始・終了をドラッグして編集しない。既存の Cue 編集カードにある表示区間入力を唯一の編集手段として維持する。
- Cue対応マップは、フォームの未保存状態から導く表示であり、`ContentDocument`、HTTP API、DB、Script Version、レイアウト設定を変更・永続化しない。
- 既存の左ペインのジャンプ、中央ペインの編集、右ペインのプレビュー操作を置き換えずに接続する。

関連: [../editor/spec.md](../editor/spec.md)（3ペインとジャンプ）、[../line-editing/spec.md](../line-editing/spec.md)（CueのLine範囲）、[../preview-workflow/spec.md](../preview-workflow/spec.md)（解決タイムライン）、[../editor-ux/spec.md](../editor-ux/spec.md)（ペイン幅と狭幅モード）。

## 連続するScene軸

左ペインは、すべてのSceneを一つの縦方向の地図として、余白で分断せずに上から順に並べる。

- 最左に細い **Sceneレール** を置く。各Sceneのレールは、そのSceneが占めるマップ上の高さだけ連続し、種別（導入／要点／結び）とScene Labelを縦書きで表示する。Sceneレールのクリックは中央ペインのScene見出しとプレビューのScene先頭へジャンプする。
- Scene境界は1本の区切り線で示す。カード、独立した見出し行、大きな余白は設けない。
- Narration Segment の行は、Scene内の順序とセリフ先頭を表示する。要点Sceneの行番号は、全体地図で位置を識別できる `要点序数.セリフ序数`（例: `4.1`）とする。これは表示専用で、既存のScene内連番・Line ID・保存内容を変えない。
- セリフのないSceneは、通常のセリフ行と同じ高さの最小3行ぶんの **Sceneブロック** を持つ。これにより導入・結びも、Scene全体のCueとともに地図上で確認・ジャンプできる。

## Cueレーン

セリフ本文の右端からペイン右端までをCueレーン領域とする。Cueは縦方向の帯で表示し、表示範囲に含まれるセリフ行またはSceneブロックを貫く。レーン領域はペイン右端に寄せ、セリフ本文の上に重ねて描く。

```text
Scene     セリフ                              前景 ←       → 背景
要点 1    1.1 セリフ……                       [見出し][カード][背景動画]
          1.2 セリフ……                               [カード][背景動画]
          1.3 セリフ……                       [画像]          [背景動画]
要点 2    2.1 セリフ……                       [画像]          [背景動画]
```

- 右端は描画順で最も奥、左へ行くほど前面とする。Cueは `Layer` の固定順（`background`、`card`、`standing`、`overlay`）と同一Layer内の `order` で並べ、プレビューと異なる前後関係を表示しない。レーンはペイン右端を基準に配置し、前面の帯ほど左、奥の帯ほど右に置く。
- 帯は半透明で、下のセリフ本文を隠さない。セリフ本文は右端まで伸びて帯と重なってよい。
- 同時に重ならないCueは、同一レーンを再利用する。同時に重なるCueだけ、より前面のCueを左の別レーンへ積む。レーンの位置が描画順を意味するのは、同時に表示されるCueの間だけである。
- `scene` 範囲のCueはSceneブロック全体、`lines` 範囲のCueは開始Lineから終了Lineまでを帯にする。`offset` 範囲は、表示中プレビューの解決済みScene・Line区間とCueの入力msから交差する行へ帯を置く。解決済みタイムラインが未取得・未反映・エラーの場合、`offset` Cueは対応するSceneレール上の「時間指定」マーカーとして残し、推測による帯は描かない。
- 各帯の先頭にはテンプレート種別を表すマーカーを置く。視覚素材を参照するCueは、テンプレート入力の順で最初の画像または動画を代表素材とし、利用可能なら小さなサムネイルを表示する。代表素材がない、またはサムネイルを取得できない場合は種別アイコンとLayer色を使う。
- 帯をポインタでホバーまたはキーボードでフォーカスすると、Cueのテンプレート名、Layer、順序、表示区間、代表素材の拡大プレビュー、および追加の参照素材一覧を表示する。帯はアクセシブルなボタンとし、クリックまたはEnter/Spaceで中央ペインのCueカードへスクロールし、プレビューをCue開始へ移動する。
- セリフ行のクリックまたはEnter/Spaceは、従来どおり中央ペインのセリフカードとプレビューの当該セリフへ移動する。

## 幅と過密時の扱い

左ペインの幅は既存の192〜360pxの範囲を守る。Cueレーンは情報量が増えてもセリフ本文自体を消さない（帯は半透明で本文の上に重ねる）。

- 通常のCueレーン幅は30pxとする。帯の先頭マーカーはこの幅に収め、拡大素材はポップオーバーで確認する。
- レーン領域はセリフ本文の右側に重ね、本文は右端まで伸ばせる。本文の全文は既存のセリフ編集カードで確認できる。
- 表示可能レーン数はペインの現在幅から算出し、最大6本とする。目安としてペイン幅288pxで6本、256pxで5本、最小の192pxで2本。ペインを広げると表示レーンも増やす。
- 必要レーン数が表示可能数を超えたときは、右端側に1本の集約レーンを置き、収まらないCueを `+N` として示す。集約レーンへのホバーまたはフォーカスで、対象Cueを描画順・表示区間・代表素材付きで列挙する。対象Cueの選択は通常のCue帯と同じジャンプを行う。
- 現在のプレビュー時刻または中央ペインの現在対象に対応するCueが集約されている場合、そのCueを一時的に可視レーンへ昇格し、同数の非対象Cueを集約する。現在確認している素材を隠さない。

## 同期と状態

- Cue対応マップは、フォーム値のScene順・Line順・Cue設定・立ち絵を即時に反映する。セリフ追加、削除、並べ替え、Scene分割、Cue追加、削除、表示区間変更、Layerまたは順序変更、立ち絵のキャラクター・外観変更により再計算する。
- `scene` と `lines` の帯配置はフォームの範囲参照だけから導く。`offset` Cueの行対応、再生位置のハイライト、Scene境界の時間的な状態判定には、表示中の保存済みまたはドラフト・プレビューが返す解決済みタイムラインだけを使う。Web側でタイミング解決器を再実装しない。
- 右ペインの再生中は、現在時刻を含むセリフ行・Sceneレール・有効なCue帯をハイライトする。停止中は、中央ペインのスクロールまたは最後の左ペイン操作で現在対象になったScene、Cue、セリフをハイライトする。
- 画面幅1280px未満では、既存の構成ドロワー内に同じCue対応マップを表示する。ジャンプ後は既存の規則どおり編集表示へ戻し、ドロワーを閉じる。

## 非ゴール

- 秒目盛り、実尺に比例する帯、波形、フレーム単位の編集を持つ動画編集タイムライン。
- Cueのドラッグ移動、ドラッグによる範囲変更、Layerまたは`order`のドラッグ並べ替え。
- Cue対応マップの表示設定・展開状態を作品データまたはブラウザ設定へ保存すること。
- 正本JSON、プレビューDTO、HTTP API、DB、VisualTemplate入力契約の変更。

## 受け入れ条件

- 左ペインで、全Sceneを連続した1本の地図として見渡せ、Scene境界・Scene Label・セリフの順序・Cue範囲を確認できる。
- 背景、カード、立ち絵、オーバーレイの同時表示は、プレビューと同じ前後関係で右から左へ積まれる。
- Cueとセリフは、帯または行から中央ペインとプレビューの該当箇所へ移動できる。マウスだけでなくキーボードで同じ情報と操作にアクセスできる。
- Cueが多い場合にもセリフ本文を消さず、右端のレーンに半透明で重ねて表示し、集約レーンから隠れたCueを確認・ジャンプできる。
- 未保存フォームの変更を保存せずに地図へ反映でき、正本・保存タイミング・レンダー入力は変化しない。
