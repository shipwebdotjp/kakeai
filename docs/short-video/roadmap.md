# 縦型ショート出力ロードマップ

[spec.md](./spec.md) の実装完了後の拡張候補を整理する。ここに書いたものは約束された仕様ではなく、優先順位と依存関係を共有するための計画である。実装するときは本ファイルを更新し、[spec.md](./spec.md) と [todo.md](./todo.md) に詳細を落とす。

## 方針

- 出力形式の正は `Work.outputProfile` に固定する（[ADR 0113](../adr/0113-work-scoped-immutable-output-profile.md)）。拡張しても、レンダーごとにアスペクトを変える方向へは戻さない。
- 縦型は再レイアウトで作る（[ADR 0114](../adr/0114-portrait-output-by-relayout.md)）。レターボックス・クロップは非常手段としても既定にしない。
- ビジュアルテーマはキャンバス非依存のまま維持する。キャンバス固有の調整はレイアウト側に置く。

## 実装順序

| フェーズ | 対象 | 依存 | 順序の理由 |
| --- | --- | --- | --- |
| P1–P2 | 契約・キャンバス基盤・レンダー経路 | なし | 寸法が通らないと以降の確認ができない |
| P3–P4 | レイアウトコア・テンプレート | P1–P2 | レンダーで見ながらテンプレートを直す |
| P5 | プレビュー UI・API | P3 | レイアウトが決まってから枠を合わせる |
| P6–P7 | 品質・文書 | P3–P5 | 数値と文言を確定してから固定する |

## 拡張候補

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| ピクセル単位のゴールデンフレーム | 画像比較によるレイアウト回帰検出 | フォントと Chromium の版に依存して不安定なため採用しない。コンパイル結果の固定幅監査とレンダー寸法の結合テストで代替する |
| 縦型サムネイル | 9:16 のサムネイル候補と書き出し | 現行サムネイルは 1280×720 固定。YouTube 側は Shorts のカスタムサムネイル指定に制約があるため、アプリ内の一覧表示用としての価値も確認する |
| Shorts 投稿支援 | 3分上限の検証、`#Shorts` の注意、縦型向けのタイトル・説明テンプレート | YouTube 投稿設定（`docs/youtube-publication/`）の拡張として扱う |
| テーマ編集の縦型プレビュー | テーマ編集画面で横型・縦型を切り替えて確認 | テーマはキャンバス非依存のため必須ではない。まず作品プレビューで確認する |
| テンプレート別の縦型プリセット | 縦型向けの余白・タイプスケールをテンプレート単位で上書き | spec の初期値を実測で調整するための逃げ道 |
| セーフエリアのプリセット | プラットフォーム別（YouTube Shorts / TikTok / Reels）の上下左右予約領域 | まずは Shorts の 1 種類に固定する |
| 出力形式の追加 | 1:1・4:5 など | `workOutputProfileSchema` の値追加と、各テンプレートの組み方の追加になる。ADR 0113 の枠組みはそのまま使える |
| 複数形式の同時レンダー | 1つの台本から横型・縦型を同時に書き出す | ADR 0113 の「Work が唯一の正」と衝突するため、必要になった時点で新しい ADR を起こす |
| 自動リフレーム | AI が縦型の構図・強調点を提案する | 再レイアウトの品質を人手で確認できる状態になってから検討する |
| 縦型用 Composition 全画面の拡充 | 縦型 Composition を全画面で使う作例とテンプレート | spec 第3節の一致判定の実装後に、利用例を増やす |

## 決定済み事項（再検討しない）

- 出力形式は Work 単位で、作成後は変更しない（ADR 0113）。
- 縦型はレイアウト再構成で作る（ADR 0114）。
- 出力形式ごとにビジュアルテーマを分けない。
- 既存作品の一括変換は提供しない。変更は複製で行う。

## 保留・見送り

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| レターボックス／クロップのフォールバック | 見送り | 可読性を大きく損ない、再レイアウトの品質課題を隠す |
| Edition 単位の出力形式 | 見送り | 言語版ごとにアスペクトが変わると検証条件が増える |
| レンダー時の都度アスペクト指定 | 見送り | 台本・履歴・プレビューの正が分裂する |
| 縦型専用テンプレート一式 | 見送り | テンプレートとテーマの二重管理になる |
