# Kakeai

**Macで作るゆっくり解説動画**

Kakeai は、ローカルで動く Web アプリです。台本を書いて素材と音声を当てはめていくことで、YouTube でよく見る、二人のキャラクターが両端で会話しながら解説する動画が作れます。  
リアルタイムプレビュー機能でできあがりを確認してから書き出せます。

## Kakeaiの特徴

- **「台本」ベース** 見た目を整える前に、まずセリフから作ります。
- **解説動画特化** 導入・各チャプター・結びという構成をもとに、字幕、キャラクターの立ち絵、背景の画像や動画を配置する機能が最初から用意されています。

## できること

- **シーンで組み立てる台本**：導入・要点（いくつでも）・結びで構成します。要点の追加・並べ替え・分割ができ、章立ての原稿をまとめて取り込めます。
- **手元の素材をそのまま活用**：画像・動画・音声をアップロードすると、全作品で共有できます。タグ・お気に入り・アーカイブで整理できます。
- **合成音声エンジンとの連携**：VOICEVOX・AivisSpeech・OpenAI 互換の TTSエンジンに接続して、セリフの読み上げ音声を自動で作成できます。まとめて生成することもできます。
- **キャラクターと立ち絵**：セリフごとに表情を切り替えられ、まばたきや口パクの機能もビルトインです。
- **字幕と演出**：セリフに合わせて字幕を焼き込みます。必要なら、字幕ファイルを SRT で書き出すこともできます。表・グラフ・デバイスフレーム・有名サイト風のモックアップなど、ビジュアルテンプレートも用意しています。
- **見た目をテーマで統一**：配色・フォント・文字スタイルをテーマとしてまとめて持ち、動画でもサムネイルでも使えるので、作品とサムネイルのデザインに統一感を出すのに役立ちます。
- **その場で確認して書き出し**：編集内容をリアルタイムにプレビューし、出来上がりを確認してから MP4 動画を出力できます。
- **YouTube 投稿まで一通り**：投稿用のサムネイルを作成し、動画と合わせて書き出せます。

## できないこと

- **細かなレイアウト指定**：プレビュー画面で、素材や字幕をドラッグして、位置や大きさを調整することはできません。
- **タイムラインでの表示時間調整**：タイムライン上でドラッグして、各素材を表示する長さを指定することはできません。

## Kakeai が向いている人

- ゆっくり風の解説・紹介動画を作りたいものの、レイアウトや動画製作そのものより、内容の調査や推敲に時間をかけたい人。
- 決まったフォーマットでブランドテーマを一貫させたい人。

## 使い方

導入手順や画面の操作は [ユーザーガイド](https://kakeai.shipweb.jp) を参照してください。

## ご注意

Kakeai は開発中です。素材・音声・BGM の利用条件は利用者ご自身で確認してください。
