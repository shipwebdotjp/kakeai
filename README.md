# Kakeai

Kakeai は、編集意図（正本JSON）をレンダー済みメディアから分離して保持する、個人用ローカル動画制作アプリです。macOS上で単一プロセス起動するWebアプリで、オフラインで日本語の解説動画をMP4出力します。

## できること

- 作品（Work）を作成し、日本語（`ja-JP`）の制作版で台本を編集・保存する。保存のたびに不変の台本版が増える。
- 導入・要点0件以上・結びからなる可変Sceneに、画像・動画の背景とカード、画像の立ち絵、セリフ音声、作品全体BGMを割り当てる。
- 保存済みの台本をブラウザでプレビューし、MP4レンダーを開始・監視・再生する。
- 素材ライブラリを全作品で共有し、未参照素材をまとめて清掃する。

正本はSQLiteの不変な台本版（`contentJson`）で、Composition HTML・MP4・フレームは派生物です。AIによる生成や外部サービス連携はMVPの対象外です。
