# Kakeai

**Macでゆっくりな解説動画作成支援**

Kakeai は、台本を書いて素材と音声を当てはめていくことで、Youtubeなどで良くある二人のキャラクターが両端で会話しながら解説する動画を作ることができるローカルWebアプリです。  
リアルタイムプレビュー機能でできあがりを確認してから書き出せます。

## Kakeaiの特徴

- **「台本」ベース** 見た目を整える前に、まずはセリフがベースになります。
- **解説動画特化** 導入・各チャプター・結びの構成をもとに、字幕、キャラクター立ち絵、背景の画像や動画の配置機能が最初から用意されています。

## できること

- **シーンで組み立てる台本** — 導入・要点（いくつでも）・結び。要点の追加・並べ替え・分割ができ、章立ての原稿をまとめて取り込めます。
- **手元の素材をそのまま活用** — 画像・動画・音声をアップロードして全作品で共有。タグ・お気に入り・アーカイブで整理できます。
- **合成音声エンジンとの連携** — VOICEVOX・AivisSpeech・OpenAI 互換の TTSエンジンに接続してセリフ読み上げを自動作成できます。一括生成も可能。
- **キャラクターと立ち絵** — 表情をセリフごとに切り替え、まばたきや口パク機能もビルトイン。
- **字幕と演出** — セリフに合わせて字幕を焼き込み、必要なら SRT で字幕ファイルをエクスポートも可能です。表・グラフ・デバイスフレーム・有名サイト風のモックアップなど、ビジュアルテンプレートも用意しています。
- **見た目をテーマで統一** — 配色・フォント・文字スタイルをテーマとして持ち、動画やサムネイルから使用できるので、作品とサムネイルのデザインに統一感を出すのに役立ちます。
- **その場で確認して書き出し** — 編集内容をリアルタイムにプレビューし、出来上がりを確認してから MP4動画を出力できます。
- **YouTube 投稿まで一通り** — 投稿用のサムネイルを作成し、動画と合わせて書き出せます。

## できないこと
- **細かなレイアウト指定** - プレビュー画面で、素材や字幕をドラッグしたりしての位置サイズ調整は行なえません。
- **タイムラインでの表示時間調整** - タイムライン上で、ドラッグしたりして各素材を表示する長さを指定することはできません。


## こんな人に

- ゆっくり風の解説・紹介動画を作りたいが、レイアウトや動画製作そのものより、内容の調査、推敲に時間をかけて作りたい人。
- 決まったフォーマットで、ブランドテーマを一貫させたい人。

## 使い方
