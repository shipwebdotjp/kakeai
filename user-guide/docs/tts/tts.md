# 音声プロファイルと読み上げ（TTS）

Kakeai は、別途起動した **VOICEVOX ENGINE** または **AivisSpeech Engine** に接続して、セリフの音声を生成できます。どちらか一方だけでも、両方を同時に起動しても使えます。ENGINE の起動・停止・更新・音声モデルの導入は Kakeai の役割ではありません。あらかじめご自身で起動してください。

:::note[利用規約とライセンス]
VOICEVOX 本体、AivisSpeech Engine 本体、そして選択した音声モデル／ライブラリにはそれぞれ利用条件があります。生成した音声を使う前に、[VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/) と、使用する各音声モデルのライセンスを確認してください。AivisSpeech 本体のクレジット表記は必須ではありませんが、**音声モデルごとのライセンス確認は必要**です。確認した条件は、生成した音声を使った成果物にも適用されます。
:::

## 接続先の設定

接続先は環境変数で変更できます。指定できるのは HTTP のループバック（`127.0.0.1` / `localhost` / `::1`）だけで、認証情報・パス・クエリは指定できません。

| ENGINE | 環境変数 | 既定 |
| --- | --- | --- |
| VOICEVOX | `KAKEAI_VOICEVOX_BASE_URL` | `http://127.0.0.1:50021` |
| AivisSpeech | `KAKEAI_AIVISSPEECH_BASE_URL` | `http://127.0.0.1:10101` |

## 音声プロファイル

音声プロファイルは、キャラクターに割り当てる声の設定です。全作品で共通に使えます。

1. 画面上部の「音声」を開きます。
2. 新規プロファイルでは **ENGINE**（VOICEVOX / AivisSpeech）を選びます。エンジンに接続できると、そのエンジンの話者とスタイルの一覧が読み込まれます。接続できないときは、選んだ ENGINE の起動を確認してください。
3. プロファイル名を入力し、**話者** と **既定スタイル** を選んで「追加」を押します。
4. 一覧から名前・話者・既定スタイルを変更して「保存」、または「削除」できます。ENGINE（アダプター）は作成後に変更できません。別の ENGINE に変えたいときは、新しいプロファイルを作ってキャラクターの割り当てを付け替えてください。台本やキャラクターから参照されているプロファイルは削除できません。

## 台本での設定

1. 作品の編集画面を開きます。
2. **キャラクター** セクションで「ライブラリから追加」を押すか、「声だけの話者を追加」でキャラクターを作ります。キャラクターの**声プロファイル**を選ぶと、そのキャラクターのセリフを読み上げできます。声プロファイルは「キャラクター」画面でも登録できます。
3. セリフごとに **キャラクター** を選び、**読み上げテキスト** を入力します。読み上げテキストは実際に読み上げる表記（ひらがななど）にすると自然な発音になります。

## 読み上げの生成

セリフの音声欄にある「TTS生成」で音声を作ります（要点シーンのセリフのみ）。

- **スタイル** と **話速**（倍、0.5〜2.0、既定 1.0）を選べます。初期表示は声プロファイルの既定スタイルです。生成には、そのプロファイルで選んだ ENGINE が使われます。
- 生成には **入力中の読み上げテキスト** が使われます。保存しなくても生成でき、複数のセリフを続けて生成してから最後に1回保存すると、まとめて1つの版になります。ただし**新しく追加したセリフは、一度保存してから**生成できます。
- 生成が終わると、そのセリフの音声候補として追加され、自動的に選択されます。手動で追加した音声と同じように、切り替え・解除・削除ができ、**再生**で確認できます。
- 生成した音声は、通常の「保存」を押すまで台本の新しい版には入りません。内容を確認して保存してください。
- エンジン未起動・話者やスタイルが見つからない・合成失敗のときは、選んだ ENGINE 名とともに理由が表示されます。

生成された音声は素材ライブラリにも保存され、同じ内容は自動的にまとめられます。生成音声のファイル名は `tts-<ENGINE>-<話者名>-<スタイル名>[-<話速>x]-<セリフID>.wav` の形式で、話速が1.0以外のときだけ話速が付きます。
