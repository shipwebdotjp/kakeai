# ライブ Run を書き出して起動する

Kakeai の GUI から、確定済みの **Live Program Version** を **ライブ Run** として書き出し・起動できます。ライブ Run は、どのパッケージ build を、どのコメントソース・開始予定・ポートで動かすかを固定する運用スナップショットです。

:::note[「アプリ起動」と「番組開始」は別です]
「アプリ起動」はローカルのライブアプリを立ち上げるだけです。番組の開始・終了は、Run の **コンソール** を別タブで開いて操作します。
:::

## Kakeai 側の準備

ライブアプリの LLM・TTS・YouTube 認証情報は、Run やパッケージには保存されません。Kakeai API を起動する前に、ローカルのライブ設定 JSON を `KAKEAI_LIVE_CONFIG` で指定してください。

```sh
export KAKEAI_LIVE_CONFIG=/path/to/live-config.json
npm run dev --workspace @kakeai/api
```

`KAKEAI_LIVE_CONFIG` を指定しない場合、ライブアプリは既定のローカル設定で起動します。実 YouTube の実行には `youtube` の API キー、または OAuth の clientId / clientSecret が必要です。設定の書き方は [ライブ設定と YouTube の接続](./setup.md) を参照してください。

## 書き出しと起動

1. ライブプログラムのエディタで版を確定します。
2. 版の詳細にある **「パッケージ書き出し」** を押します。
3. ライブ実行の新規 Run 画面で、プログラムと版を確認します。
4. パッケージの出力先（存在しない絶対パス）を入力し、**「パッケージを書き出す」** を押します。
5. 書き出し Job が成功すると、package build（`packageId`、`manifestSha256`、`packagePath`）が表示されます。Run で使えるのは、その版の成功した書き出し Job が実際に生成したパッケージだけです。手書きや別の場所へコピーしたディレクトリは指定できません。
6. コメントソースを選びます。
   - **YouTube**: 動画 URL、または `liveChatId` を入力します。
   - **fixture**: JSON ファイルを選択するか、サーバー上の fixture パスを入力します。指定できるのは 10 MiB 以下の通常ファイルだけです。
7. 必要なら開始予定とポート（既定 `3010`、`1024`〜`65535`）を指定し、**「Run を作成」** を押します。同じポートは、終了していない別の Run が使用中の間は指定できません。
8. Run 画面で **「アプリ起動」** を押します。
9. **「コンソールを開く」** を押し、別タブで番組を開始します。

OBS のブラウザソースには、Run に表示される **OBS ステージ URL**（`http://127.0.0.1:3010/stage` など）を設定します。コンソールは OBS に出しません。

## Run の状態

| 表示 | 意味 |
| --- | --- |
| 準備済み（未起動） | Run と fixture を固定済み。まだアプリを起動していない。 |
| アプリ起動中 | 起動を要求し、control の応答を待っている。 |
| アプリ実行中 | アプリは稼働中。番組開始前でもこの状態になる。番組の進行はコンソールで確認する。 |
| 番組終了 | クロージング後の `post_show` に到達した。 |
| 停止 | 停止操作で終了した。 |
| 失敗 | 起動失敗、プロセス終了、または control に接続できない。 |

- Kakeai を再起動しても、動いているライブアプリへ再接続するだけで、勝手に再起動・自動再生はしません。
- アプリのプロセスが終了している場合や control に接続できない場合は **失敗** と表示されます。必要なら新しい Run を作ってください。
- 「停止」はコンソールへの停止要求を行い、応答しない場合はプロセスを終了します。ログは削除されません。

## ログとファイル

Run のファイルは `<Kakeai のデータディレクトリ>/live-runs/<runId>/` にあります。

| ファイル | 内容 |
| --- | --- |
| `run-config.json` | パッケージ、コメントソース、開始予定、ポート。認証情報は含まない。 |
| `control-token` | ローカル制御用の一回限りのトークン。`0600`。 |
| `fixtures/comments.json` | fixture Run のコメント列。 |
| `live.log` | ライブアプリの標準出力・標準エラー。 |
| `run.json` / `events.jsonl` / `errors.log` | ライブ実行のログ。 |

Run 画面には、package build、Run のログディレクトリ、PID、control URL、失敗理由が表示されます。
