# OBS にステージを設定する

ライブの映像は、OBS の **ブラウザソース** でステージをキャプチャして配信します。ステージは 1920x1080 の固定キャンバスです。OBS のキャンバスと出力解像度も 1920x1080 に合わせてください。

## 1. ライブアプリを起動する

```sh
npm run live -- \
  --package /tmp/live-package-10m \
  --config /path/to/live-config.json
```

起動ログに表示されるステージ URL を控えます。既定のポートでは次の URL です。

```text
http://127.0.0.1:3010/stage
```

:::note[OBS に使うのは `/stage`]
OBS に入れるのは **`/stage`** です。`/stage?preview=1` はコンソール用のミュートされたプレビューで、program にはなりません。`/console` は操作画面なので OBS に入れないでください。
:::

## 2. ブラウザソースを追加する

OBS でシーンを選び、「ソース」→「+」→「ブラウザ」を選びます。

| 設定 | 値 |
| --- | --- |
| 名前 | `Kakeai Stage` など |
| URL | `http://127.0.0.1:3010/stage` |
| 幅 | `1920` |
| 高さ | `1080` |
| FPS | `30` または `60`（OBS の設定に合わせる） |
| カスタムフレームレート | 必要なら有効化 |
| ソースが表示されていないときにシャットダウン | オフを推奨 |
| シーンがアクティブになったときにブラウザを更新 | オフを推奨 |

「シーンがアクティブになったときにブラウザを更新」をオンにすると、シーン切り替えのたびにステージが再接続します。v1 では program の自動復帰を行わないため、オフのままにするのが安全です。

追加したソースを右クリックし、「変換」→「画面に合わせる」で 1920x1080 のキャンバスに合わせます。

## 3. 音声経路を設定する

ステージの音声は、**program ステージだけ** が再生します。コンソールのプレビューはミュートされています。

OBS のブラウザソースの「音声を OBS で制御する」（Control audio via OBS）をオンにすると、ステージの音声が OBS の音声ミキサーに表示されます。この場合、OBS の音声モニタリングと配信の音声トラックを確認してください。

音声経路は次のどちらかに統一します。

1. **ブラウザソースの音声を OBS で制御する**（推奨）: OBS の音声ミキサーで `Kakeai Stage` の音量を調整する。
2. **macOS のデスクトップ音声を OBS で取り込む**: ブラウザソースの音声はミュートし、デスクトップ音声だけを配信に載せる。

両方を有効にすると、同じ音声が二重に配信されます。必ずどちらか一方にしてください。

:::note[音声が出ないとき]
- OBS のブラウザソースで「音声を OBS で制御する」がオンか確認する
- macOS の出力先と OBS のモニタリング設定を確認する
- コンソールのステージ接続で、OBS のステージが `PROGRAM` になっているか確認する
- 別のブラウザで `/stage` を開いていないか確認する（最初の 1 つだけが program）
:::

## 4. コンソールを別ウィンドウで開く

コンソールは OBS に取り込まず、Safari や Chrome の別ウィンドウで開きます。

```text
http://127.0.0.1:3010/console
```

コンソールでは、開始・終了、一時停止、停止、安全モード、コメントのピン、生成レスの編集などを行います。OBS のプレビューには出さないでください。

## 5. 配信前の確認

1. OBS のブラウザソースにステージが表示され、`pre_show` のタイトルとカウントダウンが見える
2. コンソールの「ステージ接続」に、OBS のステージが `PROGRAM`、コンソールのプレビューが `PREVIEW` と表示される
3. OBS の音声ミキサーで `Kakeai Stage` のメーターが動く（テスト音声または開始後のオープニングで確認）
4. 配信の音声トラックにステージの音声が含まれている
5. コンソールの「開始」を押し、オープニングが音声付きで流れる
6. 必要なら「一時停止」「再開」「停止」を試す

## 1920x1080 以外で配信する場合

ステージは 1920x1080 の固定キャンバスで、OBS のブラウザソース内で自動的に拡大縮小されます。配信の出力解像度が 1280x720 などの場合は、OBS の「設定」→「映像」でキャンバスと出力解像度を同じ比率（16:9）にしてください。縦型配信には対応していません。

## ステージを再接続したとき

OBS のブラウザソースを再読み込みしたり、OBS を再起動したりすると、ステージは新しいセッションとして接続します。program のリースは自動で引き継がれません。コンソールの「ステージ接続」で新しいステージを選び、「program を引き継ぐ」を押してください。そのあと「再開」で現在のキューから再開します。

配信中のトラブルは [トラブルシューティング](./troubleshooting.md) も確認してください。
