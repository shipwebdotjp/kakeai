# 当日のライブを操作する

このページでは、配信当日の起動手順と、コンソールで行う操作を説明します。YouTube の配信作成・開始・終了、チャット投稿、モデレーションは人間が行います。

## 配信前のチェックリスト

- [ ] ライブパッケージを書き出した
- [ ] ローカル LLM と TTS を起動した
- [ ] YouTube の接続設定を用意した（API キーのみ、または OAuth フォールバック / OAuth のみ）
- [ ] OAuth を使う場合は `live auth` で YouTube の読み取りを認証した
- [ ] OBS のブラウザソースに `/stage` を設定した
- [ ] OBS の音声経路をどちらか一方に統一した
- [ ] コンソールを OBS に出ない別ウィンドウで開いた
- [ ] テストモードまたは非公開配信でリハーサルした

## 起動

```sh
npm run live -- \
  --package /tmp/live-package-10m \
  --config /path/to/live-config.json
```

起動したら、OBS のステージとコンソールを開きます。`pre_show` には番組タイトルと「まもなく始まります」が表示されます。Show Profile の `show.startAt` を設定している場合は、開始までのカウントダウンも表示されます。カウントダウンは表示だけであり、自動開始はしません。

YouTube の配信は、OBS とライブアプリの準備ができてから人間が開始します。

## 開始と終了

| 操作 | 動作 |
| --- | --- |
| 開始 | `pre_show` からオープニングへ進み、ショー時計が動き始める |
| 終了 | 現在のキューまたはCutInの再生が終わってからクロージングへ進む。クロージングが終わると `post_show` |
| 一時停止 | 現在の音声をフェードアウトし、CutInを停止して `paused` へ。再開すると現在のキューの先頭から |
| 再開 | `paused` から元の状態へ戻る。CutInは先頭から |
| 停止 | 音声をフェードアウトし、CutInを停止して、生成キューを消して `paused` へ。準備済みキューは保持 |
| 安全モード | 生成レスとコメントコーナー、CutInを止め、準備済みの安全なキューだけを流す。v1 では解除できない |

:::note[終了はハードストップではない]
「終了」を押しても、現在のキューまたはCutInは最後まで再生されます。すぐに音を止めたい場合は「停止」を使ってください。
:::

## ステージ接続と program の引き継ぎ

program ステージは 1 つだけです。OBS に出すステージが program で、音声を再生できます。コンソールのプレビューは preview で、ミュートされ、再生イベントも送りません。

OBS のブラウザソースを再読み込みした場合や、OBS を再起動した場合は、program のリースが失効します。コンソールの「ステージ接続」で新しいステージを選び、「program を引き継ぐ」を押してください。自動では引き継がれません。

## キューと字幕の操作

- **スキップ**: 再生中のキューをスキップします。コメントコーナー中は、現在のコメントをスキップします。
- **生成レスの編集**: 生成中の字幕・読み上げ・表情を変更できます。読み上げを変えた場合は TTS をやり直します。
- **キャンセル**: 生成中・準備完了・未再生の生成キューを取り消します。
- **再生成**: 同じコメントに対して応答をもう一度生成します。再生中のキューは対象外です。
- **削除**: 準備完了後、再生開始前の生成キューを削除します。
- **並べ替え**: 準備完了後、再生開始前の生成キューを上下に移動します。
- **訂正**: 準備済みのライブキューを選び、現在のキューの直後に差し込みます。現在の音声は途中で止めません。

再生中の生成キューに対してできるのは、停止と訂正だけです。承認待ちはなく、生成レスは準備ができ次第流れます。

## CutIn（区切り動画）の操作

CutInの再生中は、コンソールのフェーズが「カットイン」になり、「カットイン」パネルに再生中のCutIn名、尺、経過、進捗、`cutInId`、`segmentId`、`attempt` / `sequence` が表示されます。専用の「CutInをスキップ」ボタンはCutInの再生中だけ有効で、通常のキューのスキップとは別の操作です。

- **スキップ**: 現在のCutInを止め、次のスパイン要素へ進みます。
- **終了**: CutInの再生中に「終了」を押すと、そのCutInを最後まで再生してからクロージングへ進みます。CutInの開始前に終了が保留されている場合は、そのCutInを飛ばします。
- **停止**: 直ちに停止します。「再開」するとCutInは先頭から再生されます。
- **一時停止 / 再開**: 一時停止中は映像と音声を止め、再開すると先頭から再生します。
- **安全モード**: CutInは再生せず、次の準備済みセグメントへ進みます。
- CutInの読み込み・再生に失敗した場合は、警告を記録して次へ進みます。配信は停止しません。

CutInは全画面で再生され、キャラクター・字幕・素材カード・コメントは隠れます。音声ありのCutInは program ステージだけが再生し、コンソールのプレビューはミュートされます。

## コメントの操作

コンソールのコメント一覧には、投稿時刻、鮮度、投稿者、本文、フィルター状態、AI スコア、理由が表示されます。

- **ピン**: 次のコメントコーナーで優先して拾います。任意でメモ（「質問として」「ツッコミとして」など）を添えられます。
- **ピン解除**: ピンを取り消します。
- **スキップ**: そのコメントを次の候補から外します。
- **コメント一時停止 / 再開**: コメントコーナーの進行を一時停止します。コメントの受信は止まりません。
- **投稿者ブロック**: 指定した投稿者のコメントを以後ブロックします。
- **話題ブロック**: 指定した話題を含むコメントを以後ブロックします。
- **liveChatId の手動設定**: `videoUrl` から自動解決できない場合に、ライブチャット ID を直接設定します。

安全ブロックされたコメントは、人間がピンしても拾われません。ピンは次のコメントコーナーへ回り、即時に台本へ割り込むことはありません。

## コメントソースの状態

コンソールの「コメントソース」には、種類（`youtube` / `fixture`）、接続状態、認証方式（APIキー / OAuth）、OAuth フォールバックの有無、liveChatId、ポーリング間隔、最終取得時刻、クォータ概算、認証期限、再認証の要否、最終エラーが表示されます。

- **認証方式**: 現在使っている資格情報です。`APIキー` は公開ライブチャットの読み取り、`OAuth` は OAuth トークンでの読み取りを表します。
- **フォールバック**: `OAuthフォールバックあり` の場合、API キーが認証系のエラーになったとき、OAuth トークンで同じリクエストを 1 回だけ再試行できます。
- **クォータ**: 累積のリクエスト数と units の概算です。30 分の配信で既定のクォータに収まるかの目安にしてください。OAuth への再試行も 1 リクエストとして数えます。
- **認証期限**: OAuth アプリが Testing の場合の 7 日失効の目安です。API キー方式では「不要」と表示されます。
- **再認証**: OAuth の認証が失効したら `npm run live -- auth --config <file>` を実行してください。API キーのみの場合は不要です。

API キーが認証系のエラーで失敗し、OAuth フォールバックが使える場合、表示は自動的に `OAuth` に切り替わります。配信終了・チャット無効・チャットが見つからない場合はフォールバックせず、コメントソースが停止またはエラーになります。

## 生成レスの表示

コンソールの「生成レス」には、生成状態（考え中・準備中・準備完了・失敗）、対象コメント、生成キュー、字幕、読み上げ、表情、音声 URL が表示されます。生成に失敗した場合は、そのコメントをスキップするか、退避キューが 1 回だけ再生されます。連続で失敗すると通知が出ます。

## 配信後

1. クロージングが終わったら「終了」を押し、`post_show` を表示します。
2. YouTube の配信を人間が終了します。
3. ライブアプリを `Ctrl+C` で停止します。
4. 実行ディレクトリのログを確認します。

実行ディレクトリは `<dataDir>/runs/<runId>/` に作られます。

| ファイル | 内容 |
| --- | --- |
| `run.json` | ショー、パッケージ、開始・終了時刻、結果 |
| `events.jsonl` | フェーズ・コメント選択・生成・編集・削除・スキップ・停止・エラー |
| `cues.jsonl` | キューの再生状態、attempt、sequence、終了理由 |
| `comments.jsonl` | コメント ID、伏せ字、判定理由、スコア（生本文・投稿者名は保存しない） |
| `generated-text.jsonl` | 生成した字幕・読み上げ・表情 |
| `generated/` | 生成した音声 |
| `errors.log` | 復旧できなかったエラー |

ログには個人情報を含み得る情報が残る場合があります。保存先と共有範囲は利用者が管理してください。

## やってはいけないこと

- コンソールを OBS の映像に含める
- OBS とデスクトップ音声の両方でステージの音声を配信する
- 複数のブラウザで `/stage` を開き、意図しないステージを program にする
- 実 YouTube のコメントを外部 LLM へ送る設定にする
- YouTube の API キーや OAuth トークンを共有・コミットする
- YouTube の配信操作をアプリに任せようとする（アプリは行いません）
