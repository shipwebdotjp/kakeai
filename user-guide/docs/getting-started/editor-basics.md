# 編集画面の基本操作

作品の編集画面は、台本を編集して動画を確認する場所です。初回の制作は[はじめての動画を作る](./first-video.md)を参照してください。

## 画面の見方

- **左**：Scene・セリフ・映像演出の一覧です。項目を選ぶと、編集欄とプレビューの該当箇所へ移動します。
- **中央**：シーンやセリフを編集します。
- **右**：プレビューで見た目を確認し、保存済みの台本から MP4 を出力します。

画面が狭い場合は、編集と確認の表示を切り替えて使います。

## 保存・プレビュー・出力

編集内容は自動保存されません。変更を残すときは「保存」を押します。保存のたびに台本の新しい版が作られ、過去の版は残ります。

プレビューには未保存の編集も反映できますが、MP4 出力に使うのは最後に保存した版です。プレビューで見た内容を出力する前に、もう一度保存してください。

プレビューやレンダーの操作、シーン・セリフ・映像演出の細かな編集方法は[編集画面の詳しい操作](./web-ui.md)を参照してください。
