# Kakeaiとは・制作の流れ

Kakeai は、台本や編集内容を保存しながら、日本語の解説動画を作るローカル動画制作アプリです。作品と台本を編集し、プレビューで確認してから MP4 を出力できます。

## 動画を作る基本の流れ

1. アプリを起動し、作品を作成します。
2. 台本のシーンとセリフを編集します。字幕だけの動画から始めることもできます。
3. 変更を保存し、プレビューで映像を確認します。
4. 保存済みの台本から MP4 を出力します。

音声を付けたい場合は、対応する TTS エンジンを別途用意して接続します。準備と音声生成の手順は[音声プロファイルと読み上げ（TTS）](../tts/tts.md)を参照してください。
