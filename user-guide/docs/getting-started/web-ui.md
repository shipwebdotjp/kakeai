# Web UI の使い方

Kakeai の Web UI は、ブラウザで作品と台本を編集する画面です。

## 表示テーマ

画面右上の「テーマ」ボタンで、システム / ライト / ダークを切り替えられます。既定はOSの設定に従います。この設定は編集画面の見た目だけに影響し、出力動画の配色（下の「映像のテーマ」）とは別です。

## 映像のテーマ

出力動画の配色・文字の既定値は、すべての作品で映像テーマ `soft-editorial` を使います。テーマの切り替え操作はありません。

- シーンごとに **アクセント** を選びます。**テーマ色**（プライマリ／セカンダリ／ターシャリ）または **自由色** を選べます。背景はアクセントを温白色に溶かした柔らかい色になります。
- **テキスト** Cueで指定しない項目（フォント・サイズ・色・装飾など）は、役割（本文・見出し・タイトル・サブタイトル・結びの文言）ごとのテーマのスタイルで描画されます。個別に指定した項目はそちらが優先されます。

## 作品一覧

トップページに作品の一覧が表示されます。

- **作成**: 上部の入力欄に作品名を入れて「作成」を押すと、新しい作品が作られます。
- **開く**: 作品名を押すと編集画面を開きます。
- **削除**: 「削除」を押すと、その作品と台本の履歴がすべて消えます。元に戻せません。
- 詳しくは [作品の管理](../works/works.md) を参照してください。

## 素材ライブラリ

画面右上の「素材」から、全作品で使える素材（画像・動画・音声）を管理します。

- **アップロード**: ファイルを選ぶか、点線の枠内にドラッグ&ドロップします。複数ファイルをまとめて選べ、一覧を確認してからアップロードできます。取り込みが終わると状態が「準備完了」になります。
- 取り込み中は「取り込み中」、失敗したときは「失敗」と表示されます。同じ内容のファイルは自動的にまとめられ、二重には保存されません。
- **削除**: 「削除」を押すと素材を削除します。台本などで使用中の素材は削除できません。
- **タグ**: 素材にタグを付けて分類し、タグで絞り込めます。ピッカーでもタグで絞り込めます。
- 詳しくは [素材ライブラリ](../assets/assets.md) を参照してください。

## 音声プロファイル

画面右上の「音声」から、全作品で共通に使う声の設定（音声プロファイル）を管理します。新規作成時に ENGINE を選び、接続したエンジンの声を選びます。声には言語が付きます。

- セリフの音声は、このプロファイルをキャラクターに割り当てて生成します。
- 詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。

## キャラクターライブラリ

画面右上の「キャラクター」から、全作品で使えるキャラクターを登録します。

- **キャラクターを追加** で名前を入力し、**言語別の声**（言語と声プロファイルの組）を登録します。「声を追加」で言語ごとの声を増やせます。
- キャラクターごとに **外観を追加** します。外観は画像1枚と、表示名（例「夏服」）・表情・ポーズのタグを持ちます。画像は素材ライブラリの準備完了済み画像から選びます。外観には、下の「表情セット」で作った顔素材を割り当てられます（「表情セット」で「なし」を選ぶと割り当てなし）。
- 台本には、編集画面の「キャラクター」から「ライブラリから追加」でコピーして使います。コピーなので、ライブラリを変更しても追加済みの作品には波及しません。ただし外観が指す表情セットは参照のまま引き継がれるため、表情セット側の変更は追加済みの作品にも反映されます。
- 取り込んだ後は、作品の「キャラクター」欄で名前・声プロファイルに加えて **外観（画像・表示名・表情・ポーズ）の追加・編集・削除** ができます。作品独自の外観はここで調整してください。立ち絵の外観選択には、表示名があれば「夏服（smile / front）」のように表示されます。
- 複数の作品で同じ外観を使い回したいときは、ライブラリに登録しておくと各作品へ取り込めます。

## 表情セット

画面右上の「表情」から、立ち絵の表情・瞬き・口パクに使う顔素材を登録します。互換な外観（顔の向き・位置・大きさが同じ立ち絵）で共有できます。

- **顔レイヤー** を「レイヤーを追加」で登録します。部位（眉／目／口／前景）を選び、立ち絵のベース画像と**同じ寸法の透過画像**を選びます。ベース画像に描かれていない眉・目・口だけを描いた画像を使います。寸法が違う画像は保存時にエラーになります。
  - 目のレイヤーには、閉じた目のレイヤーを **閉眼** として選べます。選ぶと、その目が表示されている間に決まったタイミングで瞬きします。
  - 口のレイヤーには、開いた口のレイヤーを **開口** として選べます。選ぶと、セリフを話している間に口が不規則に開閉します。音声や読み上げ内容との同期はありません。
  - 閉眼・開口を選ばないレイヤーは静止したままです。
- **表情プリセット** を「表情を追加」で作ります。**表示名**（例「笑い」）を付け、眉・目・口に使うレイヤーをそれぞれ選びます。`normal`（通常）は必須で削除できません。表情の切り替えはこの表示名の一覧から選びます。
- 「追加」「保存」で登録します。使用中の表情セット（外観や保存済みの台本から参照中）は削除できません。
- 表情セットを編集すると、それを使う作品の次回のプレビュー・レンダーに反映されます。

### 作例：最小構成で表情差分を作る

眉・目・口を描いていないベース立ち絵に、通常の眉・目・口を重ねて表情を切り替えられるようにします。

1. 素材ライブラリに画像を4枚用意します。**ベース立ち絵**（眉・目・口なしの全身）、**眉だけ**・**目だけ**・**口だけ** を描いた透過画像3枚です。透過画像3枚はベースと**同じ寸法**にします。
2. 「表情」で表情セットを追加し、名前（例「リン正面」）を付けます。
3. **顔レイヤー** に3枚を登録します。部位はそれぞれ 眉／目／口 を選びます。
4. **表情プリセット** の `normal`（通常）に、眉・目・口の3枚を割り当てます。
5. キャラクターの外観にベース立ち絵を登録し、その外観の **表情セット** で作ったセットを選びます。
6. 台詞の **表情** で `normal` を選ぶと、そのセリフの間だけ重ねた顔で表示されます。選ばないときも通常の表情です。

差分を増やす例：目の笑顔画像を顔レイヤーに追加し、「表情を追加」で表示名「笑い」のプリセットを作り、目だけ笑顔のレイヤーに変えます。眉と口は `normal` と同じレイヤーを使い回せます。

瞬きを付ける例：閉じた目の画像を顔レイヤー（部位：目）に追加し、通常の目レイヤーの **閉眼** に選びます。口パクを付ける例：開いた口の画像を顔レイヤー（部位：口）に追加し、通常の口レイヤーの **開口** に選びます。

## Composition Library

画面右上の「コンポジション」から、AI が作成・公開した全画面モーション（Composition）の一覧を確認できます。

- 各 Composition の **名前・runtime ID・draft の状態・公開バージョン数** が並びます。押すと選択され、右に draft の entrypoint と公開バージョン（版番号・バージョンID・bundle ハッシュ・entrypoint・公開日時）が表示されます。
- Composition の作成・編集・公開は AI（HyperFrames）が行います。Web UI からの HTML 編集や公開操作はありません。
- 台本で使うには、シーンの Cue に **コンポジション背景（全面）** を追加し、入力欄から公開済みバージョンを選びます。Scene 背景（range: scene, layer: background）にのみ置け、同じバージョンは 1 つの台本内で 1 回だけ使えます。
- 詳しくは [Composition Library](../composition-library.md) を参照してください。

## 台本の編集

編集画面では、導入・要点（0件以上）・結びの順にシーンを編集します。新規作品は導入＋要点1つ＋結びで始まります。

- 画面は3つのペインに分かれます。**左**は構成（Scene・Cue・セリフ）のジャンプメニュー、**中央**は編集、**右**はプレビューとレンダーです。ペインの境目をドラッグすると幅を変えられます。左の項目をクリックすると、中央がその箇所へスクロールし、右のプレビューがその位置へ移動します。ジャンプ先は、右に表示中のプレビュー（下の「プレビュー」参照）の時刻に基づきます。中央をスクロールすると、いま表示している項目が左メニューでハイライトされます。

- 各シーンの見出し左の入力欄が **シーン名（ラベル）** です。これは映像には表示されない編集用の名前で、左の構成メニューや右のプレビューのシーンボタンに表示されます。見出しを映像に出したいときは、Cue一覧の **テキスト** Cue（役割「見出し」）に入力します。ラベルは並べ替えても自動では変わりません。
- 各シーンのテキスト（タイトル、サブタイトル、見出し、本文、結びの文言）は、Cue一覧の **テキスト** Cue として編集します。新規シーンには役割ごとのテキストCueがあらかじめ入っています。
- **アクセント** をシーンごとに選びます。**テーマ色**（プライマリ／セカンダリ／ターシャリ）または **自由色** を選べます。
- **尺** は「自動」または「固定」を選びます。導入と結びは固定尺のミリ秒を指定できます。自動では、音声の長さ（音声なしのセリフは2.5秒）に前後の0.5秒を足してシーン尺を決めます。各シーンの下の「尺を表示」を開くと、算出後のシーン尺と各セリフの区間を確認できます。
- **シーン切替** で、直前のシーンからの切り替え方を選べます。カット（既定）／フェード（暗転を挟む）／クロスフェード。尺はミリ秒で指定し、隣り合うシーンの短い方の尺を超える値は保存時にエラーになります。先頭シーンには設定できません。
- **キャラクター** セクションで、この作品で使うキャラクターを「ライブラリから追加」します。名前と声プロファイルは作品ごとに変更できます。「声だけの話者を追加」で、立ち絵を持たないナレーターを作れます。
- 要点シーンには **セリフ** を追加できます。字幕テキストと、読み上げ用のテキストを入力します。
  - セリフごとに **キャラクター** を選べます。声はそのキャラクターの声プロファイルから決まります。
  - セリフごとに **表情** を選べます。そのセリフの話者の立ち絵に表情セットが割り当てられているときだけ表示され、そのセリフの間だけ表情が切り替わります。選ばないときは通常の表情です。話者がないセリフには付けられません。立ち絵や表情セットの変更で使えなくなった表情は、警告と「クリア」で直せます。
  - セリフごとに **音声** を追加できます。「選択」でピッカーを開き、音声素材を選ぶと候補として追加され、そのセリフに使われます。候補は複数持て、ラジオで切り替え、「音声を解除」で字幕だけにできます。候補の「削除」もできます。各候補は **再生** で確認できます。
  - キャラクターに声プロファイルを割り当てると **TTS生成** が使えます。声と話速を選んで生成すると、候補として追加され自動選択されます。生成には入力中の読み上げテキストが使われ、**保存しなくても生成できます**（新しいセリフは一度保存すると生成できます）。生成後に保存すると、まとめて1つの版になります。詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。
  - ピッカーの中から新しい音声ファイルをアップロードできます。ピッカー内へのドラッグ&ドロップや複数ファイルの同時追加にも対応します。
  - 字幕テキストは動画に焼き込まれ、そのセリフの区間に表示されます。
  - 各セリフの先頭に `番号. 話者名 — 字幕先頭` の連番が表示され、番号で見分けられます。話者未設定は「話者なし」、字幕が空なら「（字幕なし）」と表示されます。番号は保存されず、並べ替えや分割で自動的に振り直されます。
  - 各セリフの見出しの `▶` で、プレビューだけをそのセリフの先頭へ移動できます（中央の編集位置は変わりません）。
  - 各セリフの `…` メニューから「上へ」「下へ」「このセリフの前でシーンを分割」「複製」「削除」を選べます。「上へ」「下へ」ではセリフのID・話者・字幕・読み・音声が保持され、TTSを再生成する必要はありません。「複製」は話者・字幕・読みだけを複製し、音声は複製しません。「削除」では、そのセリフを表示区間に使っているCueがあると確認が出ます。削除すると該当するCueの区間は残りのセリフへ調整され、そのセリフ1件だけを指していたCueは削除されます。
- 「このセリフの前でシーンを分割」を選ぶと、そのセリフ以降を新しい要点シーンとして直後に切り出します。元のシーンの見出し・背景・立ち絵は新しいシーンへコピーされないため、新しいシーンは空の見出し・本文から編集します。セリフに追随するCueは分割先へ移動し、両方をまたぐCueは前半と後半に分かれます。導入・結びや、セリフが1件以下の要点シーンでは分割できません。
- 要点シーンは「↑」「↓」で並べ替え、「削除」で取り除けます。下の「要点を追加」で増やせます。並べ替えや保存をしてもIDは変わりません。
- 「台本をインポート」で、章立ての台本をまとめて要点シーンに取り込めます。`## 見出し` の行が要点シーンのシーン名（ラベル）、`話者名: セリフ`（全角コロン `：` も可）の行がセリフ（字幕テキストと読み上げテキスト）になります。1行が1セリフです。取り込んだシーンの見出しテキストCueは空のままなので、映像に見出しを出すにはCue一覧で入力します。
  - 取り込む前に、台本中の話者名を作品内の話者へ割り当てます。名前が完全一致する話者が1人だけなら自動で選ばれ、候補がない・同名が複数あるときは選ぶまで反映できません。「話者なし」（字幕のみ）も選べます。話者は自動作成されません。
  - 反映先は「既存の要点シーンを置き換える」（既定）か「末尾へ追加する」を選べます。置き換えでも導入・結び・キャラクター・BGM・素材・話者設定は残ります。
  - 見出しより前のセリフ、空の見出し・話者名・セリフ、セリフのない章、書式に合わない行はエラーになり、反映できません。
  - 取り込みは未保存の編集内容を更新するだけで、保存済みの台本の版は「保存」を押すまで変わりません。取り込んだセリフの音声は未設定なので、必要に応じて [TTS](../tts/tts.md) を生成します。
- 要点シーンの見出し左の「前のシーンを複製」は、直前の要点シーンの見た目（アクセント・尺・シーン切替・Cue・立ち絵）をそのまま複製し、新しい要点シーンとして直後に追加します。セリフと音声は複製されません。直前が導入（要点でない）ときは押せません。
- 各シーンには **Cue一覧** があり、**背景**・**カード** などの表示要素を追加できます。
  - 「Cueを追加」で種類を選びます。背景・カードは画像・動画の素材のほか、**デバイスフレーム**（端末枠の中に画像・動画を表示する複合ビジュアル）や **サイトモックアップ**（X・GitHub・Qiita・ブラウザなど有名サイトのガワに画像・動画を収める）も選べます。**テキスト** Cueでは役割（本文・見出し・タイトル・サブタイトル・結びの文言）・左右位置・上下位置・フォント・サイズ・色・装飾（太字・斜体・縁取り・影）を設定できます。色はカラーピッカーで選び、装飾は「既定・オン・オフ」のボタンで切り替えます。「既定」は映像テーマの役割別スタイルを使う設定です。
  - サイトモックアップは種類（variant）・テーマ（ライト/ダーク）・表示名・ハンドル・URL・本文・任意ロゴを設定できます。ロゴは同梱されないため、利用者が用意した画像を選びます。ブランドの利用条件は利用者が確認してください。
  - 素材を選び、テンプレートごとの項目（見出し・補足文・フレーム種別・背景色・画面の登場アニメーションなど）を編集します。カードでは**アスペクト比**（16:9・4:3・1:1・3:4・9:16、既定16:9）を選べます。見出しと補足文を両方とも空にすると、テキスト用の枠は表示されません。
  - 各Cueは **レイヤー**（背景・カード・オーバーレイ）と **順序**、**表示区間**（シーン全体／セリフ区間／オフセット）、**入場・退場**（なし／フェード／スライド／拡大と長さ）を編集できます。入場・退場の既定はどちらも「なし」です。描画順は 背景 → カード → 立ち絵 → 字幕 → オーバーレイ の順で固定です。
  - 「セリフ区間」では、開始・終了のセリフを `番号. 話者名 — 字幕先頭` で選べます。開始を選ぶと、終了はそれ以降のセリフだけが候補になります。開始を終了より後へ変えると終了は開始へ補正され、セリフを並べ替えて範囲が逆転しても自動で整います。長い字幕はセレクト内で省略され、選択中の開始・終了は下に全文が表示されます。
- 各シーンに **立ち絵** を左右1体ずつ、最大2体まで指定できます。
  - キャラクターと外観は、編集画面の「キャラクター」セクションで追加し、外観はライブラリで登録します。
  - **左**・**右** の2枠が常に表示されます。各枠で **キャラクター** を選ぶと **外観** と **倍率**（幅480px基準、0.1〜3.0）が表示されます。キャラクターを「未指定」に戻すとその枠を外せます。枠を増やしたり位置を選んだりする操作はありません。
  - 立ち絵は画面の左右端いっぱいに寄せて表示され、倍率を変えても端からの余白は一定です。
  - キャラクターを選んだ枠では、**入場・退場**（なし／フェード／スライド／拡大と長さ）も設定できます。既定はどちらも「なし」です。
  - セリフを話している立ち絵は、そのセリフの間だけゆっくり上下に弾みます。話者が対応していない立ち絵は静止します。立ち絵の表示はセリフや音声の選択とは別に設定します。
  - 外観に表情セットを割り当てると、セリフごとの **表情** で切り替わります。セリフの区間以外は通常の表情に戻ります。シーンを分割する必要はありません。
  - 閉眼レイヤーを登録した目は、立ち絵が表示されている間ずっと決まったタイミングで **瞬き** します。開口レイヤーを登録した口は、セリフを話している間だけ不規則に **口パク** します。どちらもプレビューと出力で毎回同じ動きになります。登録がなければ静止したままです。
- **BGM（作品全体）** を1曲指定できます。ループの有無と音量（dB、既定 -18）を設定します。素材ピッカーから追加・変更できます。

:::note[固定尺の音声超過]
固定尺を選んだシーンで、音声の合計が固定尺を超えていると保存はできますがレンダー時にエラーになります。シーンの下の表示で区間を確認し、尺を延ばすか音声を調整してください。
:::

### 保存

編集内容は自動保存されません。画面上部の「保存」を押したときに、新しい版として保存されます。

- 保存のたびに新しい版が作られ、過去の版は変更されません。
- テキストがテンプレートの目安を超えると、保存は成功しますが警告が表示されます。内容を確認して修正してください。
- 入力に問題がある場合は保存されず、エラーが表示されます。

### プレビュー

編集画面の右ペインのプレビューでは、編集中の台本が動画の完成イメージとして再生できます。

- 有効な未保存の編集は、少し待つと自動でプレビューに反映されます（「未保存の変更を反映しています」と表示されます）。保存しなくても、Cueの追加などの見た目を確認できます。
- プレビューは確認用の表示であり、**保存・レンダーの対象は常に最後に保存した版**です。プレビューで確認した内容を残すには「保存」を押してください。
- 入力が一時的に不正なときやプレビューの生成に失敗したときは、直前の表示を保ち「未保存の変更が未反映です」と表示されます。失敗したときだけ「再試行」が出ます。
- 台本で指定した素材（背景など）は、取り込みが終わったものだけ表示されます。取り込み中の素材がある版はエラーになります。
- 再生コントロールで次の操作ができます。**再生／一時停止**、**コマ送り／コマ戻し**（1フレーム＝1/30秒）、**前／次のセリフ**、**前／次のシーン**、**±x秒**（移動量は1・5・10秒から選択）。プレビュー下部のシークバーをクリック・ドラッグすると任意の位置へ移動でき、右側に現在時刻と総尺が表示されます。シーン・セリフ・Cueの先頭へ移動するときは、境界の前フレームが表示されるのを避けるため1フレーム後へ移動します。停止中に移動しても停止のままです。
- 下のシーンのボタンを押すと、そのシーンの先頭へ移動します。
- プレビューの表示領域にフォーカスがあるときは、キーボードでも操作できます。`Space`（再生／一時停止）、`←`/`→`（移動量だけ戻る／進む）、`Shift+←`/`Shift+→`（コマ戻し／送り）、`J`/`L`（前／次のセリフ）、`Shift+J`/`Shift+L`（前／次のシーン）。入力欄やボタンにフォーカスがあるときは通常の操作が優先されます。

### レンダー

編集画面の右ペインのレンダーでは、保存済みの台本からMP4を出力します。

- 「MP4を出力」を押すと、その時点の保存済み版でレンダーが始まります。実行中の表示が出ている間は、新しいレンダーを開始できません。
- 履歴には状態（待機中・実行中・完了・失敗・キャンセル済み）と対象の版が表示されます。待機中のものは「キャンセル」で取り消せます。
- 完了したものはその場で再生・シークできます。
- 失敗したときは理由が表示されます。素材が取り込み中の版はエラーになるため、素材の準備完了を待って再実行してください。
