# Web UI の使い方

Kakeai の Web UI は、ブラウザで作品と台本を編集する画面です。

## 表示テーマ

画面右上の「テーマ」ボタンで、システム / ライト / ダークを切り替えられます。既定はOSの設定に従います。

## 作品一覧

トップページに作品の一覧が表示されます。

- **作成**: 上部の入力欄に作品名を入れて「作成」を押すと、新しい作品が作られます。
- **開く**: 作品名を押すと編集画面を開きます。
- **削除**: 「削除」を押すと、その作品と台本の履歴がすべて消えます。元に戻せません。
- 詳しくは [作品の管理](../works/works.md) を参照してください。

## 素材ライブラリ

画面右上の「素材」から、全作品で使える素材（画像・動画・音声）を管理します。

- **アップロード**: ファイルを選ぶか、点線の枠内にドラッグ&ドロップします。複数ファイルをまとめて選べ、一覧を確認してからアップロードできます。取り込みが終わると状態が「準備完了」になります。
- 取り込み中は「取り込み中」、失敗したときは「失敗」と表示されます。同じ内容のファイルは自動的にまとめられ、二重には保存されません。
- **削除**: 「削除」を押すと素材を削除します。台本などで使用中の素材は削除できません。
- 詳しくは [素材ライブラリ](../assets/assets.md) を参照してください。

## 音声プロファイル

画面右上の「音声」から、全作品で共通に使う声の設定（音声プロファイル）を管理します。VOICEVOX ENGINE に接続して、話者と既定スタイルを選びます。

- セリフの音声は、このプロファイルをキャラクターに割り当てて生成します。
- 詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。

## キャラクターライブラリ

画面右上の「キャラクター」から、全作品で使えるキャラクターを登録します。

- **キャラクターを追加** で名前を入力し、**声プロファイル** を選びます。
- キャラクターごとに **外観を追加** します。外観は画像1枚と、表示名（例「夏服」）・表情・ポーズのタグを持ちます。画像は素材ライブラリの準備完了済み画像から選びます。
- 台本には、編集画面の「キャラクター」から「ライブラリから追加」でコピーして使います。作品ごとに名前や声を調整できます。
- 外観の追加・編集はライブラリで行います。作品独自の外観は、別の外観としてライブラリに登録してください。

## 台本の編集

編集画面では、導入・要点（0件以上）・結びの順にシーンを編集します。新規作品は導入＋要点3つ＋結びで始まります。

- 各シーンのテキスト（タイトル、サブタイトル、見出し、本文、結びの文言）を入力します。
- **アクセント色** をシーンごとに選びます。
- **尺** は「自動」または「固定」を選びます。導入と結びは固定尺のミリ秒を指定できます。自動では、音声の長さ（音声なしのセリフは2.5秒）に前後の0.5秒を足してシーン尺を決めます。各シーンの下に、算出後のシーン尺と各セリフの区間が表示されます。
- **キャラクター** セクションで、この作品で使うキャラクターを「ライブラリから追加」します。名前と声プロファイルは作品ごとに変更できます。「声だけの話者を追加」で、立ち絵を持たないナレーターを作れます。
- 要点シーンには **セリフ** を追加できます。字幕テキストと、読み上げ用のテキストを入力します。
  - セリフごとに **キャラクター** を選べます。声はそのキャラクターの声プロファイルから決まります。
  - セリフごとに **音声** を追加できます。「選択」でピッカーを開き、音声素材を選ぶと候補として追加され、そのセリフに使われます。候補は複数持て、ラジオで切り替え、「音声を解除」で字幕だけにできます。候補の「削除」もできます。各候補は **再生** で確認できます。
  - キャラクターに声プロファイルを割り当てると **TTS生成** が使えます。スタイルと話速を選んで生成すると、候補として追加され自動選択されます。生成には入力中の読み上げテキストが使われ、**保存しなくても生成できます**（新しいセリフは一度保存すると生成できます）。生成後に保存すると、まとめて1つの版になります。詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。
  - ピッカーの中から新しい音声ファイルをアップロードできます。ピッカー内へのドラッグ&ドロップや複数ファイルの同時追加にも対応します。
  - 字幕テキストは動画に焼き込まれ、そのセリフの区間に表示されます。
- 要点シーンは「↑」「↓」で並べ替え、「削除」で取り除けます。下の「要点を追加」で増やせます。並べ替えや保存をしてもIDは変わりません。
- 各シーンに **背景** と **カード** をそれぞれ1件まで指定できます。背景は一番後ろ、カードはその上に表示されます。カードには見出しと補足文を付けられます。
  - 「選択」でピッカーを開き、画像または動画を選びます。「解除」で外します。
  - ピッカーの中から新しいファイルをアップロードできます。ピッカー内へのドラッグ&ドロップや複数ファイルの同時追加にも対応します。取り込みが終わるまでその素材は選べません。
- 各シーンに **立ち絵** を1件まで指定できます。描画順は背景、カード、立ち絵、シーン本文・字幕の順です。
  - キャラクターと外観は、編集画面の「キャラクター」セクションで追加し、外観はライブラリで登録します。
  - シーンではキャラクターと外観を選び、**x**・**y**（画面内の正規化座標、0〜1、画像の中心）と **倍率**（幅480px基準、0.1〜3.0）を数値で指定します。「解除」で外せます。
  - 立ち絵の表示はセリフや音声の選択とは連動しません。
- **BGM（作品全体）** を1曲指定できます。ループの有無と音量（dB、既定 -18）を設定します。素材ピッカーから追加・変更できます。

:::note[固定尺の音声超過]
固定尺を選んだシーンで、音声の合計が固定尺を超えていると保存はできますがレンダー時にエラーになります。シーンの下の表示で区間を確認し、尺を延ばすか音声を調整してください。
:::

### 保存

編集内容は自動保存されません。画面上部の「保存」を押したときに、新しい版として保存されます。

- 保存のたびに新しい版が作られ、過去の版は変更されません。
- テキストがテンプレートの目安を超えると、保存は成功しますが警告が表示されます。内容を確認して修正してください。
- 入力に問題がある場合は保存されず、エラーが表示されます。
- 「保存してプレビュー」を押すと、保存したうえで下部のプレビューへ移動し、その版を表示します。編集結果をすぐ確認したいときに使います。

### プレビュー

編集画面の下部にあるプレビューでは、保存済みの台本が動画の完成イメージとして再生できます。

- プレビューは未保存の編集中の内容ではなく、最後に保存した版を表示します。編集したら先に「保存」または「保存してプレビュー」を押してください。
- 「更新」を押すと、現在の版のプレビューを作り直します。
- 台本で指定した素材（背景など）は、取り込みが終わったものだけ表示されます。取り込み中の素材がある版はエラーになります。

### レンダー

編集画面の下部にあるレンダーでは、保存済みの台本からMP4を出力します。

- 「MP4を出力」を押すと、その時点の保存済み版でレンダーが始まります。実行中の表示が出ている間は、新しいレンダーを開始できません。
- 履歴には状態（待機中・実行中・完了・失敗・キャンセル済み）と対象の版が表示されます。待機中のものは「キャンセル」で取り消せます。
- 完了したものはその場で再生・シークできます。
- 失敗したときは理由が表示されます。素材が取り込み中の版はエラーになるため、素材の準備完了を待って再実行してください。
