# 編集画面の詳しい操作

編集画面の基本的な流れは[編集画面の基本操作](./editor-basics.md)を参照してください。このページでは、映像テーマやシーン編集など、細かな操作を説明します。

## 表示テーマ

画面右上の「テーマ」ボタンで、システム / ライト / ダークを切り替えられます。既定はOSの設定に従います。この設定は編集画面の見た目だけに影響し、出力動画の配色（下の「映像のテーマ」）とは別です。

## 映像のテーマ

出力動画の配色・文字・世界観（スキン）の既定値は Visual Theme が決めます。作品編集画面の「テーマ (Visual Theme)」で公開済みのテーマリビジョンを選び、台本を保存するとその作品に固定されます。詳しくは [Visual Theme のカスタマイズ](../theme-customization.md) を参照してください。

- シーンごとに **アクセント** を選びます。**テーマ色**（プライマリ／セカンダリ／ターシャリ）または **自由色** を選べます。背景はアクセントを温白色に溶かした柔らかい色になります。
- **テキスト** 映像演出で指定しない項目（フォント・サイズ・色・装飾など）は、役割（本文・見出し・タイトル・サブタイトル・結びの文言）ごとのテーマのスタイルで描画されます。個別に指定した項目はそちらが優先されます。
- テーマが **世界観（スキン）** を選ぶと、対応する表現（紙・テープなど）でタイトル・画像カード・要点・引用が描画されます。スキン未対応のテンプレート（表・グラフなど）は標準描画のままです。

## 作品一覧

トップページに作品の一覧が表示されます。

- **作成**: 上部の入力欄に作品名を入れて「作成」を押すと、新しい作品が作られます。
- **開く**: 作品名を押すと編集画面を開きます。
- **削除**: 「削除」を押すと、その作品と台本の履歴がすべて消えます。元に戻せません。
- 詳しくは [作品の管理](../works/works.md) を参照してください。

## 素材ライブラリ

画面右上の「素材」から、全作品で使える素材（画像・動画・音声）を管理します。

- **アップロード**: ファイルを選ぶか、点線の枠内にドラッグ&ドロップします。複数ファイルをまとめて選べ、一覧を確認してからアップロードできます。取り込みが終わると状態が「準備完了」になります。
- 取り込み中は「取り込み中」、失敗したときは「失敗」と表示されます。同じ内容のファイルは自動的にまとめられ、二重には保存されません。
- **削除**: 「削除」を押すと素材を削除します。台本などで使用中の素材は削除できません。
- **タグ**: 素材にタグを付けて分類し、タグで絞り込めます。ピッカーでもタグで絞り込めます。
- 詳しくは [素材ライブラリ](../assets/assets.md) を参照してください。

## 音声プロファイル

画面右上の「音声」から、全作品で共通に使う声の設定（音声プロファイル）を管理します。新規作成時に ENGINE を選び、接続したエンジンの声を選びます。声には言語が付きます。

- セリフの音声は、このプロファイルをキャラクターに割り当てて生成します。
- 詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。

## キャラクターと表情セット

キャラクターライブラリと表情セットの登録・更新方法は、[キャラクターと表情セット](../characters-and-expressions.md)を参照してください。

## Composition Library

Composition Library の確認方法と台本での使い方は、[Composition Library](../composition-library.md)を参照してください。

## 台本の編集

編集画面では、導入・要点（0件以上）・結びの順にシーンを編集します。新規作品は導入＋要点1つ＋結びで始まります。

- 画面は3つのペインに分かれます。**左**はCue対応マップ（Scene・セリフ・映像演出の対応を見渡すナビゲーション）、**中央**は編集、**右**はプレビューとレンダーです。ペインの境目をドラッグすると幅を変えられます。左の項目を選ぶと、中央がその箇所へスクロールし、右のプレビューがその位置へ移動します。ジャンプ先は、右に表示中のプレビュー（下の「プレビュー」参照）の時刻に基づきます。中央をスクロールすると、いま表示している項目が左でハイライトされます。
- Cue対応マップでは、すべてのSceneが上から下へ1本の地図として並びます。左端の細いSceneレールには種別とシーン名が縦書きで出ます。セリフの行には、要点Sceneの全体通しの番号（例 `4.1`）と字幕の先頭が出ます。セリフのないSceneは3行ぶんのブロックで表示されます。セリフ本文の右端には映像演出レーンが重なり、各映像演出は表示区間と重なる行を貫く帯として出ます。帯は半透明なので、下のセリフ本文は右端まで読めます。右端が最も奥（背景）で、左へ行くほど前面（カード・立ち絵・オーバーレイ）になり、同時に表示されない映像演出は同じレーンを使い回します。レーンはSceneごとにリセットされ、各Sceneで最も奥の映像演出が右端に来るよう右詰めに表示されます。レーンは最大6本で、ペインが広いほど増えます。帯の先頭にはテンプレートの種別マーカーと、素材があれば小さなサムネイルが出ます。帯にホバーするかキーボードでフォーカスすると、テンプレート名・レイヤー・順序・表示区間・素材の拡大プレビューが出ます。帯を選ぶと中央の映像演出の編集欄へスクロールし、プレビューが映像演出の開始へ移動します。セリフ行の選択は従来どおりセリフ編集欄とそのセリフへ移動します。時間指定（オフセット）の映像演出で、表示中のプレビューの時刻が未確定、または解決済み区間がどのセリフ行とも交差しないものは、帯の代わりにセリフ行領域の左端の時計マーカーで示します。レーンに収まらない映像演出は右端に `+N` としてまとめられ、開くと一覧から選んで移動できます。再生中は現在の時刻を含む行・Scene・有効な映像演出の帯がハイライトされます。マウスだけでなく、Tab移動とEnter/Spaceでも同じ情報と操作にアクセスできます。
- ペインの幅の比率はブラウザに記憶され、開き直しても復元されます（作品のデータには保存されません）。左の構成メニューの「レイアウトをリセット」で既定の比率に戻せます。プレビューは広く開けます。
- 画面が狭いときは、左の構成がドロワーになり、中央の **編集** と右の **確認**（プレビューとレンダー）を切り替えて使います。切り替えても入力内容・未保存の状態・プレビューの位置は保たれます。ドロワーの項目を押すと編集に戻って該当箇所へ移動します。
- 各シーンは折りたためます。見出しの左端にある開閉ボタンでそのシーンだけを開閉し、画面上部の「すべて開く」「すべて閉じる」で全シーンを一括で開閉します。各シーン内の **映像演出**・**シーン音声**・**セリフ** もそれぞれ開閉でき、挿入シーンにはセリフ欄がありません。開閉の状態はブラウザに記憶され（作品のデータには保存されません）、開き直すと前回の状態に戻ります。左の構成や警告・エラー一覧から移動すると、対象のシーンと欄が自動で開きます。

- 各シーンの見出しには **シーン名（ラベル）** の入力欄、種別バッジ、複製・移動・削除の操作がまとまっています。見出しは折りたたんでも常に表示され、セリフ件数・映像演出件数・シーン尺と、未音声や警告・エラーがあれば件数も出ます。これは映像には表示されない編集用の名前で、左の構成メニューや右のプレビューのシーンボタンに表示されます。見出しを映像に出したいときは、映像演出の一覧の **テキスト** 映像演出（役割「見出し」）に入力します。ラベルは並べ替えても自動では変わりません。
- 各シーンのテキスト（タイトル、サブタイトル、見出し、本文、結びの文言）は、映像演出の一覧の **テキスト** 映像演出として編集します。新規シーンには役割ごとのテキスト映像演出があらかじめ入っています。テキストと役割は常時表示され、位置・フォント・色・装飾は「文字スタイル」に畳まれています。
- **アクセント** をシーンごとに選びます。**テーマ色**（プライマリ／セカンダリ／ターシャリ）または **自由色** を選べます。アクセント・尺・シーン切替は「シーン設定」に畳まれています。
- **尺** は「自動」または「固定」を選びます。導入と結びは固定尺のミリ秒を指定できます。自動では、音声の長さ（音声なしのセリフは2.5秒）に各セリフの「前の間」と前後の0.5秒を足してシーン尺を決めます。各シーンの下の「尺を表示」を開くと、算出後のシーン尺と各セリフの区間・間を確認できます。
- **シーン切替** で、直前のシーンからの切り替え方を選べます。カット（既定）／フェード（暗転を挟む）／クロスフェード。尺はミリ秒で指定し、隣り合うシーンの短い方の尺を超える値は保存時にエラーになります。先頭シーンには設定できません。
- **キャラクター** セクション（折りたたみ）で、この作品で使うキャラクターを「ライブラリから追加」します。名前と声プロファイルは作品ごとに変更できます。「声だけの話者を追加」で、立ち絵を持たないナレーターを作れます。
- 要点シーンには **セリフ** を追加できます。字幕テキストと、読み上げ用のテキストを入力します。
  - セリフごとに **キャラクター** を選べます。声はそのキャラクターの声プロファイルから決まります。
  - セリフごとの **音声** と **表情** は「音声詳細」にまとまっています。表情は、そのセリフの話者の立ち絵に表情セットが割り当てられているときだけ表示され、そのセリフの間だけ表情が切り替わります。選ばないときは通常の表情です。話者がないセリフには付けられません。候補はその作品が固定している表情セットの版から作られます。立ち絵や表情セットの変更で使えなくなった表情は、警告と「クリア」で直せます。
  - セリフごとに **音声** を追加できます。「音声追加」でピッカーを開き、音声素材を選ぶと候補として追加され、そのセリフに使われます。候補は複数持て、ラジオで切り替え、「音声解除」で字幕だけにできます。「音声解除」「音声追加」は候補一覧の下に横並びで並びます。不要になった候補は「候補削除」で消します（音声解除は候補を残したまま使わない選択だけを外します）。各候補は **再生** で確認できます。
  - キャラクターに声プロファイルを割り当てると **TTS生成** が使えます。声と話速を選んで生成すると、候補として追加され自動選択されます。生成には入力中の読み上げテキストが使われ、**保存しなくても生成できます**（新しいセリフは一度保存すると生成できます）。生成後に保存すると、まとめて1つの版になります。詳しくは [音声プロファイルと読み上げ（TTS）](../tts/tts.md) を参照してください。
  - ピッカーの中から新しい音声ファイルをアップロードできます。ピッカー内へのドラッグ&ドロップや複数ファイルの同時追加にも対応します。
  - 字幕テキストは動画に焼き込まれ、そのセリフの区間に表示されます。テーマ欄の「字幕に話者名を表示」を付けると、話者名の小さなタブが字幕枠の左上に重なります（焼き込みのみ・SRTは名前なし・話者なしと空名はタブなし）。
  - セリフごとに **前の間（ms）** を指定できます。指定した長さだけ、そのセリフの直前に字幕・読み上げ・立ち絵の発話演出のない間が入ります。先頭のセリフにも指定できます。新しく追加したセリフ（「セリフを追加」・台本インポート）の初期値は500msです。既存のセリフは変更されず、空欄は0として扱います。
  - 各セリフの先頭に `番号. 話者名 — 字幕先頭` の連番が表示され、番号で見分けられます。話者未設定は「話者なし」、字幕が空なら「（字幕なし）」と表示されます。番号は保存されず、並べ替えや分割で自動的に振り直されます。
  - 各セリフの見出しの `▶` で、プレビューだけをそのセリフの先頭へ移動できます（中央の編集位置は変わりません）。
  - 各セリフの `…` メニューから「上へ」「下へ」「このセリフの前でシーンを分割」「複製」「削除」を選べます。「上へ」「下へ」ではセリフのID・話者・字幕・読み・音声が保持され、TTSを再生成する必要はありません。「複製」は話者・字幕・読みだけを複製し、音声は複製しません。「削除」では、そのセリフを表示区間に使っている映像演出があると確認が出ます。削除すると該当する映像演出の区間は残りのセリフへ調整され、そのセリフ1件だけを指していた映像演出は削除されます。
- 「このセリフの前でシーンを分割」を選ぶと、そのセリフ以降を新しい要点シーンとして直後に切り出します。元のシーンの見出し・背景・立ち絵は新しいシーンへコピーされないため、新しいシーンは空の見出し・本文から編集します。セリフに追随する映像演出は分割先へ移動し、両方をまたぐ映像演出は前半と後半に分かれます。導入・結びや、セリフが1件以下の要点シーンでは分割できません。
- 要点シーンは「↑」「↓」で並べ替え、「削除」で取り除けます。並べ替えてもスクロール位置が先頭へ戻らないので、「↑」「↓」を続けて押せます。下の「追加位置」で「（シーン名）の前」か「結びの前」を選び、「要点を追加」で増やせます。追加したシーンが見える位置へ自動でスクロールします。「動画を挿入」も同じ追加位置に従います。並べ替えや保存をしてもIDは変わりません。
- 「台本をインポート」で、章立ての台本をまとめて要点シーンに取り込めます。`## 見出し` の行が要点シーンのシーン名（ラベル）、`話者名: セリフ`（全角コロン `：` も可）の行がセリフ（字幕テキストと読み上げテキスト）になります。1行が1セリフです。取り込んだシーンの見出しのテキスト映像演出は空のままなので、映像に見出しを出すには映像演出の一覧で入力します。
  - 取り込む前に、台本中の話者名を作品内の話者へ割り当てます。名前が完全一致する話者が1人だけなら自動で選ばれ、候補がない・同名が複数あるときは選ぶまで反映できません。「話者なし」（字幕のみ）も選べます。話者は自動作成されません。
  - 反映先は「既存の要点シーンを置き換える」（既定）か「末尾へ追加する」を選べます。置き換えでも導入・結び・キャラクター・BGM・素材・話者設定は残ります。
  - 見出しより前のセリフ、空の見出し・話者名・セリフ、セリフのない章、書式に合わない行はエラーになり、反映できません。
  - 取り込みは未保存の編集内容を更新するだけで、保存済みの台本の版は「保存」を押すまで変わりません。取り込んだセリフの音声は未設定なので、必要に応じて [TTS](../tts/tts.md) を生成します。
- 要点シーンの見出し左の「前のシーンを複製」は、直前の要点シーンの見た目（アクセント・尺・シーン切替・映像演出・立ち絵）をそのまま複製し、新しい要点シーンとして直後に追加します。セリフと音声は複製されません。直前が導入（要点でない）ときは押せません。
- 各シーンには **映像演出の一覧** があり、**背景**・**カード** などの表示要素を追加できます。
  - 「新しい映像演出」でテンプレートを選び、「映像演出を追加」を押します。各映像演出の `…` メニューから「複製」「別のシーンへ移動…」「別のシーンへ複製…」「削除」を選べます。「複製」は同一シーンの同じレイヤー末尾に複製します（未保存の追加分は保存後に複製できます）。「別のシーンへ移動…」では1つのシーンへ移動し、「別のシーンへ複製…」では複数のシーンへ複製できます。別のシーンへ移すと表示区間はシーン全体に戻り、セリフ同期のトリガーはシーン全体に変わるので、移動先で選び直してください。背景・カードは画像・動画の素材のほか、**デバイスフレーム**（端末枠の中に画像・動画を表示する複合ビジュアル）や **サイトモックアップ**（X・GitHub・Qiita・ブラウザなど有名サイトのガワに画像・動画を収める）も選べます。**テキスト** 映像演出では役割（本文・見出し・タイトル・サブタイトル・結びの文言）・左右位置・上下位置・フォント・サイズ・色・装飾（太字・斜体・縁取り・影）を設定できます。色はカラーピッカーで選び、装飾は「既定・オン・オフ」のボタンで切り替えます。「既定」は映像テーマの役割別スタイルを使う設定です。
  - サイトモックアップは種類（variant）・テーマ（ライト/ダーク）・表示名・ハンドル・URL・本文・任意ロゴを設定できます。ロゴは同梱されないため、利用者が用意した画像を選びます。ブランドの利用条件は利用者が確認してください。
  - 素材を選び、テンプレートごとの項目（見出し・補足文・フレーム種別・背景色・画面の登場アニメーションなど）を編集します。カードでは**アスペクト比**（16:9・4:3・1:1・3:4・9:16、既定16:9）を選べます。見出しと補足文を両方とも空にすると、テキスト用の枠は表示されません。**デバイスフレーム**では、スマートフォン枠にステータスバー、ノートPC枠に開いたノートPCのベース（キーボード・トラックパッド・スピーカー）が既定で表示されます（それぞれオフにもできます）。
  - 背景とカードでは **焦点位置** を編集できます。横・縦のスライダー（0〜100%）で、画像・動画の見せたい部分を中央からずらせます。**中央に戻す** を押すと中央クロップに戻ります（このとき設定は省略されます）。「全体を収める（contain）」でも位置は保持されます。
  - 同じ欄の **倍率** スライダー（50〜300%）で、中の画像・動画だけを拡大・縮小できます（カードの枠や文字の配置は変わりません）。**等倍に戻す** を押すと等倍に戻ります（このとき設定は省略されます）。100%未満にすると、カードの矩形や背景フレームとの間にすき間ができます。
  - 背景とカードの動画では **動画をループ再生**（既定・オン・オフ）を選べます。オンにすると、動画素材がその映像演出の表示区間より短いときに、区間いっぱいまで繰り返し再生します。動画素材が区間以上に長いときはループせず、区間の長さで切り取られます。画像や、デバイスフレーム・サイトモックアップの中の動画には効きません。
  - **表** の映像演出では、列（見出し・種類・揃え・書式）と行を編集します。数値の書式は整数・小数・百分率・通貨から選び、百分率は比率で入力します（0.25→25%）。「CSV貼り付け」にカンマ区切りを貼って「取り込む」を押すと、先頭行を見出しとして取り込めます（上限を超えた分は切り捨てられます）。登場や強調は **セリフ同期の効果** で設定します。
   - **棒グラフ** の映像演出では、先頭の列をカテゴリ、2列目以降を系列として棒を描きます（系列は最大4本、複数系列では凡例が出ます）。タイトル・向き（縦棒／横棒）・目盛り線・値ラベル・軸の単位・色分け（系列ごと／カテゴリごと）を設定できます。データは表と同じグリッドで編集し、CSV貼り付けも使えます。登場は **セリフ同期の効果** で「伸ばす／弾ませる／フェード」から選び、カテゴリごとにずらして表示できます。負の値は0として描画され、保存時に警告が出ます。
   - **数値** の映像演出では、大きな数値・ラベル・補足・書式（整数／小数／百分率／通貨）・トーン・カード表示を設定します。**セリフ同期の効果** の「数値カウント」で、**開始値** から **数値**（カウント後の値）までカウントできます。開始値が数値より小さければカウントアップ、大きければカウントダウンになります（新規は 0 → 100）。
   - **フロー図** の映像演出では、ノード（名前・補足）と辺（から／へ・ラベル）を編集します。ノードは **↑／↓** で並び替えでき、辺の参照とセリフ同期の効果の対象も自動で追従します。向き（横／縦）と枠（シンプル／ボックス）を選べます。**セリフ同期の効果** でノードを登場・強調できます。
    - **ポイント** の映像演出では、箇条書きの見出しと各ポイントの文言を編集します。幅（長い・中くらい・短い）と揃え（左揃え・中央揃え・右揃え）を選べます。幅は見出しとポイント列の両方に効き、見出しはリストと同じ幅に揃います。揃えは文言の文字揃えで、リストの束は画面中央に置いたままです。各ポイントは、特定のセリフ区間を契機に枠・背景で強調（または登場）でき、区間の終わりで元に戻ります。
    - **引用** の映像演出では、引用の文言と、任意の著者・出典を編集します。色（7トーン）は引用符や左罫線のアクセントに、スタイル（シンプル／カード）は見た目の枠に使います。**セリフ同期の効果** で、特定のセリフ区間を契機に引用を枠・背景・スポットライトで強調でき、区間の終わりで元に戻ります。スポットライトでは著者と出典が暗くなります。
    - **チャット** の映像演出では、タイトルとメッセージ（名前・本文・左右・時刻・任意のアイコン画像）を編集します。**端末の枠** でスマートフォン（9:16）・ノートPC（16:9）・デスクトップ（21:9のワイド）・枠なし（全面）を選べ、同じ内容のまま幅の違いに追従して表示されます。スマートフォンでは上部に時刻・ダイナミックアイランド・Wi‑Fi・バッテリーのステータスバーが、下部に空の入力欄と送信アイコンの飾り（入力はできません）が付きます。スマートフォンとデスクトップの枠は、2行の字幕と重ならないよう字幕のぶんだけ上に寄せて表示するため、スマートフォンは以前より小さくなります。メッセージが多いときはプレビューで読みやすさを確認してください。ノートPCでは画面の下に、開いたノートPCのベース（キーボード・トラックパッド・スピーカー）が既定で付きます（「キーボードを表示」でオフにもできます）。会話は映像として見せるだけで、読み上げや字幕とは連動しません。**セリフ同期の効果** で、対象のメッセージ（または全メッセージ）を、特定のセリフ区間を契機に登場させたり、枠・背景・スポットライトで強調できます。対象のメッセージは本文のドロップダウンから選べます。
   - **表**・**棒グラフ** の映像演出では、**セリフ同期の効果** を追加できます。効果ごとに「対象」（表は行・セル・全行・全列、グラフはカテゴリ・系列・全棒）、「契機」（セリフ区間または映像演出全体）、「効果」（登場・強調）を設定します。セリフ区間を契機にすると、その区間で対象が登場したり、強調が始まり区間の終わりで元に戻ります。セリフの実時間は音声の長さから決まるため、セリフを編集すると同期も自動で追従します。
   - 各映像演出は **レイヤー**（背景・カード・オーバーレイ）と **順序**、**表示区間**（シーン全体／セリフ区間／オフセット）、**入場・退場**（なし／フェード／スライド／拡大と長さ）を「表示の詳細」で編集できます。入場・退場の既定はどちらも「なし」です。描画順は 背景 → カード → 立ち絵 → 字幕 → オーバーレイ の順で固定です。
  - 「セリフ区間」では、開始・終了のセリフを `番号. 話者名 — 字幕先頭` で選べます。開始を選ぶと、終了はそれ以降のセリフだけが候補になります。開始を終了より後へ変えると終了は開始へ補正され、セリフを並べ替えて範囲が逆転しても自動で整います。長い字幕はセレクト内で省略され、選択中の開始・終了は下に全文が表示されます。
- 各シーンに **立ち絵** を左右1体ずつ、最大2体まで指定できます。
  - キャラクターと外観は、編集画面の「キャラクター」セクションで追加し、外観はライブラリで登録します。
  - **左**・**右** の2枠が常に表示されます。各枠で **キャラクター** を選ぶと **外観** が表示されます。**倍率**（幅576px基準、0.1〜3.0、1が標準）と **端からの位置**（ギリギリ／少し余白あり・既定／中央より）、**高さ**（上／標準・既定／下）と **入場・退場**（なし／フェード／スライド／拡大と長さ、既定はどちらも「なし」）は「表示の調整」に畳まれています。キャラクターを「未指定」に戻すとその枠を外せます。枠を増やす操作はありません。見出しの `…` メニューから「別のシーンへ移動…」「別のシーンへ複製…」「別のシーンと入れ替え…」を選べます。左右まとめて置き換わり、移動ではこのシーンの立ち絵が削除され、入れ替えでは両シーンの立ち絵が交換されます。
  - 立ち絵は画面の左右端に寄せて表示され、倍率を変えても端からの余白は一定です。
  - **立ち絵画像を作るとき**は、同じ作品で使うキャラクター・ポーズ・表情を、背景が透明で同じ幅・高さのキャンバスにそろえることをおすすめします。足元などの基準位置もそろえ、身長や体格の差はキャンバス内での人物の大きさ・配置・描写で表現してください。人物を縦横に引き伸ばして画像寸法だけを合わせる必要はありません。既存画像のキャンバス比率が異なるときは、透明な余白を追加してそろえるか、プレビューを見ながらキャラクターごとに倍率を調整します。
  - セリフを話している立ち絵は、そのセリフの間だけゆっくり上下に弾みます。話者が対応していない立ち絵は静止します。立ち絵の表示はセリフや音声の選択とは別に設定します。
  - 外観に表情セットを割り当てると、セリフごとの **表情** で切り替わります。セリフの区間以外は通常の表情に戻ります。シーンを分割する必要はありません。
  - 閉眼レイヤーを登録した目は、立ち絵が表示されている間ずっと決まったタイミングで **瞬き** します。開口レイヤーを登録した口は、セリフを話している間だけ不規則に **口パク** します。どちらもプレビューと出力で毎回同じ動きになります。登録がなければ静止したままです。
- **BGM（作品全体）** を1曲指定できます（折りたたみ）。ループの有無と音量（dB、既定 -18）を設定します。素材ピッカーから追加・変更できます。
- 各シーンには **シーン音声** を追加できます。準備完了済みの音声素材を選び、**役割**（BGM／効果音／音源）・**ループ**・**音量**（dB）を設定します。
  - シーン音声はそのシーンの先頭から終端まで再生されます。複数追加すると重ねて再生されます。役割は音源の種類ではなく編集意図の分類で、音源の使い分けの目安にするものです。作品全体BGMとも重なります。
  - ループをオンにすると音源がシーンより短いときにシーンの終端まで繰り返し、オフのときは音源の終端かシーンの終端の早い方で止まります。
  - 作品全体BGMとシーン音声は別々に管理されます。一方の変更で他方が削除・変更されることはありません。開始オフセット・フェード・ダッキングは指定できません。

:::note[固定尺の音声超過]
固定尺を選んだシーンで、音声の合計と各セリフの「前の間」の合計が固定尺を超えていると保存はできますがレンダー時にエラーになります。シーンの下の表示で区間を確認し、尺を延ばすか音声・間を調整してください。
:::

### 保存

編集内容は自動保存されません。画面上部の「保存」を押したときに、新しい版として保存されます。

- 保存のたびに新しい版が作られ、過去の版は変更されません。
- テキストがテンプレートの目安を超えると、保存は成功しますが警告が表示されます。内容を確認して修正してください。字幕は2行までを目安とし、3行目から警告します。目安は全角換算（半角2文字=全角1文字）のため、英語では同じ行数により多くの文字が入ります。
- 入力に問題がある場合は保存されず、エラーが表示されます。

### プレビュー

編集画面の右ペインのプレビューでは、編集中の台本が動画の完成イメージとして再生できます。

- 有効な未保存の編集は、少し待つと自動でプレビューに反映されます（「未保存の変更を反映しています」と表示されます）。保存しなくても、映像演出の追加などの見た目を確認できます。
- プレビューは確認用の表示であり、**保存・レンダーの対象は常に最後に保存した版**です。プレビューで確認した内容を残すには「保存」を押してください。
- 入力が一時的に不正なときやプレビューの生成に失敗したときは、直前の表示を保ち「未保存の変更が未反映です」と表示されます。失敗したときだけ「再試行」が出ます。
- 台本で指定した素材（背景など）は、取り込みが終わったものだけ表示されます。取り込み中の素材がある版はエラーになります。
- 再生コントロールはツールバーにまとまっています。**再生／一時停止**、**コマ送り／コマ戻し**（1フレーム＝1/30秒）、**前／次のセリフ**、**前／次のシーン**、**±x秒**（移動量は1・5・10秒から選択）。プレビュー下部のシークバーをクリック・ドラッグすると任意の位置へ移動でき、右側に現在時刻と総尺が表示されます。シーン・セリフ・映像演出の先頭へ移動するときは、境界の前フレームが表示されるのを避けるため1フレーム後へ移動します。停止中に移動しても停止のままです。
- 下のシーンのボタンを押すと、そのシーンの先頭へ移動します。
- プレビューの表示領域にフォーカスがあるときは、キーボードでも操作できます。`Space`（再生／一時停止）、`←`/`→`（移動量だけ戻る／進む）、`Shift+←`/`Shift+→`（コマ戻し／送り）、`J`/`L`（前／次のセリフ）、`Shift+J`/`Shift+L`（前／次のシーン）。入力欄やボタンにフォーカスがあるときは通常の操作が優先されます。

### レンダー

編集画面の右ペインのレンダーでは、保存済みの台本からMP4を出力します。

- 「MP4を出力」を押すと、その時点の保存済み版でレンダーが始まります。実行中の表示が出ている間は、新しいレンダーを開始できません。
- 履歴は「履歴」に畳まれています。状態（待機中・実行中・完了・失敗・キャンセル済み）と対象の版が表示されます。待機中のものは「キャンセル」で取り消せます。
- 実行中は進捗がバーとパーセンテージで表示されます。
- 完了したものはその場で再生・シークできます。「MP4をダウンロード」でMP4ファイル（ファイル名は作品名と版番号）を取り出せます。
- 「削除」で不要になった出力ファイルを消せます。削除すると元に戻せず、履歴には「出力は削除済みです。」と表示されます。
- 完了した出力のメタデータ（解像度・ファイルサイズ・長さ・フレームレート・形式・映像／音声コーデック）が表示されます。
- 「字幕をダウンロード」を押すと、現在の保存済み版の字幕ファイル（SRT形式）をすぐに取り出せます。レンダーとは独立しているため、MP4の出力待ちは不要です。取り出したファイルはYouTubeの字幕としてそのまま取り込めます。
- 失敗したときは理由が表示されます。素材が取り込み中の版はエラーになるため、素材の準備完了を待って再実行してください。
