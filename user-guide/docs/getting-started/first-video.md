# はじめての動画を作る

作品を作成し、短い台本を MP4 に出力するまでの最短手順です。まずは既定のテーマと字幕だけで試せます。インストールがまだの場合は、先に[インストールと起動](./installation.md)を済ませてください。

## 1. 作品を作る

アプリのトップページで作品名を入力し、「作成」を押します。新しい作品には、導入・要点・結びのシーンが用意されています。

## 2. セリフを編集する

要点シーンのセリフに、動画で見せる字幕と読み上げ用テキストを入力します。セリフが無い場合は「セリフを追加」から追加してください。まずは短い内容で試すと、プレビューを確認しやすくなります。

音声がなくても MP4 を出力できます。音声を付ける場合は、対応する TTS エンジンを起動してから[音声プロファイルと読み上げ（TTS）](../tts/tts.md)の手順に進みます。

## 3. 保存してプレビューする

画面上部の「保存」を押して編集内容を保存します。右側のプレビューでシーンを再生し、字幕や映像を確認します。プレビューに未保存の変更が表示されていても、MP4 出力に使われるのは最後に保存した台本です。

## 4. MP4 を出力する

右側のレンダー欄で「MP4を出力」を押します。完了したら「MP4をダウンロード」で動画を取り出せます。
