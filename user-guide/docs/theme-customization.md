# Visual Theme のカスタマイズ

Kakeai では、動画全体の配色、フォント、文字スタイル、字幕やラベルの背景デザインを「Visual Theme」としてカスタマイズできます。

## テーマ一覧画面

グローバルナビゲーションの「テーマ」リンクからテーマ一覧画面へアクセスできます。

- **組み込みテーマ**: システム既定のテーマ（例: Soft Editorial）です。直接編集はできませんが「複製して編集」で新しいカスタマイズテーマを作成できます。
- **マイテーマ**: 利用者が作成・複製したカスタムテーマの一覧です。公開済みリビジョン番号や未公開の変更（Draft）状態、フォント欠落警告が表示されます。

## テーマの編集とライブプレビュー

テーマ詳細画面（`/themes/:themeId`）では、フォームの変更が右側の代表サンプルプレビューへリアルタイムに反映されます。

### 設定項目

1. **配色・トークン**: キャンバス背景色、文字インク色、アクセントカラー（プライマリ・セカンダリ・ターシャリ）、カード背景色（surface）を設定できます。
2. **文字スタイル**: タイトル、見出し、本文、結び、字幕、ラベル等の役職（Text Role）ごとに、フォントカテゴリ（ゴシック/明朝/等幅）、フォントサイズ、文字色、太字・斜体・影・縁取り装飾を設定できます。macOS環境ではローカル端末のフォントを指定可能です。
3. **テキスト囲み・背景**: 字幕（caption）およびチャプターラベル（label）の背景囲み色、不透明度、余白（パディング）、角丸サイズを調整できます。
4. **世界観（スキン）**: 動画全体の描写スタイルを選びます。`Neutral` は標準描画、`Handmade Paper` は紙とテープで情報を整理した編集ノート風の世界観です。スキンが未対応のテンプレート（表、グラフなど）は標準描画のまま表示されます。スキン自体を利用者が作成・編集することはできません。

:::note[フォント欠落に関する注意]
テーマ内で指定したフォントが現在の端末に存在しない場合、警告アイコンが表示され、代替フォント（フォールバック）で描画されます。代表プレビューでは、指定フォントが HyperFrames と同じ Chromium で実際に解決できるかを診断し、解決できない場合は定義済みの代替で描画したうえで診断結果を知らせます。
:::

## ドラフト保存・公開・アーカイブ

- **Draft保存**: 編集内容を一時保存します（作品出力には影響しません）。
- **Draft破棄**: 保存前の変更を破棄します。
- **公開 (Publish)**: 現在のDraftを検証し、連番の新しい Theme Revision として公開・固定します。
- **アーカイブ**: 不要になったマイテーマをアーカイブ状態にします（過去の作品参照は維持されます）。

## 作品（Work）へのテーマ適用

作品編集画面（`/works/:workId`）の「テーマ (Visual Theme)」セクションから、公開済みのテーマリビジョンを選択し、作品の台本を保存することでテーマが作品に固定・適用されます。
