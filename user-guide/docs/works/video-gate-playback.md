# セリフゲート動画再生

セリフゲート動画再生は、**台詞の開始を目印（ゲート）にして動画を再生する**機能です。台詞が遅れているときだけ動画のフレームをそのまま保持し、次の台詞が始まったら動画の再生を続けます。台詞が早いときは停止も巻き戻しも起きません。

通常の動画CueはSceneの尺どおりに再生されますが、セリフゲート再生を使うと「動画が先に進みすぎた分」だけ映像を止めて、台詞と映像のずれを埋められます。

## 使える場所

動画素材を選べる次の場所で利用できます。

- **全画面の動画**（`media.full-bleed`）
- **枠つきカードの動画**（`media.card`）
- **端末フレーム内の画面動画**（`device-frame` の「画面」）
- **サイトモックアップ内の画面動画**（`site-mockup` の「画面」・「ロゴ」）

素材として**動画**を選んだときだけ、編集部品が表示されます。画像やCompositionを選んでいるあいだは表示されず、値も保存されません。

## 設定のしかた

1. 動画Cue（または端末フレームなどの入れ子の画面）で**動画素材を選びます**。取り込みが終わった動画を選んでください。
2. 「**セリフゲート再生を有効にする**」を押します。最初のゲートが1つ作成されます。
3. 各ゲートで次を設定します。
   - **台詞**: ゲートにする台詞（そのSceneの台詞から選びます）。台詞の並び順に自動で整列します。
   - **source(ms)**: その台詞が始まる瞬間に動画のどの位置（ミリ秒）を表示するか。0が動画の先頭です。
   - **この区間の音声を出す**: オンにすると、そのゲートの再生区間だけ動画の埋め込み音声を出します。
     - **音量(dB)**: 0が元の音量、負で小さく、正で大きく（-60〜+12 dB）。
     - **フェードイン(ms) / フェードアウト(ms)**: 区間の入り口・出口の音声フェードです。
4. 「**ゲートを追加**」で台詞を増やせます。不要なゲートは「**削除**」で消します。「**解除**」でセリフゲート再生をやめ、通常の動画再生に戻ります。
5. **再生終端(ms)** を指定すると、動画を使う範囲の終わりを決められます。空欄は素材の末尾までです。

素材を差し替えると、以前のゲートは解除されます（新しい動画に合わせて設定し直してください）。

## どう再生されるか

- ゲートから次のゲートまでのあいだ、動画は `source(ms)` の位置から実時間で再生されます。
- 次のゲートより**早く**動画の該当位置へ着いてしまったときだけ、その位置のフレームを**保持**します。保持中は映像が止まり、音声は出ません。
- 次の台詞が始まると、保持していた位置から再生を再開します。後ろへ巻き戻すことはありません。
- 台詞が遅れていなければ（動画が間に合っていれば）停止もシークも起きません。

## 制約

- **通常の動画再生設定とは併用できません。** セリフゲート再生が有効な動画では、「ループ再生」「トリム開始(ms)」「トリム終了(ms)」は使えません。これらを使いたいときはゲートを解除してください。
- **インサートSceneでは使えません。** インサートSceneは動画を単体で再生する専用の仕組みです。セリフゲート再生はCueの映像として使います。
- **確定尺をもつ動画だけ**が対象です。取り込み中の動画は選べません。
- ゲートにする台詞は、そのCueと同じSceneの台詞を選びます。Cueが表示されていない範囲の台詞は指定できません。
- 初版では区間ごとの自動ダッキングは行いません。ゲートの音声と作品全体BGMを重ねたくない場合は、音量やフェードで調整してください。
- ゲートの `source(ms)` は、その台詞の順序に合わせて前から順に大きくなるように指定してください。

## インサートSceneとの違い

| | インサートScene | セリフゲート動画再生 |
| --- | --- | --- |
| 会話の扱い | 会話を一時停止して動画を丸ごと再生 | 会話はそのまま。台詞に合わせて映像を保持・再開 |
| 動画の尺 | Scene尺として自動設定 | Scene尺とは独立。ゲートで進行を制御 |
| 音声 | 埋め込み音声をそのまま再生 | ゲートごとに音声の有無・音量・フェードを指定 |
| 向いている用途 | ここで動画を1本見せたい | 台詞に映像を追従させたい |

埋め込み音声をもつ動画を単体で見せたいだけなら、[動画を挿入する（インサートScene）](./insert-scenes.md) を検討してください。
