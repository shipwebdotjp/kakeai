# 動画を挿入する（インサートScene）

会話の途中で素材動画をそのまま見せたいときは、Scene列に「動画を挿入」でインサートSceneを追加します。インサートSceneは会話を一時停止し、動画を映像と埋め込み音声ごと再生してから、元の会話へ戻ります。

## 追加のしかた

1. 編集画面のScene一覧の下にある「動画を挿入」を押します。
2. 素材ライブラリから動画を選びます。**尺が確定している動画**だけを選べます。取り込みが終わっていない動画は選び直してください。
3. 結びの直前にインサートSceneが追加され、動画の尺がScene尺に自動設定されます。

## 画面に表示されること

各インサートSceneには次が表示されます。

- **動画尺**: 選んだ動画の長さ。
- **音声ストリームあり / なし**: 動画に音声が含まれるか。
- **埋め込み音声を再生**: オンにすると動画の音声を映像と同時に再生します（既定でオン）。
- **作品全体BGMをこの区間で抑制**: 埋め込み音声が有効なあいだ、作品全体BGMが自動で下がります。

「動画を差し替え」で別の動画に変更でき、尺も新しい動画に合わせて更新されます。

## 音声の規則

- 埋め込み音声をオンにした区間では、動画の音声をScene先頭から末尾まで映像と同期して再生します。作品全体BGMは200msのフェードでこの区間だけ抑制され、重なりません。
- 動画に音声が無い場合や、埋め込み音声をオフにした場合は無音で再生されます。音声が無い動画をオンにしたときは保存時に警告が表示されます。
- Sceneごとの音声（Scene AudioCue）は、動画の音声と重ねて再生できます。音量はCueごとに調整してください。
- 通常の背景動画・カード動画はこれまでどおり無音のままです。

## 制約（初期版）

- 動画のトリム・ループ・速度変更・逆再生には対応していません。動画全体をそのまま再生します。
- インサートSceneにはセリフ・字幕・立ち絵を置けません。
- 複数の動画をつなぐインサートはできません。動画ごとにインサートSceneを追加してください。
- インサートSceneを削除しても、動画素材や他のSceneのCueは削除されません。
- 主動画の削除や別テンプレートへの変更はできません。別の動画へ差し替えてください。
