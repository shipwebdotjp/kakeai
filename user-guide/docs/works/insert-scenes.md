# 動画を挿入する（インサートScene）

会話の途中で素材動画をそのまま見せたいときは、Scene列に「動画を挿入」でインサートSceneを追加します。インサートSceneは会話を一時停止し、動画を映像と埋め込み音声ごと再生してから、元の会話へ戻ります。

## 追加のしかた

1. 編集画面のScene一覧の下にある「追加位置」で、動画を挿入する場所（各Sceneの前、または結びの前）を選びます。既定は結びの前です。
2. 「動画を挿入」を押し、素材ライブラリから動画を選びます。**尺が確定している動画**だけを選べます。取り込みが終わっていない動画は選び直してください。
3. 選んだ位置にインサートSceneが追加され、動画の尺がScene尺に自動設定されます。追加したSceneが見える位置へスクロールします。

## 画面に表示されること

各インサートSceneには次が表示されます。

- **動画尺**: 選んだ動画の長さ。使用区間を指定すると、その長さも表示されます。
- **トリム開始(ms) / トリム終了(ms)**: 動画のどの範囲を使うかをミリ秒で指定します。空欄は動画の先頭／末尾です。
- **ループ再生**: 使用区間をScene尺まで繰り返します。
- **音声ストリームあり / なし**: 動画に音声が含まれるか。
- **埋め込み音声を再生**: オンにすると動画の音声を映像と同時に再生します（既定でオン）。
- **音量(dB)**: 埋め込み音声の音量です。0 が元の音量、負の値で小さく、正の値で大きくできます（-60〜+12 dB）。
- **作品全体BGMをこの区間で抑制**: 埋め込み音声が有効なあいだ、作品全体BGMが自動で下がります。

「動画を差し替え」で別の動画に変更でき、尺も新しい動画に合わせて更新されます。

## トリムとループ

- **トリム**: 使用区間の開始と終了をミリ秒で指定します。ループをオフにすると、Sceneの尺は使用区間の長さに自動で合わせられます。
- **ループ**: 使用区間をScene尺まで繰り返します。ループがオンのときはScene尺を使用区間以上にしてください（使用区間より短い尺は保存できません）。使用区間を指定せずループだけをオンにすると、動画全体を繰り返します。
- 映像と埋め込み音声は同じ使用区間で再生されるため、トリムしても音がずれません。

## 音声の規則

- 埋め込み音声をオンにした区間では、動画の音声を使用区間だけ映像と同期して再生します。音量は「音量(dB)」で調整でき、0が元の音量です。作品全体BGMは200msのフェードでこの区間だけ抑制され、重なりません。
- 音量を大きく（0dB超）した場合、プレビューでは0dB相当で頭打ちになりますが、書き出したMP4には指定した音量が反映されます。
- 動画に音声が無い場合や、埋め込み音声をオフにした場合は無音で再生されます。音声が無い動画をオンにしたときは保存時に警告が表示されます。
- Sceneごとの音声（Scene AudioCue）は、動画の音声と重ねて再生できます。音量はCueごとに調整してください。
- 通常の背景動画・カード動画はこれまでどおり無音のままです。

## 制約（初期版）

- 動画の速度変更・逆再生には対応していません。
- インサートSceneにはセリフ・字幕・立ち絵を置けません。
- 複数の動画をつなぐインサートはできません。動画ごとにインサートSceneを追加してください。
- インサートSceneを削除しても、動画素材や他のSceneのCueは削除されません。
- 主動画の削除や別テンプレートへの変更はできません。別の動画へ差し替えてください。
