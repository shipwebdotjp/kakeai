# サムネイルの作成

YouTube投稿用のサムネイルを、テンプレートに文字と写真を差し込んで作成します。画像生成AIではなく、決まったレイアウトを使うので、作品ごとの見た目がそろいます。

作品編集画面の右側にある「サムネイル」ボタンから開きます。サムネイルは**言語版ごと**に管理します。

## 候補を作る

1. 「候補名」を入力します（一覧で見分けるための名前です）。
2. 「切り抜きヒーロー」テンプレートに、背景写真と前景の切り抜き画像を選びます。
3. 見出し・補足文を入力します。
4. 右側にプレビューが表示されます。内容を確かめて「候補を追加」を押すと保存されます。

前景には、背景が透明なPNGまたはWebPを使います。透過していない画像を選ぶと、画像の四角い背景ごと表示されます。アプリは透過を自動判定しないため、プレビューで確認してください。

:::note[保存について]
入力は自動保存されません。変更したら必ず保存ボタンを押してください。保存済みの候補を開いて直した場合も同じボタンで上書きされます。
:::

## 共通の見た目と候補ごとの上書き

サムネイル画面の上部に「共通の見た目（この言語版）」があります。ここで変えた内容は、その言語版のすべての候補に適用されます。

- 見出し・補足文のカテゴリ、Font Face、サイズ、色、行間、装飾
- 縁取りの色と太さ
- 強調記法（`==`）のアクセント色
- 写真の暗幕（scrim）の色と不透明度

各項目は「Themeから継承する／上書きする」を切り替えられます。「すべてThemeに戻す」で、共通の上書きを全部消せます。共通の見た目は「共通の見た目を保存」を押すまで保存されません。保存前の内容も、候補フォームのプレビューに反映されます。

候補ごとに変えたいときは、候補フォームの「この候補だけ見た目を上書き」を開きます。共通の見た目を継承した状態から、必要な項目だけ上書きできます。

- 台本のテーマ（Visual Theme）を変えると、上書きしていない項目は新しいテーマに追従します。
- 自分で指定した色・書体・サイズ・太さ・行間は、テーマを変えても保持されます。

### 縁取りの色と太さ

縁取りは見出しと補足文で別々に設定できます。

- **縁取り色**：「自動」にすると、文字色と背景から読みやすい色を選びます。指定した色はそのまま使われます。
- **縁取りの太さ**：0〜12の数値です。1080p基準で、0にすると縁取りなしになります。
- 見出し全体の「縁取り」装飾と、`%%縁取り%%` の部分装飾は、同じ色・太さを使います。

## 文字の一部を装飾する

見出し・補足文は、文字の一部だけを太字・斜体・アクセント色・縁取りにできます。

1. 装飾したい文字を選択します。
2. 入力欄の上のボタン（太字・斜体・アクセント・縁取り）を押すと、選択範囲が記法で囲まれます。

記法を直接入力しても構いません。

| 書き方 | 結果 |
| --- | --- |
| `**重要**` | 太字 |
| `*Good*` | 斜体（書体に斜体がない場合は傾いた表示） |
| `==ここだけ色==` | アクセント色 |
| `%%縁取り%%` | 縁取り |
| `\*` | 記号をそのまま表示 |

- 装飾は組み合わせられます（例: `==**重要**==`）。
- アクセント色は「共通の見た目」の強調色、未指定ならテーマのアクセントから選ばれます。
- 自分で指定した強調色は、自動で別の色に置き換えられません。読みにくいときは、暗幕や縁取りも調整してプレビューで確認してください。
- 閉じ忘れの記号はそのまま表示されます。その項目で使えない装飾があると保存できず、エラーが入力欄の下に表示されます。
- 改行はそのまま反映されます。

## 写真の位置と大きさ

- 背景写真は、切り出し位置（左右・上下）と拡大率を調整できます。
- 前景の被写体は、左右のどちらに置くか、左右反転するか、大きさを変えるかを調整できます。
- 見出しは被写体の反対側の下部に置かれます。文字量が多いと自動で小さくなります。
- 自由なキャンバス配置（ドラッグ・回転・レイヤー編集）はできません。

## 候補の管理

候補ごとに次の操作ができます。

- **投稿用にする**: YouTubeにアップロードする1枚を選びます。候補が1つだけのときは自動で選ばれます。
- **書き出し**: PNGファイル（1280x720）をダウンロードします。
- **削除**: 候補を消します。投稿用の候補を消した場合は、残っている別の候補が自動で選ばれます。

「＋ 新しい候補」で候補を増やせます。複数作って見比べ、良いものを投稿用に選んでください。

## 見た目の決まり

- 色・書体・アクセントは、その言語版の台本で使っているテーマ（Visual Theme）を共有します。
- 共通の見た目と候補の上書きで、テーマを置き換えずに一部だけ調整できます。
- 写真の切り出し位置と拡大率、被写体の位置・反転・大きさはテンプレートの範囲内で調整できます。自由なキャンバス配置はできません。
- 出力は1280x720（16:9）です。
