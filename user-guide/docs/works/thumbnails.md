# サムネイルの作成

YouTube投稿用のサムネイルを、テンプレートに文字と写真を差し込んで作成します。画像生成AIではなく、決まったレイアウトを使うので、作品ごとの見た目がそろいます。

作品編集画面の右側にある「サムネイル」ボタンから開きます。サムネイルは**言語版ごと**に管理します。

## 候補を作る

1. 「候補名」を入力します（一覧で見分けるための名前です）。
2. 「テンプレート」を選びます（見出し＋写真、写真全面、文字のみ、重ね合わせなど）。
3. 見出し・補足文・写真などを入力します。写真は素材ライブラリから選びます。
4. 右側にプレビューが表示されます。内容を確かめて「候補を追加」を押すと保存されます。

:::note[保存について]
入力は自動保存されません。変更したら必ず保存ボタンを押してください。保存済みの候補を開いて直した場合も同じボタンで上書きされます。
:::

## 候補の管理

候補ごとに次の操作ができます。

- **投稿用にする**: YouTubeにアップロードする1枚を選びます。候補が1つだけのときは自動で選ばれます。
- **書き出し**: PNGファイル（1280x720）をダウンロードします。
- **削除**: 候補を消します。投稿用の候補を消した場合は、残っている別の候補が自動で選ばれます。

「＋ 新しい候補」で候補を増やせます。複数作って見比べ、良いものを投稿用に選んでください。

## 見た目の決まり

- 色・書体・アクセントは、その言語版の台本で使っているテーマ（Visual Theme）を共有します。作品の見た目とサムネイルの見た目がそろいます。
- 台本のテーマを変えると、保存済みのサムネイルの見た目も変わります。サムネイル単体では凍結されません。
- 写真の切り出し位置と拡大率、文字の位置や大きさはテンプレートの範囲内で調整できます。自由なキャンバス配置はできません。
- 出力は1280x720（16:9）です。
