# ターミナル風の映像を作る

**ターミナル** の映像演出は、黒いフローティングウインドウにコマンドの入力と出力を並べるテンプレートです。操作の解説、CLIのデモ、エラーと解決策の比較など、入力と結果のやりとりを見せたい場面で使います。

## 追加する

1. シーンの **映像演出** で「新しい映像演出」を開き、**ターミナル** を選びます。
2. 「映像演出を追加」を押すと、2つの入出力ターンが入った状態で追加されます。
3. **ウインドウのタイトル** と **プロンプト**（既定は `$`）を必要に応じて変えます。
4. **入力と出力** のターンごとに、入力するコマンドと、その出力を編集します。出力は1行につき1行として表示されます。
5. **入力速度（半角換算/秒）** でタイピングの速さを、**出力までの間隔(ms)** で入力完了から出力までの間を変えられます。未入力ならそれぞれ40・120で、通常の入力よりかなり速く打ちます。

新しいターンを追加すると、まだ使っていない次のセリフを自動で割り当てます。割り当てを変えるときは、下の **セリフ同期** でターンとセリフを選び直してください。

## セリフと同期する

**セリフ同期** で「効果を追加」を押し、対象のターン、契機（セリフまたは映像演出全体）、表示方法を選びます。

- **1文字ずつタイプ**: セリフの開始と同時に入力を打ち始め、打ち終わったあとに出力を表示します。
- **すぐに表示**: セリフの開始時に、入力と出力をまとめて表示します。
- セリフの長さよりタイピングが長くなった場合は、セリフの終わりで残りを一気に表示します。次のセリフに持ち越しません。
- 効果を付けないターンは、映像演出の最初から表示されます。セリフと同期せず、静的な画面として見せたいときに使います。

1つのターンには1つの効果だけを設定できます。セリフを選ぶときは、そのターンに対応するセリフを1つ選びます。

## 表示と注意

- ウインドウは画面の中央に余白を大きめに取って表示します。左右の立ち絵とは重なりにくくしていますが、完全に自動で避けることはできません。重なるときは立ち絵の位置や倍率を調整してください。
- ターミナルは **カード** の層に置かれるため、立ち絵が手前に描かれます。端末が立ち絵を隠すことはありません。
- 内容は上から詰めて表示し、スクロールはしません。行数が画面の目安を超えると、保存時に `terminal_overflow` 警告が出ます。ターンや出力行を減らすか、シーンを分割してください。
- 下端は字幕のセーフエリアの上で止まります。字幕と重なることはありません。
- 入力できるのは1行のコマンドだけです。複数行の入力や、出力のタイプ表示には対応していません。
- 端末の中身は映像として見せるだけで、読み上げや字幕とは連動しません。ナレーションは通常どおりセリフとして編集します。

:::note[目安]
横型では、入力1行＋出力2行のターンが4〜5個程度で画面が埋まります。長いセッションは、シーンを分けて複数のターミナル映像演出に分けると読みやすくなります。
:::
