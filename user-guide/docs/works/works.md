# 作品の管理

トップページの作品一覧で、作品の作成・表示・複製・版の復元・削除を行います。

## 作成

上部の入力欄に作品名を入れて「作成」を押すと、新しい作品が作られます。作成時は日本語（ja-JP）の台本の初期版も一緒に用意されます。

## 一覧の見方と操作

作品ごとに次の情報と「操作」メニューが表示されます。

- **作品名**: 押すと編集画面を開きます。
- **版番号（vN）**: 現在の台本の版番号です。保存のたびに増えます。
- **更新日時**: 台本を保存した日時で並びます。

「操作」ボタンを押すと以下のメニューが表示されます。

- **複製**: 現在の台本版を引き継いだ新しい子作品を作成します。作品名を編集して確認すると、複製先の編集画面へ移動します。
- **履歴・復元**: 保存日時と版番号の履歴一覧を表示します。過去の版から「復元」を押すと、既存の版を上書きせず、新しい版として最新の現在版へ復元します。
- **削除**: 確認のうえ作品を削除します。元に戻せません。

## 作品名の変更

編集画面の上部で名前を変えて「作品名を保存」を押すと、管理上の作品名だけが変わります。動画内に表示するタイトルは台本の編集で変えてください。

## 削除の注意点

- 作品と一緒に、その台本の履歴・レンダー履歴・出力ファイルも消えます。
- 素材ライブラリの素材は共有のため残ります。
- 子作品がある作品は削除できません。
