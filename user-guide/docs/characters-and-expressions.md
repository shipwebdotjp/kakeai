# キャラクターと表情セット

キャラクターライブラリは、作品をまたいで使うキャラクターと外観を管理します。表情セットを使うと、立ち絵の顔パーツを組み合わせて表情を切り替えたり、瞬きや口パクを付けたりできます。

## キャラクターライブラリ

画面右上の「キャラクター」から、全作品で使えるキャラクターを登録します。

- **キャラクターを追加** で名前を入力し、**言語別の声**（言語と声プロファイルの組）を登録します。「声を追加」で言語ごとの声を増やせます。
- **言語別の名前**（言語と名前の組）を登録すると、台本への取り込みと言語版の作成で対象の言語の名前が使われます。一致がなければ上の名前を使います。「名前を追加」で言語ごとの名前を増やせます。
- キャラクターごとに **外観を追加** します。外観は画像1枚と、表示名（例「夏服」）・表情・ポーズのタグを持ちます。画像は素材ライブラリの準備完了済み画像から選びます。外観には、下の「表情セット」で作った顔素材を割り当てられます（「表情セット」で「なし」を選ぶと割り当てなし）。
- 台本には、編集画面の「キャラクター」から「ライブラリから追加」でコピーして使います。コピーなので、ライブラリを変更しても追加済みの作品には波及しません。外観が使う表情セットも、追加した時点の版に固定されます。
- ライブラリの変更を作品へ取り込みたいときは、作品のキャラクター欄にある **ライブラリから更新** を使います。名前・言語別名・声・外観と、表情セットの最新版の差分が表示され、作品内のキャラクター・話者・立ち絵の ID は維持されます。ライブラリで削除された外観は作品内に残り、新しく追加された外観は追加されます。新しい表情セット版にない表情を使っている台詞は一覧表示され、適用すると通常の表情に戻ります。
- この更新機能は、この機能が追加された後に「ライブラリから追加」したキャラクターだけが対象です。それ以前に追加したキャラクターは更新対象外で、固定された版のまま使います。
- 取り込んだ後は、作品の「キャラクター」欄で名前・声プロファイルに加えて **外観（画像・表示名・表情・ポーズ）の追加・編集・削除** ができます。作品独自の外観はここで調整してください。立ち絵の外観選択には、表示名があれば「夏服（smile / front）」のように表示されます。
- 複数の作品で同じ外観を使い回したいときは、ライブラリに登録しておくと各作品へ取り込めます。

## 表情セット

画面右上の「表情」から、立ち絵の表情・瞬き・口パクに使う顔素材を登録します。互換な外観（顔の向き・位置・大きさが同じ立ち絵）で共有できます。

- **顔レイヤー** を「レイヤーを追加」で登録します。部位（眉／目／口／前景）を選び、立ち絵のベース画像と**同じ寸法の透過画像**を選びます。ベース画像に描かれていない眉・目・口だけを描いた画像を使います。寸法が違う画像は保存時にエラーになります。
  - 目のレイヤーには、閉じた目のレイヤーを **閉眼** として選べます。選ぶと、その目が表示されている間に決まったタイミングで瞬きします。
  - 口のレイヤーには、開いた口のレイヤーを **開口** として選べます。選ぶと、セリフを話している間に口が不規則に開閉します。音声や読み上げ内容との同期はありません。
  - 閉眼・開口を選ばないレイヤーは静止したままです。
- **表情プリセット** を「表情を追加」で作ります。**表示名**（例「笑い」）を付け、眉・目・口に使うレイヤーをそれぞれ選びます。`normal`（通常）は必須で削除できません。表情の切り替えはこの表示名の一覧から選びます。
- 「追加」「保存」で登録します。使用中の表情セット（外観や保存済みの台本から参照中）は削除できません。
- レイヤーや表情を変更して保存すると、**新しい改訂版**が作られます。名前だけを変えた場合は版は増えません。使用中ライブラリキャラクターのベース画像との合成プレビューと寸法診断が表示され、寸法が一致しない内容は最新版として保存できません。
- 改訂版を保存しても、追加済みの作品は固定した版を使い続けます。ライブラリのキャラクターと新しく追加する作品は最新版を使います。

### 作例：最小構成で表情差分を作る

眉・目・口を描いていないベース立ち絵に、通常の眉・目・口を重ねて表情を切り替えられるようにします。

1. 素材ライブラリに画像を4枚用意します。**ベース立ち絵**（眉・目・口なしの全身）、**眉だけ**・**目だけ**・**口だけ** を描いた透過画像3枚です。透過画像3枚はベースと**同じ寸法**にします。
2. 「表情」で表情セットを追加し、名前（例「リン正面」）を付けます。
3. **顔レイヤー** に3枚を登録します。部位はそれぞれ 眉／目／口 を選びます。
4. **表情プリセット** の `normal`（通常）に、眉・目・口の3枚を割り当てます。
5. キャラクターの外観にベース立ち絵を登録し、その外観の **表情セット** で作ったセットを選びます。
6. 台詞の **表情** で `normal` を選ぶと、そのセリフの間だけ重ねた顔で表示されます。選ばないときも通常の表情です。

差分を増やす例：目の笑顔画像を顔レイヤーに追加し、「表情を追加」で表示名「笑い」のプリセットを作り、目だけ笑顔のレイヤーに変えます。眉と口は `normal` と同じレイヤーを使い回せます。

瞬きを付ける例：閉じた目の画像を顔レイヤー（部位：目）に追加し、通常の目レイヤーの **閉眼** に選びます。口パクを付ける例：開いた口の画像を顔レイヤー（部位：口）に追加し、通常の口レイヤーの **開口** に選びます。
