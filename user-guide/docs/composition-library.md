# Composition Library 機能の更新

Composition Library 関連機能が追加されました。

- Web UI に `/compositions` (Composition Library 画面) が追加され、AI 等によって作成・更新・Publish された Composition の一覧や Draft 状態、公開バージョンが確認できるようになりました。
- Script 編集画面等において、Scene 背景 (range: scene, layer: background) として `composition.full-bleed@1` テンプレートを指定し、特定の CompositionVersion ID を設定することで背景モーションを配置できます。
