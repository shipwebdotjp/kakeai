# Composition Library

Composition Library は、AI（HyperFrames）が作成・公開した全画面モーション（Composition）を、作品をまたいで再利用するためのライブラリです。

## 確認する

画面右上の「コンポジション」を開くと、登録されている Composition の一覧が表示されます。

- 一覧には各 Composition の名前・runtime ID・draft の状態・公開バージョン数が並びます。項目を押すと選択され、詳細が表示されます。
- 詳細には draft の entrypoint と、公開バージョンの一覧（版番号・キャンバス・スキン・バージョンID・bundle ハッシュ・entrypoint・公開日時）が表示されます。「キャンバス」はその版の Canvas Profile（横長 1920×1080 ／ 縦長 1080×1920）です。「スキン」は AI がその版を作ったときの世界観（例: `handmade-paper@1`、スキン未指定の `neutral`、情報がない `legacy`）です。
- Composition の作成・更新・公開（Publish）は AI が行います。Web UI には HTML の直接編集や公開ボタンはありません。編集内容は draft に入り、公開して初めて台本から参照できる不変の CompositionVersion になります。

AI は Agent Access（MCP / CLI）の `composition.draft.get` で draft を読み、`composition.draft.save` で書き、`composition.publish` で公開します。アプリが管理する `drafts/` と `bundles/` を直接編集することはありません（[エージェント連携](./agent-access.md)）。

## 台本で使う

背景として使う場合:

1. 作品の編集画面で、対象シーンの Cue に **コンポジション背景（全面）**（`composition.full-bleed@1`）を追加します。
2. 入力欄のドロップダウンから、公開済みの横長（landscape 1920×1080）CompositionVersion を選びます。縦長（portrait）の版はここには表示されません。

端末画面（デバイスフレーム）の中に使う場合:

1. 対象シーンの Cue に **デバイスフレーム**（`scene.device-frame@1`）を追加します。
2. 画面欄の「素材／Composition」で **Composition** を選びます。
3. 公開済みの CompositionVersion を選び、必要に応じて **表示方法**（全体を収める／全体を覆う）、**位置**（横・縦）、**倍率** を調整します。中央・等倍に戻すボタンで既定に戻せます。ドロップダウンには横長・縦長の両方が表示されます。スマートフォン枠は 9:16 なので、縦長の版は「全体を収める」でちょうど収まります。

制約:

- `composition.full-bleed@1` の **レイヤー** は背景のみです。**表示区間** は Scene 全体・セリフ区間・オフセット（ミリ秒指定）から選べます。縦長（portrait）の版は指定できません（保存・プレビュー・レンダーでエラーになります）。縦長は端末画面（スマートフォン枠）に置いてください。
- 同じ CompositionVersion は、1 つの台本内で何度でも参照できます（複数の背景や複数の端末画面に置けます）。
- Composition の尺（公開時の再生時間）より表示区間が長い場合、Composition の終わりで表示が打ち切られます（最後の絵を止めて表示し続けたり、繰り返したりはしません）。端末画面内の Composition も同じで、終わりで非表示になります。
- Scene 間のクロスフェードで必要になる表示時間が Composition の尺を超えると、保存時とレンダー開始時にエラーになります。Composition を長くするか、クロスフェードを短くしてください。
- 公開バージョンは不変です。AI が修正しても、既存の台本が参照する版は変わりません。新しい版を使いたいときは、台本のバージョンIDを差し替えて保存します。
- 端末画面での埋め込みは、いまはデバイスフレーム（ラップトップ／スマートフォン）の画面のみです。サイトモックアップやカードへの埋め込みは今後の対応です。

> ドロップダウンに目的のバージョンが無い場合は、AI がまだ公開していないか、公開に失敗しています。公開時には、manifest の Canvas Profile（横長 1920×1080 ／ 縦長 1080×1920）と寸法の一致・有限尺・無音・HyperFrames lint エラーなしなどが検証されます。

> 台本のテーマのスキンと、選んだ CompositionVersion のスキンが異なる場合、ドロップダウンの下に警告が表示されます（例: 紙のスキンの台本に `neutral` の Composition を置いた場合）。保存やレンダーは拒否されません。見た目の調和を確認してください。
