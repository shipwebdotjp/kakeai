# 素材ライブラリ

画面右上の「素材」から、全作品で使える素材（画像・動画・音声）を管理します。

## 対応形式と上限

- **画像**: PNG / JPEG / WebP など
- **動画**: MP4 / WebM など
- **音声**: MP3 / WAV など
- **上限の目安**: 1ファイル4GiBまで、動画・音声は30分まで、画像・動画は縦横とも3840pxまで

上限を超えるファイルはアップロード時にエラーになります。

## アップロード

ファイルを選ぶか、点線の枠内にドラッグ&ドロップします。

- 「ファイルを選択」では複数のファイルを一度に選べます。選んだファイルは枠内に一覧表示され、「外す」で取り消せます。
- 一覧を確認して「N件をアップロード」を押すと取り込みが始まります。取り込みが終わると状態が「準備完了」になります。
- 取り込み中は「取り込み中」、対応外の内容などは「失敗」と表示されます。
- 同じ内容のファイルは自動的にまとめられ、二重には保存されません。
- 「準備完了」になる前の素材は、台本・プレビュー・レンダーには使えません。
- 失敗したファイルは一覧に残るので、内容を確認して再度アップロードできます。

## 一覧の見方

素材ごとにプレビュー（画像のサムネイル、動画・音声の再生）、種類、サイズ、寸法・長さが表示されます。

## 素材を選ぶ（ピッカー）

台本編集やキャラクターの外観などで画像・動画・音声を選ぶときは、モーダルの素材ライブラリが開きます。

- **ファイル名で検索** で絞り込めます。
- その場でファイルをアップロードできます（ドラッグ&ドロップ、またはファイル選択）。
- 素材を選ぶとモーダルが閉じ、選んだ素材のサムネイルとファイル名が欄のそばに表示されたままになります。「解除」で選択を外せます。
- 準備完了（「準備完了」）の素材だけが選べます。

## 削除

「削除」を押すと確認のうえ削除されます。台本などで使用中の素材は削除できません。
