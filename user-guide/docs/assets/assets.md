# 素材ライブラリ

画面右上の「素材」から、全作品で使える素材（画像・動画・音声）を管理します。

## 対応形式と上限

- **画像**: PNG / JPEG / WebP など
- **動画**: MP4 / WebM など
- **音声**: MP3 / WAV など
- **上限の目安**: 1ファイル4GiBまで、動画・音声は30分まで、画像・動画は縦横とも3840pxまで

上限を超えるファイルはアップロード時にエラーになります。

## アップロード

ファイルを選ぶか、点線の枠内にドラッグ&ドロップします。

- 「ファイルを選択」では複数のファイルを一度に選べます。選んだファイルは枠内に一覧表示され、「外す」で取り消せます。
- 一覧を確認して「N件をアップロード」を押すと取り込みが始まります。取り込みが終わると状態が「準備完了」になります。
- 取り込み中は「取り込み中」、対応外の内容などは「失敗」と表示されます。
- 同じ内容のファイルは自動的にまとめられ、二重には保存されません。
- 「準備完了」になる前の素材は、台本・プレビュー・レンダーには使えません。
- 失敗したファイルは一覧に残るので、内容を確認して再度アップロードできます。

## 一覧の見方

素材ごとにプレビュー（画像のサムネイル、動画・音声の再生）、種類、サイズ、寸法・長さが表示されます。

一覧の上の操作で、目当ての素材を絞り込めます。

- **ファイル名で検索**: 名前の一部を入力すると、一致する素材だけを表示します。
- **種類**: 画像・動画・音声のいずれかに絞り込めます。
- **並び替え**: 「追加が新しい順」「名前順」「お気に入り優先」から選べます。
- **★ お気に入り**: お気に入りを付けた素材だけを表示します。
- **アーカイブ**: 通常隠れているアーカイブ済みの素材を表示します。
- **カード / リスト**: 表示形式を切り替えます。カードはサムネイル中心、リストは情報を並べて表示します。

タグを選ぶ絞り込みと組み合わせて使えます。

## お気に入りとアーカイブ

素材ごとに、お気に入り（★）とアーカイブを切り替えられます。

- **お気に入り**: ☆を押すと★になり、お気に入りに追加されます。「お気に入り優先」の並び替えや「★ お気に入り」の絞り込みで使えます。
- **アーカイブ**: 「アーカイブ」を押すと、通常の一覧とピッカーから隠れます。見たいときは「アーカイブ」トグルで表示し、「戻す」で元に戻せます。アーカイブしても素材は削除されませんが、「未参照素材を清掃」ではアーカイブ済みでも未参照なら削除対象になります。

## タグ

素材を分類するタグを付けられます。素材が増えてきたときに、目当ての素材を探しやすくなります。

- 素材の下の「タグを追加」に文字を入れて Enter か、欄の外をクリックするとタグが付きます。
- タグの「×」を押すと外せます。変更はその場で保存されます。
- 見出しの下に、付いているタグの一覧が並びます。タグを押すとそのタグの素材だけが表示され、もう一度押すと解除されます。複数のタグを選ぶと、いずれか1つ以上を持つ素材を表示します。「解除」で絞り込みを止めます。
- タグの変更は、その素材の分類だけを変えます。同じ素材を使っている台本やプレビューには影響しません。

## 素材を選ぶ（ピッカー）

台本編集やキャラクターの外観などで画像・動画・音声を選ぶときは、モーダルの素材ライブラリが開きます。

- **ファイル名で検索** や **タグ** で絞り込めます。並び替え・お気に入り・アーカイブの切り替えも、素材ライブラリと同じ操作です。
- **カード / リスト** で表示形式を切り替えられます。カードでは、種類のラベルとタグ、ファイル名の順に表示されます。
- その場でファイルをアップロードできます（ドラッグ&ドロップ、またはファイル選択）。
- 素材を選ぶとモーダルが閉じ、選んだ素材のサムネイルとファイル名が欄のそばに表示されたままになります。「解除」で選択を外せます。
- 準備完了（「準備完了」）の素材だけが選べます。

## 削除

「削除」を押すと確認のうえ削除されます。台本などで使用中の素材は削除できません。

## 未参照素材の清掃

見出しの右の「未参照素材を清掃」を押すと、どの台本からも参照されていない素材をまとめて削除します。台本などで使用中の素材は残り、削除件数と残した件数が表示されます。作品を削除した後などに、使われなくなった素材をまとめて片付けるときに使います。
